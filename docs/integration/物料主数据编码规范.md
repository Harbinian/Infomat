# 物料主数据编码规范草案 V0.2

> 文档状态：草案（待5月9日专题会议确认）
> 编制日期：2026-05-01
> 适用范围：ERP（用友U8）、MES（北京虎蜥）、PLM、WMS 等各系统物料主数据

---

## 一、编码设计原则

1. **唯一性**：每一个物料在全公司范围内有且仅有一个编码，跨系统共用。
2. **稳定性**：编码一经创建，不得因物料名称、规格、版次变更而修改；版次（REV）作为独立字段，不进入主编码。
3. **可读性**：编码结构须兼顾人工识别与系统解析，大类码+小类码+流水号三段式。
4. **扩展性**：小类码预留扩展空间，避免未来分类调整导致编码体系崩溃。
5. **系统兼容性**：编码长度与字符集须经各系统确认，确保无截断或乱码风险。

---

## 二、编码结构（10位 + 2个连字符 = 13字符）

```
XX  -  XXX  -  00000
│      │        │
大类   小类    流水号
(2位)  (3位)   (5位)

总长度：13字符（含2个连字符）
版次REV：独立字段，不进主编码
```

| 段位 | 位数 | 来源 | 示例 |
|------|------|------|------|
| 大类码 | 2位 | 一级分类（12大类） | `CF`=碳纤维复合材料件 |
| 小类码 | 3位 | 二级分类（各子类自行定义） | `PNL`=壁板类、`SPA`=梁类 |
| 流水号 | 5位 | 系统自动生成，按小类顺序递增 | `00001` ~ `99999` |

**完整示例**：`CF-PNL-00001`（碳纤维 / 壁板类 / 第1条）

## 四、航空复材特殊编码规则

| 规则 | 说明 |
|------|------|
| **件号（Part Number）与物料编码的关系** | 对外交付件号（主机厂要求格式）与内部物料编码**完全分离**，通过映射表关联。**禁止**直接用主机厂件号作为内部物料编码 |
| **预浸料有效期不进编码** | 预浸料的批次号、生产日期、有效期作为**批次属性**管理，不体现在物料编码中 |
| **工艺规范号单独字段** | 固化工艺规范（Cure Spec）、无损检测规范（NDT Spec）作为**物料属性字段**，不进编码 |
| **构型状态码** | 适航构型状态（如 TC/STC 适用性）作为**独立属性**，不进编码 |
| **版次（REV）独立管理** | 版次变更（如 A→B）不改变物料编码，旧编码废止或新建物料编码 |

## 七、编码创建与变更规则

### 7.1 核心原则

> **编码一经创建，永久不变。版次（REV）变更不等于编码变更。**

- 物料编码**永久不变**，停产仅标记"废止"状态，不复用。
- 规格、材质、功能发生实质性变更时，必须**新建物料编码**，旧编码标记废止。
- 版次变更（如 Rev.A → Rev.B）：物料编码不变，REV字段更新，BOM版本同步切换。
- ECO（工程变更单）触发实质性变更时，由PLM发起新编码申请。

### 7.2 ECO变更对物料的影响

```
ECO发起（PLM）
    ↓
判断变更类型
    ├── 版次变更（REV更新）→ 原编码不变，REV字段更新，同步各系统
    └── 实质性变更 → 新建物料编码，旧编码标记废止
                        ↓
                    确定切换时间点（Cut-in Date）
                        ↓
                    ERP更新BOM & MRP
                        ↓
                    MES更新工艺路线
                        ↓
                    WMS处理旧编码库存（消耗/退货/报废）
```
