      CAPP                 ERP-PP（用友U8）

  三维工艺/工装            +定额下达

### MBD 在集成中的关键作用

| 传递内容 | 接收方 | 意义 |
|---------|-------|------|
| 含标注的三维模型 | CAPP / 三维工艺 | 工艺设计直接读取模型，无需二维图纸 |
| 材料/公差定义 | CAPP → 计划管控 | 驱动下料管理、零件采购规格 |
| 更改管理 | PDM → EBOM | 设计变更自动触发BOM版本更新 |
| 设计资源 | PDM归档受控 | 确保制造端使用唯一受控版本 |

> **核心价值：** MBD 是"无纸化制造"的起点，三维模型携带完整制造信息，直接驱动下游 CAPP、三维工艺、WMS 下料管理，避免二维图纸的信息损失和传递延迟。

## 七、华天动力 OA 系统集成说明

### 7.1 产品定位

华天动力 OA 由大连华天软件有限公司于 2003 年推出，专注 OA 领域超过 20 年。系统基于 **Java/J2EE + 魔方架构**开发，以**工作流引擎、智能报表、低代码平台**为三大核心技术，是本架构中的**流程协同层**，横向贯穿各业务域。

### 7.2 产品线矩阵

| 产品系列 | 版本 | 适用对象 |
|---------|------|---------|
| 企业组织系列 | 企业版 / 集团版 | 中大型企业、集团型组织 |
| 政府/事业单位系列 | 政务版 / 信创版 | 政府机关、党政单位 |
| 跨国组织系列 | 多语言版 / 鸿蒙版 | 跨国企业、国产化适配 |

### 7.3 核心功能模块

**业务应用层**

```
├── 费控管理        ← 费用申请、报销、预算管控
├── 资产管理        ← 全景式资产全生命周期
├── HR管理          ← 智能招聘、人事档案
├── 项目管理        ← 项目立项、进度、成本
├── 采购管理        ← 采购申请到合同执行
├── 合同管理        ← 合同起草、审批、归档
├── 公文管理        ← 收发文、套红、归档
├── 会议管理        ← 会议室预约、纪要
└── 知识管理        ← 文档库、权限管控
```

**平台引擎层**

```
├── 工作流引擎      ← 图形化流程设计，支持固定/分支/并行流程
├── 低代码平台      ← 可视化构建专属业务应用
├── 集成平台        ← 单点登录、多系统集成、API对接
└── 嵌入式应用      ← 支持嵌入第三方系统
```

### 7.4 技术架构特点

| 技术维度 | 说明 |
|---------|------|
| 开发框架 | Java/J2EE，魔方架构 |
| 数据库支持 | Oracle、MySQL、SQL Server 等多数据库 |
| 操作系统 | 跨平台，支持 Windows / Linux |
| 移动端 | 支持 App + 微信/钉钉集成，鸿蒙版适配 |
| 信创适配 | 支持国产操作系统、国产数据库、国产芯片 |
| 集成能力 | 支持 ERP、CRM、财务等异构系统集成，单点登录 |

### 7.5 与本架构的集成关系

```
华天动力 OA（流程协同层）
    │
    ├── 合同管理模块  ←→  合同管理系统（补充线上审批流）
    │                      合同准备 → OA审批 → 合同签订 → 合同执行
    │
    ├── 项目管理模块  ←→  一体化平台（项目商务/启动策划/执行控制/KPI）
    │                      项目立项审批、里程碑节点审核
    │
    ├── 采购管理模块  ←→  ERP-用友U8 / SCIM
    │                      采购申请 → OA审批 → 用友U8生成采购订单
    │
    ├── 公文管理模块  ←→  PDM（工程文件会签流程）
    │                      设计变更单(ECO)线上会签、归档
    │
    ├── 费控管理模块  ←→  ERP-用友U8
    │                      费用报销审批 → 财务凭证自动生成
    │
    ├── HR管理模块    ←→  ERP-用友U8（人力资源）
    │                      人员信息同步、考勤数据对接
    │
    └── 集成平台      ←→  ERP-用友U8 / MES-北京虎蜥 / PLM / WMS
                           单点登录统一入口，一屏通办
```

### 7.6 OA 在各业务域的流程协同价值

| 业务域 | OA介入的核心流程 | 与业务系统的数据交互 |
|-------|---------------|------------------|
| **研发域** | 设计评审、ECO变更审批、文件发放审批 | PDM ← OA审批结果 → PLM状态更新 |
| **采购域** | 采购申请审批、合同会签、付款审批 | ERP-用友U8 ← OA审批单据 → SCIM协同 |
| **制造域** | 工艺更改审批、质量问题处理流程 | MES-北京虎蜥 ← OA工艺变更通知 |
| **财务域** | 费用报销、预算申请、资产盘点审批 | ERP-用友U8 ← OA凭证数据 |
| **项目域** | 项目立项、阶段评审、KPI考核 | 一体化平台 ← OA项目审批节点 |

## 九、各系统层次定位总结

```
┌─────────────────────────────────────────────────────┐
│  PLM（翎瑞鸿翔）：管"产品是什么、怎么定义"           │
├─────────────────────────────────────────────────────┤
│  OA-华天动力（流程协同）：管"审批怎么流转、协同怎么做"  │
├─────────────────────────────────────────────────────┤
│  ERP-用友U8（企业资源计划）：管"资源怎么计划、成本怎么核算"│
├─────────────────────────────────────────────────────┤
│  MES-北京虎蜥（制造执行）：管"车间怎么执行、过程怎么管控"│
├─────────────────────────────────────────────────────┤
│  WMS（仓储管理）：管"物料在哪里、怎么流转"             │
├─────────────────────────────────────────────────────┤
│  SCIM（供应商协同）：管"外部供应链怎么协同"            │
└─────────────────────────────────────────────────────┘
         ↑ 以上所有系统的数据汇聚至 ↓
┌─────────────────────────────────────────────────────┐
│         数据底座 + 数字孪生                   │
└─────────────────────────────────────────────────────┘
```

> **一句话总结：** PLM 定义产品，**OA-华天动力协同流程**，ERP-用友U8 计划资源，MES-北京虎蜥执行制造，WMS 管控物流，SCIM 协同供应商——六者以**数据驱动**方式串联，共同支撑客户交付一体化平台的端到端运营。
