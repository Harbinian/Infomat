# 存货档案编码规范

1. **对象区分。** 建档前明确档案代表物料、服务、费用、工具或资产实物、生产任务。物料使用物料主编码，其他对象使用各自标识，并按需关联物料。

2. **编码结构。** 物料主编码采用“2 位大类—2 位小类—6 位顺序号”，各段使用数字，以半角连字符连接，共 12 个字符，如 `01-01-000223`。顺序号在同一大类、小类内从 `000001` 递增，不重复使用。

3. **分类规则。** 大类、小类代码从统一分类字典选取，不得自行增设。同一层级采用一致的划分依据；项目、研制或批产阶段、供应商、自制或外购、客供及使用位置不作为物料分类依据。

4. **唯一性。** 一个经确认的物料身份对应一个主编码。依据图样、标准、材料、尺寸及适用技术要求判断是否同物，不得仅凭名称相同、规格文字相同或编码相似合并档案。

5. **名称与规格。** 名称应明确表达对象，不得直接复制编码。规格按类别分别维护型号、尺寸、材料等适用属性，保留原始描述并关联定义依据；不得以重复名称或占位文字代替必要规格。服务和任务应明确处理对象、业务范围及交付要求。

6. **计量单位。** 每个物料明确主计量单位，单位名称统一。盒、卷、套等包装或成套单位须明确数量或组成；换算须有依据，不得默认按 1∶1 换算。

7. **业务关系。** 供应商、项目、使用位置、批号、实物卷号、任务及组成关系单独记录，不拼入物料主编码。技术定义及适用要求不变时，不因上述关系变化另建物料号。

8. **建档发号。** 申请人提供定义依据，经授权的档案维护人员查重后统一发号。查重结果分为“同物复用、不同物新建、证据不足补充”；证据不足时不得直接新建或合并。

9. **变更与停用。** 编码发出后保持稳定，分类调整时仅更新当前分类，编码保留发号时的分类段。技术定义变化是否形成新物料，由有权主体确认；停用编码不得重新分配，变更须留存依据和记录。

10. **原码对应与传递。** 保留“来源系统、账套、原存货编码”与主编码的对应关系，不直接覆盖或批量改写原码。编码在保存、引用、导入导出及接口传递中均按文本处理，保留前导零和完整字符；启用前核对系统字段、单据及接口兼容性。
