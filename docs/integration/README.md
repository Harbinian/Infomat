# docs/integration 说明

> 状态：集成方案与接口设计参考目录  
> 生效日期：2026-06-10  
> 范围：接口模板、系统集成关系说明、主数据治理方案和选型参考材料。

本目录保存系统集成和主数据治理相关的方案材料。它可以为接口设计、主数据治理和系统关系梳理提供参考，但不替代流程真源、组织真源或 PMO 展示数据。

## 1. 当前文件

| 文件 | 作用 | 口径 |
|---|---|---|
| `接口设计卡模板.md` | 记录接口设计字段和接口卡片结构 | 模板 |
| `系统集成关系说明.md` | 描述系统间集成关系和说明口径 | 参考说明 |
| `MDM主数据治理方案.md` | 主数据治理方案材料 | 方案参考 |
| `PLM选型评分矩阵.md` | PLM 选型评分材料 | 历史或评估参考 |

## 2. 使用边界

1. 流程数量、流程落位和部门口径仍以 `docs/norms/` 与 `docs/organization/` 为准。
2. 本目录可以承接接口设计和集成说明，但不要在这里新增部门流程映射真源。
3. 评分矩阵和方案材料只作为评估记录，不能单独作为系统选型结论。
4. 与 MDM 平台实现有关的代码、接口和测试仍归 `apps/mdm-platform/`。

## 3. 修改自检

- 新增接口卡或集成说明时，写清输入、输出、系统边界和数据责任方。
- 引用流程或部门数据时，标明来自哪份真源文件。
- 如果材料已转为历史参考，在文件开头注明状态和日期。
