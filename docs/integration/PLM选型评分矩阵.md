## 三、评分说明

### 评分等级定义

| 等级 | 分值 | 定义 |
|------|-----|------|
| 完全满足 | 5 | 功能成熟，可直接使用，无需二次开发 |
| 基本满足 | 3 | 功能存在，但需一定配置或定制开发 |
| 不满足 | 1 | 功能缺失或不可用，需大量二次开发 |
| 不适用 | 0 | 该维度与产品无关，不计入权重 |

### 加权得分计算

```
加权得分 = Σ(权重_i × 得分_i)
总分 = 加权得分 / Σ权重_i（排除0分维度后重新计算权重基准）
```

## 四、评审注意事项

1. **航空复材专项优先**：航空复材BOM能力（50%权重）是核心门槛，任何一项得分≤1分应一票否决或大幅降权
2. **集成能力验证**：SSO和API能力需实际演示确认，不能仅凭文档评分
3. **构型管理闭环**：ECO变更链路必须与华天动力OA形成闭环，否则无法满足适航追溯要求
4. **固化规范绑定**：固化工艺规范号若不能与MBOM工序强制绑定，则预浸料-零件-固化参数的追溯链会断裂
5. **试用期要求**：建议安排不少于2周的试用期，重点测试EBOM铺层数据录入和MBOM转换流程
