## 9. 正例、反例、边界例和盲样需求

### 9.1 分类与扩展样本最低要求

每个待验证小类至少需要：3 个真实正例、2 个相邻类别反例、2 个边界或冲突例。总体样本还必须覆盖：机电/流体多功能对象；标准定义与制造商定义并存对象；品牌化材料和当前用途混淆对象；工艺辅助、包装和清洁材料的范围重叠；同一身份在不同 BOM 角色下的重复发生；自制转外购；暂时无法归类对象。

样本不足时使用全部已取得对象，但 G4、G5 仍保持阻断或失败，不降低门槛。

### 9.2 映射与身份样本

必须分别取得 EBOM 行到企业物料身份/U8 档案的无对应、一对一、一对多、多对一、多对多和无法判断案例。每个案例需同时携带受控定义、修订、有效性、技术特征、供给/用途情境及有权主体判断，防止把 ERP 控制差异误当成身份差异。

### 9.3 独立盲样

G10 使用的盲样必须由未参与规则设计的人员判断；样本不显示原分类答案和预期扩展值；记录首次判断、复判、冲突原因和关闭证据。设计者自测和本轮自动检查不等于独立反证。
