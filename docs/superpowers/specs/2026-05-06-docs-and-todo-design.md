### 3.3 P1 阶段详细接口范围

**本项目聚焦 OA、ERP、MES、PLM 四套系统。P1 必须完成全部接口链路设计，WMS/SCIM 相关接口同样必须设计——接口标准先于选型确定，不专业的供应商直接排除。**

需完成的全部接口链路（每条链路一张接口卡）：

| # | 接口链路 | 方向 | 说明 |
|---|---------|------|------|
| 1 | PLM → PDM | 工程 BOM 发布 | EBOM/ECO/MBD/构型发布 |
| 2 | PLM → ERP | 设计件物料主数据同步 | PLM 字段样例确认后 |
| 3 | PDM → CAPP | 受控 EBOM + MBD 传递 | PLM 选型确认后展开 |
| 4 | CAPP → MES | MBOM 下发 | 工序/工装/定额传递 |
| 5 | ERP-PP → MES | 生产订单下达 | 用友 U8 标准接口 |
| 6 | MES → ERP-PP | 完工反馈 | 报工/工时/质检回传 |
| 7 | ERP-MM ↔ WMS | 库存同步 | 采购件/原材料出入库 |
| 8 | MES ↔ WMS | 领料/入库 | 批次/有效期管控 |
| 9 | OA → ERP | 审批结果通知 | 审批流触发 ERP 操作 |
| 10 | OA → MES | 审批结果通知 | 审批流触发 MES 动作 |
| 11 | OA ↔ PLM | ECO 审批闭环 | ECO 发布审批对接 |
| 12 | OA ↔ PDM | 质量文件受控归档 | 文档审批 → PDM 发布 |
| 13 | ERP-MM → SCIM | 供应商协同基础数据 | SCIM 边界确认后补齐 |
| 14 | MES → 追溯数据湖 | 制造过程数据写入 | Phase 3 追溯设计 |

> 注：PDM、CAPP、WMS、SCIM 的系统选型尚未完成；接口卡需在选型前基于标准格式完成初稿，选型确认后验证和补全具体字段。

## 五、关键原则

1. **接口标准先于选型**：所有系统相关接口卡必须先设计完毕；供应商不专业则排除，不等待
2. **文档是执行依据**：to-do list 的每项交付物必须有对应文档承接；无文档的交付物视为未完成
3. **信息化项目组为技术总集成方**：P1-P5 各阶段的技术执行牵头均为信息化项目组；项目管理部负责业务收口和进度统筹
4. **归档不等于删除**：归档文档保留历史，不丢弃；未来仍有审计和追溯价值
