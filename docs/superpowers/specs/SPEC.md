# 业务关系网络图 - 设计规范

## 概念与愿景

一个直观的三列可视化工具，用于映射制造业信息化系统中业务能力（L2）、业务流程（L3）和应用系统（S1）之间的复杂关系。用户通过点击操作快速建立连线，系统自动计算最佳布局，实现所见即所得的网络图构建体验。

## 设计语言

### 视觉风格
- **主题**：深色专业界面（#1a1a2e 背景）
- **节点样式**：
  - 业务能力（L2）（绿色）：渐变蓝 #1565c0 → #0d47a1，实线边框
  - 业务流程（L3）（紫色）：渐变紫 #6a1b9a → #4a148c
  - 应用系统（S1）（橙色）：渐变橙 #e67e22 → #d35400
- **连线**：红色实线 #e94560，带箭头，悬停高亮
- **L2标题**：虚线边框，仅作视觉指示，不可点击

### 布局
- 三列固定位置（列起始 x 坐标）：
  - 业务能力（L2）列：x=30
  - 业务流程（L3）列：x=320
  - 应用系统（S1）列：x=600
- 节点垂直间距：固定行高 45px，节点高度 36px
- 所有列垂直居中于最大行数

### 动效
- 节点悬停：scale(1.03)，box-shadow 增强
- 节点选中：scale(1.05)，黄色光晕
- 连线：虚线动画（dash 8px）

## 功能

### 核心操作
1. **添加连线**：点击绿→紫→橙节点三步完成连线
2. **删除连线**：点击连线或标签，弹出确认面板删除
3. **新增系统**：底部输入框添加新应用系统
4. **导出数据**：输出 JSON 到控制台

### 键盘快捷键
- `Delete`：确认删除选中连线
- `Escape`：取消删除操作

## 技术实现
- 纯 HTML/CSS/JS，无外部依赖
- SVG 绘制连线，带箭头 marker
- 响应式滚动同步
