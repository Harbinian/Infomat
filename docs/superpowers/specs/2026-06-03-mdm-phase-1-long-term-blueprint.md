# MDM 一期长期蓝图

> 编制日期：2026-06-03
> 定位：MDM 一期升级后的长期建设路线输入。

## 1. 蓝图边界

本蓝图属于 MDM 一期交付物。它不要求一期完成 ERP、MES、OA、PLM 的全部联调，但要求在一期内明确主数据域、黄金源候选、接口路线、数据质量机制和后续里程碑。

当前真源仍保留在 `docs/norms/`、`docs/organization/组织架构和部门职责.md` 和 parser 生成的 `docs/company-sankey-data.json`。MDM 在一期内先承接只读快照、字段台账关联和校验能力，不抢跑替代 PMO 静态驾驶舱。

## 2. 候选主数据域

| 主数据域 | 当前依据 | 一期处理 |
|---|---|---|
| 组织 | `docs/organization/组织架构和部门职责.md` | 对齐流程治理部门和管理域 |
| 人员 | `docs/organization/花名册.md` | 保持平台用户与组织维表关系 |
| 岗位 | 组织职责、花名册 | 作为人员、权限、数据 owner 的辅助维度 |
| 物料 | `docs/主数据编码规范.md`、`docs/U8编码规则汇总.md` | 建立编码规则、字段台账和系统间字段对照 |
| 供应商 | 经营发展部、物资保障部流程 | 建立字段台账和黄金源候选 |
| 客户 | 经营发展部流程 | 建立合同、订单和交付相关字段候选 |
| 项目 | 项目管理部流程 | 关联计划、风险、交付、成本流程 |
| 产品 | MDM 平台产品主数据模块 | 保留产品族、产品和分类节点能力 |
| 工装 | 项目管理部、物资保障部流程 | 识别工装台账、状态流转和字段候选 |
| 设备 | 运维安环部流程 | 识别设备台账、备件、维修字段候选 |
| 质量记录 | 质量管理部流程 | 识别检验、不合格、归零和交付文件字段候选 |

## 3. 黄金源候选路线

| 数据对象 | 候选来源 | 候选消费 | 一期动作 |
|---|---|---|---|
| 组织与人员 | MDM 平台、花名册 | OA、ERP、MES、PLM | 先在 MDM 内治理口径 |
| 物料 | PLM、ERP | ERP、MES、PLM | 建立字段台账和编码规则对照 |
| 供应商 | ERP、采购流程资料 | ERP、OA、MDM | 识别供应商编码、资质、状态字段 |
| 客户 | 合同与订单流程资料 | ERP、OA、MDM | 识别客户编码、合同、订单字段 |
| 项目 | 项目管理流程、ERP | ERP、MES、OA | 识别项目编号、计划、成本字段 |
| 工装 | PLM、ERP、MES | PLM、ERP、MES | 识别工装台账和状态流转字段 |
| 设备 | MES、ERP | MES、ERP | 识别设备台账、备件、维修字段 |
| 质量记录 | MES、PLM、OA | MES、PLM、OA | 识别质量记录、检验、不合格字段 |

黄金源结论必须通过字段台账与数据 owner 确认。流程中的“建议落位应用”只表达流程执行或数据记录建议，不能自动认定为黄金源。

## 4. 接口路线

一期只形成接口候选清单和字段依据：

| 接口方向 | 业务依据 | 后续关注 |
|---|---|---|
| MDM -> OA | 组织、人员、角色、流程待办 | 权限同步、统一待办、审批状态 |
| MDM -> ERP | 组织、物料、供应商、项目、成本字段 | 编码一致性、主数据分发、变更审计 |
| MDM -> MES | 物料、工装、设备、质量记录 | 生产执行数据一致性、状态同步 |
| MDM -> PLM | 物料、BOM、工艺、工装 | 设计制造数据一致性、版本关系 |
| MDM -> 集成总线 | 主数据分发与变更事件 | 事件模型、幂等、审计和重放 |

接口清单必须从流程、A1、字段台账和数据质量问题中反推，不直接用系统名称替代业务场景判断。

## 5. 数据质量机制

一期建立以下机制：

- 字段台账标准化：中文名、英文名、数据对象、类型、同步方式。
- 术语冲突识别：同名异义、近似术语、禁用词。
- 黄金源冲突识别：同一字段多个权威系统候选不一致。
- 流程上下文关联：字段可以引用 L3 或 A1。
- 快照一致性校验：MDM 快照与 `docs/company-sankey-data.json` 统计一致。
- 跨部门交互检查：记录输入来源、输出目标、确认状态和风险等级。

## 6. 后续里程碑

| 里程碑 | 通过条件 |
|---|---|
| M1 平台安全升级 | 测试库隔离，现有路由测试可安全运行 |
| M2 流程治理快照 | MDM 可导入当前流程治理 JSON，并通过一致性校验 |
| M3 A1 与跨部门视图 | 平台内可查询 A1、跨部门风险、交互链 |
| M4 字段台账衔接 | 字段台账可关联 L3/A1 |
| M5 蓝图评审 | 主数据域、黄金源候选、接口路线和数据质量机制完成评审 |

## 7. 一期验收口径

- PMO 静态驾驶舱继续读取 parser 产物，不切换到登录态 MDM API。
- MDM 只读 API 可返回与当前快照兼容的流程治理数据。
- 字段台账可以保留流程治理节点和 A1 编号。
- 黄金源确认仍走字段治理逻辑，不由流程建议自动推出。
- 后续建设路线以主数据域、接口候选和数据质量机制为主线。
