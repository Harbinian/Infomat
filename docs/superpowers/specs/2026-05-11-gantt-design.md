# 总体排期甘特图独立网页设计

## 概述
将 `信息化系统应用与集成说明会.html` 中第4节的甘特图提取为独立单文件网页，直接用浏览器打开即可运行，无构建步骤。

## 技术方案
- **文件形式**：单一 `gantt.html`，包含内嵌 CSS + JS
- **渲染方式**：直接复用现有甘特图 CSS 样式和 JS 渲染逻辑
- **数据来源**：JS 内嵌任务数据（不变动内容）
- **外部依赖**：无（纯原生 HTML/CSS/JS）

## 页面结构
```
gantt.html
├── 页面标题：昌兴复材数字化项目实施甘特图（2026.05 - 2026.12）
├── 头部说明区
├── 甘特图内容区（分组标签 + 时间轴 + 任务行 + 条形图 + 里程碑线）
└── 图例区
```

## 关键要素
- 5个分组：数据标准、MDM底座、PLM建设、MES建设、联调验收
- 约40条任务行，含子泳道（主数据、工艺、仓储）
- 4个里程碑节点
- 8个月时间轴（2026年5月-12月）
- 颜色编码和图例
