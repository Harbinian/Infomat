### 第1章：系统全景（4页，每系统一页）

#### 1.1 ERP（用友U8）

**页面布局**：
- 左侧：系统名称 + 供应商标签
- 中央：功能模块矩阵（PS/FI/CO/PP/MM/SD）
- 右侧：核心定位一句话 + 主要用户部门

**内容**：
```
定位：企业资源计划核心层
一句话：管"资源怎么计划、成本怎么核算"

功能模块：
├── PS（项目主线）  ← 项目管理部主导
├── FI（财务核算）  ← 财务部主导
├── CO（成本归集）  ← 财务部主导
├── PP（生产计划）  ← 项目管理部/复材车间主导
├── MM（采购管理）  ← 物资保障部主导
└── SD（销售管理）  ← 经营发展部主导

协作关系：
- ⇄ MES（生产订单、工时回传）
- → SCIM（采购订单下达）
- → OA（审批流对接）
- ⇄ 数据中台（主数据同步）
```

---

#### 1.2 OA（华天动力）

**内容**：
```
定位：流程协同层
一句话：管"审批怎么流转、协同怎么做"

核心功能：
├── 合同管理    ← 合同线上审批
├── 项目管理    ← 项目立项审批、里程碑节点
├── 采购管理    ← 采购申请 → 生成订单
├── 公文管理    ← ECO变更会签
└── 费控管理    ← 费用报销 → 财务凭证

协作关系：
- → ERP（审批单据同步）
- → PLM（ECO变更审批）
- → MES（工艺变更通知）
- → 全系统（单点登录统一入口）
```

---

#### 1.3 PLM（翎瑞鸿翔）

**内容**：
```
定位：产品全生命周期管理
一句话：管"产品是什么、怎么定义"
一期范围：MBOM / ECO / 工程项目管理

核心功能：
├── 需求管理    ← 研发需求分解
├── EBOM管理    ← 工程BOM结构（铺层顺序、材料规范）
├── ECO变更     ← 设计变更单（工程变更审批）
├── MBD模型     ← 三维模型含PMI标注
└── 文档受控    ← 设计资源归档

协作关系：
- → PDM（EBOM受控发布）
- → OA（ECO变更审批）
- → CAPP（MBD模型传递）
- → ERP-PP（MBOM下达）
```

---

#### 1.4 MES（北京虎蜥）

**内容**：
```
定位：制造执行层
一句话：管"车间怎么执行、过程怎么管控"

核心功能：
├── 排产管理    ← 工装/工具/夹具资源
├── 工艺管理    ← 工艺规程执行
├── 生产执行    ← 工序报工
├── 工时管理    ← 实际工时采集
└── IoT采集     ← 设备数据采集

协作关系：
- ⇄ ERP-PP（生产订单下达、完工反馈）
- ⇄ ERP-CO（工时成本回传）
- ← CAPP（MBOM、工艺规范接收）
- → WMS（领料出库、批次追溯）
```

       →   合同签订          →   OA + 合同系统
       →   采购订单下达      →   ERP-MM
       →   仓储收货         →   WMS
       →   领料出库         →   MES
```

#### 3.3 制造域

**映射关系**：
```
业务能力          L3流程              应用系统

#### 3.4 质量域（横向贯穿）

**映射关系**：
```
研发阶段        采购阶段        制造阶段        交付阶段

    ↓            ↓              ↓              ↓
  PDM受控 ←── 统一质量数据 ──→ ERP-CO
```

### 第4章：MDM主数据治理

#### 4.1 编码规范

**结构**（13位，含连字符）：
```
XX  -  XXX  -  00000
大类   小类    流水号
```

**12类分类码**（表格展示）：
| 分类码 | 名称 | 黄金源 |
|--------|------|--------|
| CF | 碳纤维复合材料件 | PLM |
| GF | 玻璃纤维复合材料件 | PLM |
| ME | 金属件/机加件 | PLM |
| PM | 预浸料/基体材料 | ERP-MM |
| ... | ... | ... |

---

#### 4.2 黄金源确认表

**核心原则**：一数据一黄金源，其他系统只读

| 数据域 | 数据项 | 黄金源 | 备注 |
|--------|--------|--------|------|
| 物料主数据 | 物料编码、名称、规格 | PLM / ERP-MM | 按物料类型分 |
| EBOM结构 | 铺层顺序、材料规范 | PLM | — |
| MBOM结构 | 工序分工、工装、定额 | CAPP | Q6待决 |
| 工艺规范 | 固化曲线、NDT规范 | CAPP/PDM | — |
| 供应商信息 | 供应商编码、ASL | ERP-MM | — |
| 生产订单 | 订单号、计划数量 | ERP-PP | — |
| 工时数据 | 实际工时、报工记录 | MES | — |
| 质量记录 | NDT报告、检验结果 | MES/质量系统 | — |

---

#### 4.3 适航追溯链

**序列号级追溯链路**（可视化）：
```
原材料批次（预浸料）
    ↓ 批次号 + 有效期
铺层工序（MES）
    ↓ 铺层顺序 + 操作员 + 环境温湿度
热压罐固化（MES + IoT）
    ↓ 固化曲线（温度/压力/时间）
NDT检测（质量系统）
    ↓ 超声C扫 + 孔隙率
最终检验（质量系统）
    ↓ 合格判定 + 检验员
交付构型（PDM/SBOM）
    ↓ 件号 + 序列号 + 偏离记录
主机厂交付
    ↓ SoC + FAI报告
```

## 六、技术实现

### 6.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 结构 | HTML5 + CSS3 | 语义化标签 |
| 样式 | Tailwind CSS | 通过CDN引入，自定义主题色板 |
| 交互 | Vanilla JS | 无需框架，轻量运行 |
| 图表 | SVG | 拓扑图、追溯链 |
| 字体 | system sans-serif | 避免加载时间 |

### 6.2 文件结构

```
index.html          # 主入口（重构）
├── Tailwind CSS    # CDN引入
├── 内联 JS         # 所有交互逻辑内联
└── SVG 图标        # 内联SVG，无外部图片
```

### 6.3 响应式策略

| 断点 | 适配 |
|------|------|
| ≥1200px | 最佳阅读宽度1200px，居中 |
| 768-1199px | 全宽显示，适当缩小字号 |
| <768px | 提示"建议PC端查看"，或简化布局 |
