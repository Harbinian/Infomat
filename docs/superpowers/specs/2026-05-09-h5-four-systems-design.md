# H5 仅保留四大系统 — 设计规格

**日期**：2026-05-09
**状态**：已确认

---

## 目标

将 `系统集成说明H5（完整版）.html` 的讲解范围从 8 套系统收敛至 **OA / ERP / PLM / MES**，桑基图终端节点中非四大系统一律指向 MES，拓扑图不受影响。

---

## 规则定义

### 四大系统
- OA（办公自动化）
- ERP（企业资源计划）
- PLM（产品全生命周期管理）
- MES（制造执行系统）

### 桑基图终端节点路由规则

| 节点类型 | 处理方式 |
|----------|----------|
| 四大独立节点 | 保留（OA / ERP / PLM / MES） |
| 非四大独立节点（WMS / QMS / CAPP / 供应链管理系统 / 能源管理系统 / 工装工具管理系统 / PDM） | 路由至 MES |
| 复合节点 `ERP+MES` / `PLM+MES` | 保留（组成全属四大） |
| 复合节点含非四大（`ERP+APS` / `ERP+PDM` / `CAPP+MES` / `MRP+MES`） | 路由至 MES |

### D2 工装管理特殊规则

工装业务以**验收**为分界点：

| 节点 | 路由终点 | 说明 |
|------|----------|------|
| 工装工具策划(PLM) | PLM | 设计环节 |
| 工装申请管理(PLM) | PLM | 设计环节 |
| 工具申请(PLM) | PLM | 设计环节 |
| 工装设计与更改 | PLM | 设计环节 |
| 专用工具设计与更改 | PLM | 设计环节 |
| 工艺装备验收 | PLM | 验收属于设计环节 |
| 工装验证 | MES | 验收后验证 |
| 工艺装备使用 | MES | 验收后使用 |
| 工艺装备返工 | MES | 验收后维护 |
| 工艺装备维护 | MES | 验收后维护 |
| 工艺装备定检 | MES | 验收后定检 |
| 工装优化 | **PLM+MES** | 跨越设计与执行两端 |
| 工具验证 | MES | 验收后验证 |
| 工具试用与选型 | MES | 验收后选型 |
| 工装工具管理系统 | MES | 运营管理系统 |
