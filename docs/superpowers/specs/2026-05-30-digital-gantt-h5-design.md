# 数字化底座项目 H5 甘特图设计

## 概述

基于 `pmo/信息化项目.csv`（313 行任务数据）制作可交互 H5 甘特图页面，用于项目管理、领导汇报和进度跟踪。

## 技术方案

**纯静态 HTML + CSS + JS**，单文件 `index.html` 内嵌全部逻辑，通过 `fetch` 读取 `tasks.json`。无框架、无构建步骤、无 CDN 依赖。

文件结构：
```
digital-gantt-h5/
├── index.html          # 单文件完整应用（内嵌 CSS + JS）
├── tasks.json          # CSV 转换后的任务数据
├── convert.js          # CSV → JSON 转换脚本
└── README.md           # 使用说明
```

## 数据流

```
信息化项目.csv → convert.js → tasks.json → fetch → 内存筛选/排序 → Canvas 渲染
```

## 组件架构

所有组件在一个 HTML 文件内用 JS 动态生成：

| 组件 | 实现方式 | 职责 |
|------|----------|------|
| DashboardCards | DOM 生成 | 顶部 7 个指标卡片 |
| FilterBar | DOM + 事件 | 筛选器 + 搜索框 + 视图切换按钮 |
| TaskTree | DOM + 虚拟滚动 | 左侧固定列 WBS 树，展开/折叠 |
| GanttChart | Canvas 2D | 时间轴、任务条、里程碑菱形、今日线 |
| TaskDetail | DOM 滑出面板 | 右侧详情面板 |
| MilestoneList | DOM 列表 | 底部关键里程碑汇总 |

## 甘特图渲染方案

- **Canvas 2D** 绘制甘特条（比 DOM 方案性能好，比 SVG 灵活）
- 左侧任务列固定 ~340px，右侧 Canvas 横向滚动
- 顶部月轴在 Canvas 内绘制，随横向滚动同步
- 里程碑（工期=0）用菱形绘制
- 高风险任务条加红色边框/条纹
- 今日线为红色竖线贯穿

## 视觉风格

深色科技风：`#1a1d2e` 背景，`#252838` 卡片，白色文字，避免花哨。

## 功能清单

1. Canvas 甘特图横向时间轴（2026-06 ~ 2028-01，按月分列）
2. WBS 层级树（展开/折叠，一二级默认展开）
3. 7 个筛选器：年份、主线、部门、供应商、风险、类型、里程碑
4. 里程碑突出显示（菱形）
5. 今日红色竖线
6. 任务详情侧边栏
7. 搜索框
8. 6 个预设视图：总览/2026/2027/2028/里程碑/高风险
9. 7 个统计指标卡片
10. 关键里程碑清单
11. Canvas 悬停检测 + tooltip
12. 缓冲任务特殊样式

## 日期兼容

兼容 `2026-06-01`、`2026/6/1`、`2026年6月1日` 三种格式，空日期任务仅显示在任务树。

## 质量要求

- 无控制台报错
- 中文正常显示
- 横向滚动可用
- 左侧固定列 + 顶部固定月轴
- 筛选后指标同步更新
- 点击任务打开详情
- CSV→JSON 转换脚本可复用

## 输出

`digital-gantt-h5/` 目录，`python -m http.server 8080` 或直接浏览器打开 `index.html` 即可运行。
