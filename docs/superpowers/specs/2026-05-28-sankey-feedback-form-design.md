# 桑基图反馈表单设计

## 概述

为各部门桑基图 HTML 嵌入 A1 业务行为反馈表单，让部门人员以选择题方式逐条确认映射关系的准确性，无需思考、无需写字，填完导出 JSON 发回。

## 范围

- V1 范围：生成脚本 + 反馈表单 + 进度条 + 导出 JSON + 使用说明
- V1 不做：回写脚本、在线提交、MDM 平台集成
- 试点部门：财务部（83 条 A1），验证后扩展到其他五个部门

## 反馈卡片设计

点击桑基图中 A1 节点 → 右侧滑出反馈卡片，包含：

1. **整体确认**（必选）：本行 A1 描述是否准确？
   - A) 准确，无需修改
   - B) 基本准确，有小问题
   - C) 不准确，需要重写

2. **执行角色确认**（必选，预填当前值）：这个角色描述对吗？
   - A) 正确 / B) 不对 / C) 不清楚

3. **审批类型确认**（必选，预填当前值）：审批类型对吗？
   - A) 正确 / B) 不对 / C) 不清楚

4. **输入输出部门确认**（必选，预填当前值）：输入来源部门和输出目标部门对吗？
   - A) 正确 / B) 不对 / C) 不清楚

5. **核验提醒回应**（仅当有核验提醒时显示，预填提醒内容）：这个提醒你有反馈吗？
   - A) 同意，需要细化 / B) 不同意，当前描述足够 / C) 不适用

6. **备注**（条件显示：仅当任一题选"有问题"时出现）：自由文本，一行即可

## 交互设计

- 点击桑基图 A1 节点 → 右侧滑出反馈卡片（position: fixed 侧边栏）
- 卡片底部有"确认本条"按钮
- 确认后：节点变色（绿=准确 / 黄=小问题 / 红=不准确）
- 页面顶部显示进度条：`已完成 N / 83`
- 表格区域改为"反馈总览"：只显示已填/待填行数，不展示原始 22 列
- 点击"导出反馈"按钮 → 浏览器下载 `财务部-反馈-2026-05-28.json`

## JSON 导出格式

```json
{
  "department": "财务部",
  "exported_at": "2026-05-28T15:30:00",
  "feedback": [
    {
      "a1_id": "CW-L3-01-A1-003",
      "row_confirmed": "accurate",
      "role_confirmed": "correct",
      "approval_confirmed": "correct",
      "io_dept_confirmed": "correct",
      "verification_response": "agree",
      "notes": ""
    }
  ]
}
```

## 生成脚本

`scripts/build-feedback-sankey.mjs`：

1. 读取 `{部门}部门-能力-流程-系统映射关系.md`
2. 解析 A1 主记录表，提取每行的 A1编号、业务行为、执行角色、审批类型、输入来源部门、输出目标部门、核验提醒
3. 将 A1 数据注入到 HTML 模板中（替代现有硬编码数据）
4. 同时注入反馈表单的 HTML/CSS/JS
5. 输出 `{部门}部门能力流程系统桑基图.html`（覆盖现有版本）

## 验收标准

1. 打开财务部桑基图 HTML，点击 A1 节点弹出反馈卡片，5 道选择题可点选
2. 选"有问题"时出现备注框
3. 顶部显示进度条 `已完成 N / 83`
4. 已填节点变色，未填保持原色
5. 点击导出 → 下载 JSON，A1 编号与映射 MD 一致
6. 页面内置使用说明，部门无需额外文档即可操作
