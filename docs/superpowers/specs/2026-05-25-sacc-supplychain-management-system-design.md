# 沈飞民机供应链信息化协同平台管理制度 — 设计说明

## 背景

昌兴复材作为沈飞民机供应商，通过沈飞民机供应链信息化协同平台（https://sacc-supplychain.avicnet.cn/）进行业务交互。当前两部门（经营发展部、项目管理部）在平台上存在职责边界模糊、操作时限缺失的问题，需出台正式管理制度。

## 文档定位

混合型：前半部分正式制度文本（章/条/款，满足合规留痕），后半部分操作细则 + 流程表格（满足日常执行和新人培训）。

## 章节结构

1. **目的** — 规范平台操作行为，明确职责与协作边界，确保报价→订单→交付→结算全链路受控
2. **范围** — 适用部门（经营发展部、项目管理部）及人员，覆盖端到端流程
3. **术语和定义** — 平台地址、订单流水号、派工号、质量编号、U8系统、零件交付计划调整等
4. **职责和权限** — 6类岗位职责 + 平台功能权限矩阵
5. **工作程序** — 按业务流程分节，每节含执行岗位、具体动作、输出物、验收标准、时限
6. **相关流程** — 跨部门协作流程图（泳道图文字描述 + RACI 表）
7. **引用文件** — 平台使用说明手册、内部相关制度
8. **记录表格** — 5份表单登记（均标注"后补"）
9. **附录** — 平台功能与部门对应矩阵表

## 部门分工

### 经营发展部
| 岗位 | 职责 |
|------|------|
| 室主任 | 组织报价、盖章、上传报价单（经审批后）；结算核对；审核零件交付计划调整报告后上传 |
| 计划员 | 接收订单、转化U8下单；可在审批后代理上传报价单 |
| 部长/经营副总 | 审批报价单、审批结算核对结果 |

### 项目管理部
| 岗位 | 职责 |
|------|------|
| 部长 | 审核生产状态录入并执行交付确认 |
| 部长助理 | 按实际交付内容起草生产状态录入 |
| 项目助理/计划员 | 发起零件交付计划调整报告；执行生产过程管理（生成数据&质量编号、分卡）、打印封面及合格证、生产状态录入（批量导入）、反馈问题管理、产品交付清单管理 |

## 时限规则

| 环节 | 时限 | 执行人 |
|------|------|--------|
| 报价（询价→审批→盖章→上传） | 3 工作日 | 室主任/计划员 + 部长/经营副总 |
| 订单接收→U8下单 | 1 工作日 | 计划员 |
| 零件交付计划调整报告 | 1 工作日 | 项目助理发起 → 室主任审核上传 |
| 结算核对反馈 | 3 工作日 | 室主任核对 → 部长/经营副总审批 |
| 产品交付确认 | 1 工作日 | 项目管理部部长 |

## 审批链路

- **报价**：室主任/计划员起草 → 部长/经营副总审批 → 室主任盖章上传
- **结算**：室主任核对 → 部长/经营副总审批 → 反馈沈飞
- **生产交付**：部长助理起草生产状态 → 部长审核 → 部长交付确认
- **交付计划调整**：项目管理部发起 → 经营发展部室主任审核 → 上传平台
