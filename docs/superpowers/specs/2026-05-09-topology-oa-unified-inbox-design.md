# 拓扑图OA统一待办入口交互设计

**日期：** 2026-05-09
**状态：** 已确认

---

## 背景

用户要求在拓扑图中表达：
- OA通过二次开发实现所有审批流统一入口
- 直接执行、跳转入口、抓待办提醒三种模式按需分级
- PLM/ERP/MES虽有内部审批流，但用户不希望在多系统中找待办

---

## 改动范围

**修改文件：** `docs/Demo/系统集成说明H5（完整版）.html`

**不涉及：** 其他桑基图、H5子页面、后端接口

---

## 交互设计

### 1. OA卡片标注升级

在OA系统卡片上增加**"统一待办入口"**标签：
- 橙色高亮文字（与OA连线颜色一致）
- 悬停时显示简要说明

### 2. 点击弹窗机制

**触发方式：** 点击任意系统卡片

**弹窗内容：** 模态框显示该系统的审批流处理策略

### 3. 各系统弹窗内容

| 系统 | 审批流策略 |
|------|-----------|
| OA | 统一待办入口（直接执行 / 跳转执行 / 抓提醒，按需分级） |
| PLM | 审批流在PLM内，OA拉取待办摘要后跳转或抓提醒 |
| ERP | 同上 |
| MES | 同上 |
| PDM | 含于PLM口径，受控BOM/版本/发布审批在PLM内 |
| CAPP | 待供应商确认 |
| WMS | 待供应商确认 |
| 供应链管理平台 | 自研或采购待决 |

### 4. 技术实现

- **纯前端：** HTML + CSS + JavaScript，无外部依赖
- **模态框：** 点击卡片显示，点击遮罩或关闭按钮消失
- **悬停提示：** CSS `:hover` 实现，无JS依赖
- **响应式：** 模态框居中，适应不同屏幕

---

## 验收标准

1. OA卡片上有"统一待办入口"标签
2. 点击OA卡片，弹窗显示三种处理模式说明
3. 点击其他系统卡片，弹窗显示各自审批流策略
4. 弹窗可关闭
5. 不影响现有拓扑图布局和连线
