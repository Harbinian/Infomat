# MDM 平台使用说明

## 1. 系统概述

MDM（Master Data Management）平台是航空复材制造领域的业务关系映射与主数据管理工具集，提供从业务能力申报、流程映射、字段台账到主数据全生命周期管理的一站式解决方案。

- **访问地址**: `http://localhost:3000`
- **技术基础**: Express.js + SQLite，浏览器原生前端

## 3. 功能模块

### 3.1 统计看板

系统首页的仪表盘视图，提供以下概览指标：

- **流程映射**: 系统中已录入的业务流程→系统映射总数
- **字段台账**: 已登记的字段条目总数
- **待处理待办**: 当前跨部门待办事项数量
- **未解决冲突**: 尚未解决的字段/术语冲突数

下方展示「各部门流程数」柱状图和「审批状态分布」饼图，便于快速了解整体业务状况。

---

### 3.2 报送管理

查看个人或部门提交的全部流程映射报送记录。

**表格列**：ID、流程名称、所属部门、当前状态、提交时间、操作

**状态流转**：`草稿 → 已提交 → 部门审核通过 → 跨部门确认 → 字段确认 → 终审通过 → 已发布`

点击「查看」按钮可进入单条报送的详情页，查看完整审批历史和关联的字段台账。

---

### 3.3 能力与流程申报

#### 申报业务能力

填写表单创建新的业务能力条目：

| 字段 | 说明 |
|------|------|
| 能力名称 | 业务的标准化能力描述 |
| 能力层级 | 能力域（L1）/ 业务能力（L2）/ 业务流程（L3）|
| 所属部门 | 该能力归属的组织部门 |

#### 申报业务流程

在已有业务能力下创建具体流程：

| 字段 | 说明 |
|------|------|
| 流程名称 | 流程的描述性名称 |
| 所属能力 | 从已申报的业务能力中选择 |

---

### 3.4 业务地图

以桑基图（Sankey）形式可视化展示 **部门（D1）→ 能力域（L1）→ 业务能力（L2）→ 业务流程（L3）→ 应用系统（S1）** 之间的关系链路，支持交互式筛选和钻取。

---

### 3.5 待办收到

展示分配给当前用户的跨部门待办事项列表。每条待办关联到具体的流程映射，可在此完成审核、确认等操作。

---

### 3.6 评审记录

查看所有已完成和进行中的审批记录，每个审批步骤的决策（通过/驳回/退回修改）和时间戳均有完整审计轨迹。

---

### 3.7 术语词典

管理业务术语的标准化定义。支持：

- 添加、编辑、删除术语条目
- 术语审核流（提交→审核→发布）
- 版本历史追溯

---

### 3.8 冲突管理

自动检测跨部门间的字段定义冲突和术语不一致问题。列表展示冲突类型、涉及部门、冲突详情，支持在线协调和标记解决。

---

### 3.9 主数据台账（MDM 核心模块）

主数据条目的统一管理入口，提供完整的 CRUD 功能。

**筛选条件**：

| 筛选项 | 可选值 |
|--------|--------|
| 分类 | 全部 / 零组件 / 工艺组件 / 工装 / 原材料 / 设备 / 工具 |
| 状态 | 全部 / 新增 / 审核中 / 生效 / 变更中 / 停用 / 归档 |
| 搜索 | 按编码或名称模糊搜索 |

**操作按钮**：

| 按钮 | 功能 |
|------|------|
| 查询 | 应用筛选条件刷新列表 |
| + 新增条目 | 弹出表单手动添加主数据条目 |
| Excel 导入 | 批量上传 Excel 文件导入主数据 |

**编码规则引擎**：新增条目时系统自动生成符合规则的物料编码，无需手动输入。

---

### 3.10 主数据审批（生命周期管理）

管理主数据变更的完整审批流程。支持 **7 种生命周期状态**：

```
新增 → 审核中 → 生效 → 变更中 → 停用 → 归档
         ↑         ↓
         └── 审核驳回
```

**审批列表列**：变更ID、物料编码、物料名称、变更类型、变更摘要、申请人、审批进度、状态、操作

支持**多级会签审批**，每个审批节点可配置审批人。

---

### 3.11 数据质量

数据质量 KPI 仪表盘，包括四大核心指标：

| 指标 | 说明 | 目标 |
|------|------|:--:|
| 完整率 | 必填字段的填写率 | 100% |
| 唯一率 | 编码/名称无重复的比例 | 100% |
| 及时率 | 按时完成的数据更新比例 | ≥95% |
| 消费一致率 | 下游系统数据一致性 | 100% |

**黄金源确认进度**：按数据域（固化工艺、工艺资源、工艺路线、物料主数据等）展示字段黄金源的确认比例，逐域追踪数据治理进度。

## 4. 审批流程

### 4.1 流程映射审批

```
用户提交 → 部门审核 → 跨部门确认 → 字段台账确认 → 终审 → 发布
```

每个步骤生成对应的审批任务（`approval_tasks`），审批历史完整记录到 `approval_history`。

### 4.2 主数据变更审批

```
提交变更申请 → 部门负责人审核 → 数据管理员复核 → 变更生效/驳回
```

## 5. 数据导入导出

### 5.1 Excel 导入

主数据台账页面支持 Excel 批量导入。点击「Excel 导入」按钮，选择文件上传。系统自动校验格式和必填项，导入结果含成功/失败明细。

### 5.2 Excel 导出

支持导出以下内容为 Excel：
- 字段台账
- 黄金源矩阵
- 冲突清单

## 6. 集成接口（API）

系统提供 RESTful API 供外部系统集成，支持：

- **API Key 认证**：外部系统通过 API Key 鉴权访问
- **增量同步**：按时间戳增量拉取主数据变更
- **旧编码映射**：`old_new_code_mapping` 表维护历史编码对应关系
- **一致性校验回调**：下游系统可回调确认数据一致性

详细的 API 文档参见各路由模块的源码注释。

## 7. 常用命令速查

```bash
cd apps/mdm-platform

# 启动服务
npm start              # Express，端口 3000
npm run dev            # 开发模式（nodemon 自动重启）

# MySQL结构初始化
npm run init:mysql     # 初始化或升级MySQL结构

# 冒烟测试
npm run smoke          # 基础冒烟
node scripts/smoke-master-data.js    # 主数据模块
node scripts/smoke-integration.js    # 集成接口

# 路由专项测试
npm test:org npm test:catalog npm test:mappings
npm test:conflicts npm test:terms
npm test:export npm test:import
npm test:frontend
```

正式运行和流程治理同步使用MySQL。`npm run legacy-sqlite:init-db`只用于遗留迁移或隔离测试，不得作为正式初始化命令。执行前必须设置`MDM_ALLOW_LEGACY_TEST_MODE=1`，并通过`MDM_DB_PATH`指定非共享隔离库；脚本拒绝写入默认共享`data/platform.db`。
