## 映射关系层级结构说明

桑基图采用 4 层结构，从左到右依次为：

```
[部门/角色] ──→ [业务能力] ──→ [业务流程] ──→ [应用系统]
   Layer 1        Layer 2        Layer 3        Layer 4
```

### 部门/角色层（Layer 1）
- 单一部门：如"工程技术部""质量管理部""复材车间"
- 跨部门组合：以 `+` 连接，如"项目+物保""工技+物保+质量+运维"，表示联合牵头或协同负责

### 业务能力层（Layer 2）
- 按业务域聚合，如"工艺生产过程管控""质量执行""计划与排程"
- value 数值表示该能力下涵盖的流程条目规模

### 业务流程层（Layer 3）
- 具体可执行的操作流程，如"首件检验""MBOM编制""工装定检"
- 部分节点有 `(PLM)` 后缀，表示该节点为 PLM 侧记录

### 应用系统层（Layer 4）
- **PLM**: 产品生命周期管理（含 PDM、CAPP 能力）
- **MES**: 制造执行系统
- **ERP**: 用友 U8（计划、采购、库存、财务、成本）
- **PLM+MES**: 跨系统协同节点

## 跨部门协同模式

### D2 工装管理的典型跨部门链路

```
工装策划与申请       ← 工程技术部（主导）
工装设计与制造       ← 工程技术部（主导）
工装使用与维护       ← 复材车间 + 物资保障部 + 质量 + 运维安环 + 项目（5方参与）
工装验证与优化       ← 质量管理部 + 工程技术部 + 复材车间
```

### D3 物资保障的联合牵头

```
仓储与物流协同       ← 物资保障部 + 项目管理部（联合）
计划与排程           ← 项目管理部（主导）
生产执行             ← 项目管理部 + 复材车间（联合）
```
