# ADR-0001: 仓库结构与生成物策略

## 状态

Accepted

## 背景

Infomat 同时包含资料、工具脚本、可运行应用与大量可再生成输出。若不明确目录职责与生成物策略，维护者需要在大量无关文件中定位信息，降低可维护性并增加误提交风险。

## 决策

1. 可运行应用统一放在 `apps/`。
2. 业务资料与说明文档统一放在 `docs/`。
3. 所有可再生成输出统一视为“生成物（Artifact）”，不得提交到仓库。
4. 仅保留必要样例到 `docs/samples/`，用于：
   - 输入输出格式示例
   - 最小复现与对齐
   - 关键契约的示范数据

## 影响

- 目录职责清晰，变更更集中（locality 提升）
- 生成物不进入主干，索引与检索噪音降低
- 样例集中管理，便于对齐与复现
