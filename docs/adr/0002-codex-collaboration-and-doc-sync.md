# ADR-0002: Codex 协作入口与代码文档同步

## 状态

Accepted

## 背景

仓库已长期使用 Agent 辅助维护流程地图、数据地图、PMO 展示和 MDM 承接能力。旧 AI 专用入口和当前 Codex 使用方式并存时，容易造成上下文加载顺序、目录规则和验证口径不一致。

同时，代码、脚本和启动命令变化后如果文档没有同步，后续维护者会按过期说明操作，增加排障成本。

## 决策

1. 当前 AI 协作入口统一为 `AGENTS.md`、`CODEX.md`、相关目录 `AGENTS.md` 和 `.agents/`。
2. 删除当前生效的旧 AI 专用入口和工作区配置。
3. 历史报告、历史计划和历史 specs 中的旧称只作为追溯记录，不作为当前执行入口。
4. 每次代码、脚本、接口、数据库结构、前端行为、启动命令或测试命令变化，必须同步检查并更新对应文档。
5. 如果确认无需文档更新，交付说明必须写明原因。

## 影响

- Codex 读取上下文时有单一路径，减少旧入口误导。
- 目录级维护规则统一使用 `AGENTS.md`。
- 代码和文档同步成为项目级硬规则。
- 历史材料保留追溯价值，但不覆盖当前边界文件。
