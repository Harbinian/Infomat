# ADR-0005：Codex 小入口、按需路由与上下文预算门禁

## 状态

Proposed

## 日期

2026-09-01

## 背景

Codex 从项目根目录向当前工作目录逐层合并 `AGENTS.md`。官方文档说明，项目指令默认受 `project_doc_max_bytes` 的 32 KiB 上限约束；累计达到上限后，Codex 停止继续加入文件。

改造前，根 `AGENTS.md` 为 18,721 UTF-8 字节，`apps/structured-output-service/AGENTS.md` 为 37,108 字节，根到 3001 的项目指令链合计 55,829 字节。3001 局部规则因此不能完整进入模型输入。根入口还复制了 PMO、MDM、3001、结构化助手和静态资产的详细规则，使普通任务承担无关上下文，并增加多处同步维护成本。

## 提议

在 ADR-0002 保留的 Codex 协作入口基础上，进一步明确自动加载 Interface 和按需 Implementation 的职责：

1. 根 `AGENTS.md` 只保留当前阶段、全仓硬规则、权威任务路由和状态表述底线。
2. 目录 `AGENTS.md` 只保留该目录不可违反的边界、禁止事项和专题路由。
3. `CODEX.md` 作为仓库变更任务的按需执行手册，不作为普通只读问答的固定前置。
4. README、PRD、Tech-Spec、接口和测试说明承载应用详细产品与技术规则，由局部入口按任务读取。
5. `DIRECTORY_OWNERSHIP.md` 的机器可读注册块是全部局部 `AGENTS.md` 的唯一清单。其他文件不得复制完整清单。
6. `MEMORY.md` 只记录当前运行基线和长期事实，不保存执行顺序或常用命令。
7. 运行状态、版本、端口、服务、数据库和 Git 状态必须实时核对，不写入自动加载入口。

## 预算门禁

仓库保持 Codex 默认 32 KiB 项目文档上限，不新增或提高 `project_doc_max_bytes`。仓库持续检查采用以下更严格门槛：

| 检查对象 | 上限 |
|---|---:|
| 根 `AGENTS.md` | 6,144 UTF-8 字节 |
| 3001 局部 `AGENTS.md` | 8,192 UTF-8 字节 |
| 任一已登记项目指令链 | 16,384 UTF-8 字节 |

固定检查入口为 `npm run test:codex-context`。检查器只读执行，检查字节预算、链路组成、局部入口登记、根入口应用细节泄漏和权威标记唯一性。长段完全重复和模糊相似内容只报告提示，不能自动删除规则。

## 规则迁移边界

- 删除重复正文前，必须确认责任主体、适用条件、处理对象、时序、输入输出、异常处理和验证要求均一致。
- 找不到唯一且语义完整承载位置的硬规则继续保留；不得为缩短文件删除安全、迁移、责任或验收边界。
- 历史 plans/specs/reports 只用于追溯。当前入口必须明确标出历史正文，历史内容不能覆盖当前结构规则、README、现有实现和当前测试。
- 新增或删除局部入口时，只更新 `DIRECTORY_OWNERSHIP.md` 的注册块，并同步相关目录 README 和上下文管理说明。

## 验证与接受条件

本提议的技术检查包括：

1. 运行上下文预算、注册和夹具测试。
2. 在根、3001、MDM、PMO 和流程资料代表目录运行 `codex debug prompt-input`，确认局部文件末尾可见且没有 Unicode 截断字符。
3. 使用相同模型、推理强度、提示和仓库状态执行代表任务 A/B；模型或 CLI 不满足固定条件时，必须记录未完成，不能换用其他模型代替。
4. 运行受影响的固定服务配置、流程治理主线和 3001 自动化回归。

静态和自动化检查通过只证明上下文架构及既有代码回归结果，不表示服务已经运行、页面已经人工验收或业务已经验收。

## 与现有 ADR 的关系

- 本提议细化 ADR-0002 的 Codex 协作入口职责，不修改 ADR-0002 的历史结论，也不退役 `CODEX.md`。
- 本提议不改变 ADR-0001 的仓库结构和生成物策略。A/B 输出、提示输入和临时日志继续进入被忽略的 `artifacts/`。
- ADR-0004 继续保持 `Proposed`；本提议不把受控派生消费文件例外写成已经接受。
- 本提议不改变 ADR-0003 的工作角色、岗位映射或流程绑定规则。

## 影响

- 普通任务自动加载的规则减少，局部任务可以完整取得根和目录硬规则。
- 详细规则集中到责任正确的文档，维护者只需在一个位置修改正文。
- 新增局部入口或扩大入口内容时，需要承担预算和注册检查成本。
- 本 ADR 仍为 `Proposed`。完成实施和自动化测试不表示架构评审已经接受。
