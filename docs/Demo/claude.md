# claude.md

本文件用于指导 Claude Code 在 `docs/Demo` 目录内维护演示材料，尤其是 `信息化系统应用与集成说明会.html`。

## 当前演示文件

- 主文件：`信息化系统应用与集成说明会.html`
- 页面标题口径：`信息化系统应用与集成说明会 · 昌兴复材`
- 会议日期：`2026-05-14`
- 定位：正式说明会材料。

## 业务背景

该页面面向沈阳昌兴复材航空科技有限责任公司 2026-05-14 召开的信息化系统应用与集成说明会。核心目标是围绕 ERP、OA、PLM、MES 四套一期系统，说明数字化建设目标、主数据治理、系统集成拓扑、关键接口、成熟度判断、组织分工和会后行动清单。

页面必须保持以下业务口径：

- 一期聚焦 `ERP / OA / PLM / MES`。
- `PLM` 使用泛称 `PLM供应商`，一期口径包含 `MBOM / ECO(ECN) / 工程项目管理 / 工艺路线与工艺规程管理`。
- `MES` 供应商未定，定位为制造执行层，不只是报工系统。
- `ERP` 为用友 U8，定位为计划、采购、库存账、财务和成本核心。
- `OA` 供应商未定，定位为流程协同层和统一待办入口。
- `WMS / 供应链管理系统` 是一期后远景规划项，不应写成一期承诺；PLM 一期可覆盖工艺路线与工艺规程管理。
- `PDM` 在当前口径中纳入 PLM 一期能力，不作为独立一期系统表达。
- `MDM` 是集成基石，组织身份先行，流程牵引，术语统一，字段落账，黄金源矩阵确认。
- `Q1-Q8` 按成熟度分类表达，未确认事项不要写成最终结论。

## 页面结构

主 HTML 是单文件页面，包含 CSS、HTML、SVG 和原生 JavaScript。主要章节如下：

1. 会议定位
2. 公司数字化目标
3. 我们有哪 4 套系统
4. 总体排期一览
5. 关键里程碑
6. 执行抓手（四张桑基图：部门→能力→流程→系统）
7. 系统集成拓扑 + 五条数据流
8. OA 是什么
9. PLM 是什么
10. MES 是什么
11. ERP 是什么
12. 其他系统（远景规划）
13. 主数据混乱事故链
14. MDM 是基石，不是可选项（含 MDM 建设路径阶段二至五）
15. 黄金源说明矩阵
16. 关键接口设计
17. Q1-Q8 成熟度总览
18. 组织分工确认
19. 会后行动清单
20. 附录：文档版本说明

修改导航、章节编号或锚点时，要同步更新顶部导航链接、章节 `id`、章节标题和相关跳转。

## 技术约束

- 不引入构建流程；该文件应继续能直接用浏览器打开。
- 继续使用原生 HTML/CSS/JavaScript，不引入前端框架。
- 桑基图使用本地 `echarts.min.js`，无需外部 CDN 依赖。
- 桑基图使用 ECharts 初始化，容器包括 `chart-d1`、`chart-d2`、`chart-d3`、`chart-d4`。
- 系统拓扑图含内嵌 SVG，部分系统矩形通过坐标绑定点击事件并打开详情弹窗。
- 修改拓扑 SVG 时，必须同步检查底部 `openTopoModal` 点击绑定逻辑，避免坐标失效。
- 不要把交互数据拆到外部文件，除非用户明确要求重构。

## 内容维护规则

- 保持中文正式汇报语气，适合企业内部说明会。
- 不把供应商未确认能力、接口字段、实施周期和系统边界写成最终决议。
- 与航空复材制造相关的内容要保留追溯、质量编号、适航、BOM、ECO、工艺、工装、批次等关键词。
- 时间和版本号如有变更，要同步封面、导航标识、页脚和附录版本说明。
- 涉及接口设计时，必须明确主写方、消费方、同步频率、异常处理、人工兜底和责任人。
- 涉及主数据时，优先说明黄金源、维护部门、审批部门、只读系统和字段台账。
- 涉及未决项时，用“待确认”“需补资料”“需供应商确认”等表述，不要模糊成已完成。

## 视觉与交互风格

- 页面是汇报型长页，不是营销页。
- 保持深蓝、绿色、紫色、青色等系统域配色的区分度。
- 卡片、表格、警示框和信息框已经形成统一视觉语言，新增内容优先复用现有 class。
- 新增表格需保证移动端可横向滚动，使用现有 `.tw` 容器。
- 新增重要风险用 `.alert`，待确认事项用 `.warn`，说明性内容用 `.info`，正向结论用 `.success`。
- 不要加入无业务意义的装饰图形或动画。

## 修改前检查

在编辑 `信息化系统应用与集成说明会.html` 前，先确认：

- 用户要改的是业务口径、页面结构、样式，还是交互脚本。
- 是否会影响 `信息化系统应用与集成说明会 / 2026-05-14` 会议口径。
- 是否会影响一期范围与远景规划的边界。
- 是否需要同步会后行动清单、Q1-Q8、黄金源矩阵或接口卡。

## 修改后验证

完成修改后至少检查：

- HTML 可以在浏览器中打开，页面不是空白。
- 顶部导航锚点能跳转到对应章节。
- ECharts 桑基图仍能渲染。
- 拓扑图系统点击弹窗仍能打开和关闭。
- 移动端宽度下表格、卡片、拓扑图和长文字不明显重叠。
- 封面、正文、附录和页脚的版本日期一致。
