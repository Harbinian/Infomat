# PLM供应商洽谈大纲

> 时间：2026-05-07  
> 背景：PLM 是研发域数据源头，直接影响 EBOM、MBD、ECO、物料主数据、构型管理和后续接口设计。此次洽谈目标不是泛泛了解产品，而是确认其是否能支撑昌兴复材航空复材制造场景下的集成方案。

---

## 一、洽谈目标

本次洽谈建议聚焦四个目标：

1. 确认 PLM 是否能支撑航空复材场景下的 EBOM、MBD、ECO、构型与版本管理。
2. 确认 PLM 与 PDM、CAPP、ERP、MES、OA、数据中台之间的接口能力和责任边界。
3. 获取供应商可提供的数据模型、字段清单、接口方式、实施交付物和典型案例资料。
4. 形成对 5月9日专题会 Q5、Q7 及接口设计的输入，避免后续接口设计返工。

---

## 二、建议参会人员

| 角色 | 建议参会原因 |
|---|---|
| 项目管理部 | 统筹 PLM 选型、接口边界和5月9日决策输入 |
| 工程技术部 | 确认 EBOM、ECO、MBD、物料版本、工程发布要求 |
| 质量管理部 | 确认 NDT规范、质量文件受控、适航追溯与构型记录 |
| 复材车间 | 确认 MBOM、工序、工艺路线、MES执行侧需求 |
| 物资保障部 | 确认设计数据如何驱动采购件、原材料、供应商协同 |
| 用友U8 / MES 接口代表 | 评估 PLM 数据如何下传 ERP、MES 或经中台同步 |
| PLM候选供应商 | 提供产品能力、接口资料、实施边界和案例 |

## 三、建议议程（120分钟）

| 时间 | 议题 | 目标 |
|---|---|---|
| 0-10min | 项目背景说明 | 说明昌兴复材业务场景、8套系统边界、5月9日专题会目标 |
| 10-25min | 供应商方案总览 | 供应商介绍 PLM 产品定位、模块范围、航空/复材相关能力 |
| 25-45min | EBOM / MBD / 工程发布能力 | 确认 EBOM结构、铺层顺序、材料规范、固化规范、NDT规范、MBD模型和虚拟件标记如何管理 |
| 45-60min | ECO / 版本 / 构型管理 | 确认 ECO流程、版本生效、旧版本保留、构型状态、偏离/超差记录如何实现 |
| 60-80min | 下游集成接口 | 确认 PLM→PDM、PDM→CAPP、PLM/ERP/OA/MES/数据中台的可行接口方式 |
| 80-95min | 适航追溯与质量文件 | 确认 PLM/PDM中哪些数据可用于适航追溯、质量文件受控和长期归档 |
| 95-110min | 实施交付与边界 | 确认实施周期、需客户准备的数据、二开范围、接口开发责任、验收交付物 |
| 110-120min | 资料清单与会后动作 | 明确供应商需在会后提交的材料、样例、报价或二次演示安排 |

## 四、必须问清楚的问题

### 1. EBOM 与复材工程数据

| 问题 | 需要供应商回答 |
|---|---|
| EBOM 能否管理铺层顺序（Ply Stack-up）？ | 字段方式、结构方式、样例截图或数据样例 |
| 材料规范号、固化工艺规范、NDT检测规范如何挂接？ | 是物料属性、文档对象，还是工艺对象 |
| 虚拟件如何标记？ | 能否在发布到下游时过滤虚拟件 |
| 版次 REV 是否可作为独立字段管理？ | 是否支持旧版本保留和版本追溯 |
| 对外交付件号和内部物料编码能否分离？ | 是否支持映射表和多编码体系 |

### 2. MBD 能力

| 问题 | 需要供应商回答 |
|---|---|
| 是否支持 MBD 模型管理？ | 支持哪些格式、是否可管理 PMI 标注 |
| MBD 如何与 EBOM 关联？ | 模型、零件、BOM、版本之间的关系 |
| MBD 如何传给 CAPP 或三维工艺？ | 接口方式、格式、触发方式 |
| MBD 变更后如何触发 BOM 或工艺更新？ | 与 ECO 流程的关系 |

### 3. ECO 变更闭环

| 问题 | 需要供应商回答 |
|---|---|
| ECO 在 PLM 中如何发起、审批、发布？ | 是否可对接 OA 审批 |
| ECO 生效范围如何定义？ | 按日期、批次、订单、序列号或构型状态 |
| ECO 发布后如何通知 PDM、CAPP、ERP、MES？ | 消息、接口、人工任务或中台同步 |
| 已下发生产订单和 MES 工单如何处理？ | PLM 是否只通知，还是能参与闭环控制 |
| 旧版本 EBOM 和旧工艺文件如何保留？ | 是否支持审计追溯 |

### 4. 接口与数据开放能力

| 问题 | 需要供应商回答 |
|---|---|
| 是否提供标准 API？ | REST、SOAP、WebService、数据库视图、文件交换等 |
| 是否支持 JSON / XML 数据交换？ | 字段清单和样例 |
| 是否支持事件触发？ | 工程发布、ECO发布、物料变更、版本生效 |
| 接口失败如何处理？ | 重试、告警、日志、人工补偿 |
| 是否支持接入数据中台或 ESB？ | 供应商已有案例和技术边界 |
| 接口开发由谁负责？ | PLM方、客户方、中台方还是第三方实施商 |

### 5. 主数据与黄金源

| 问题 | 需要供应商回答 |
|---|---|
| 设计件物料主数据是否适合由 PLM 作为黄金源？ | 供应商建议及原因 |
| PLM 能否支持 13 位含连字符物料编码？ | 长度、字符集、唯一性校验 |
| REV 独立字段是否支持？ | 是否能参与查询、发布、接口同步 |
| 采购件和设计件如何区分？ | 与 ERP-MM 的主数据边界 |
| 是否支持物料编码、件号、构型状态分离管理？ | 字段模型和样例 |

### 6. 适航追溯与质量文件

| 问题 | 需要供应商回答 |
|---|---|
| PLM/PDM能否保存构型状态和偏离记录？ | 字段、流程和查询方式 |
| NDT规范和质量文件如何受控归档？ | 与 PDM 或质量系统的边界 |
| 是否支持按件号、序列号、版本查询关联文件？ | 是否支持长期归档和审计 |
| 适航追溯数据哪些应在 PLM/PDM，哪些应在 MES/数据中台？ | 供应商建议边界 |

## 五、要求供应商会后提交的资料

请供应商至少提交以下材料：

| 材料 | 用途 |
|---|---|
| PLM功能模块清单 | 判断是否覆盖 EBOM、ECO、MBD、构型、文档受控 |
| EBOM字段样例 | 支撑 PLM→PDM 接口卡 |
| ECO流程样例 | 支撑跨 OA、PDM、ERP、MES 的变更闭环设计 |
| 接口方式说明 | 判断点对点、ESB或数据中台路线可行性 |
| 标准 API 或数据交换样例 | 支撑字段级接口设计 |
| MBD管理与下发样例 | 判断能否支撑 CAPP/三维工艺 |
| 实施计划与交付物清单 | 判断周期、责任边界和验收条件 |
| 类似制造业或航空复材案例说明 | 仅作为参考，不作为未验证承诺 |

## 六、洽谈后需要形成的项目组结论

洽谈结束后，项目组建议当天形成一页纸结论：

| 结论项 | 内容 |
|---|---|
| PLM能力判断 | 能满足 / 部分满足 / 关键能力待确认 |
| 对Q5的影响 | 设计件物料主数据是否倾向 PLM 作为黄金源 |
| 对接口设计的影响 | PLM→PDM、PDM→CAPP、PLM/OA/ECO接口是否可进入设计 |
| 对Q7的影响 | 是否支持接入 ESB/数据中台 |
| 主要风险 | 供应商未明确、需二开、接口受限、字段不匹配等 |
| 需补充资料 | 列出供应商承诺提交的文档和截止时间 |
| 5月9日建议带上会的问题 | 只带可决策问题，不带泛泛讨论 |

---

## 七、建议现场坚持的边界

- 不接受“可以做”作为结论，必须要求供应商说明通过标准功能、配置、二开还是接口实现。
- 不现场承诺 PLM 为所有数据的黄金源，只确认其是否具备作为设计件主数据源的能力。
- 不把适航追溯全部压给 PLM，需区分 PLM/PDM、MES、WMS、ERP、数据中台各自的数据归属。
- 不讨论泛泛数字化蓝图，优先锁定 EBOM、MBD、ECO、接口、主数据和构型追溯六件事。
- 不让供应商只讲演示页面，必须拿到字段样例、接口样例和实施边界。
