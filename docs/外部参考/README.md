# docs/外部参考 说明

> 状态：外部参考资料目录  
> 生效日期：2026-06-10  
> 范围：外部行业材料、系统资料和整理产物。

本目录保存外部参考材料及其整理结果。这里的资料可以用于背景理解、术语核对和方案参考，但不能直接替代公司内部流程输入基线、组织真源或项目计划。

## 使用边界

1. 引用本目录内容形成正式结论前，应标明来源和整理日期。
2. 若外部材料中的部门、系统或流程口径与当前仓库真源冲突，以 `docs/organization/`、`docs/norms/` 和 PMO 当前数据为准。
3. `_整理产物/` 仍属于参考整理结果，不自动升级为标准规范。
4. 大体积或重复外部材料后续迁移前，应先写迁移提案并查清引用关系。

## 修改自检

- 新增资料时，优先放到能表达主题的子目录。
- 不提交浏览器缓存、解包目录、临时截图或未脱敏材料。
- 从参考材料抽取到正式规范时，在正式文件中写明来源。
