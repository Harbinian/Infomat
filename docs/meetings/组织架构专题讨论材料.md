## 一、四系统组织模型差异对照

| 维度 | 用友U8 ERP | 华天动力OA | 北京虎蜥MES | PLM（待定） |

## 二、建议方案：OA为主源，分层同步

```
华天动力OA（组织架构黄金源）
  │
  ├── 基础组织架构（部门/岗位）
  │     ├──→ 用友U8 ERP：部门、人员、岗位
  │     ├──→ 北京虎蜥MES：人员基础信息
  │     └──→ PLM：人员、角色
  │
  ├── 人员基础信息（工号/姓名/部门/岗位）
  │     └──→ 全系统统一工号
  │
  └── 资质信息（航空特殊）
        ├──→ MES：特种工艺资质（派工校验）
        └──→ 质量系统：检验员授权

MES自维护（不从OA同步）：
  · 车间/产线/工作中心/班组（制造资源，OA不关心）
  · 设备/工装（制造资源）

ERP自维护（不从OA同步）：
  · 成本中心（财务属性）
  · 工厂/库存地点（物流属性）
```

## 三、人员全生命周期同步规范

### 入职流程

```
HR在OA办理入职
  ↓ 触发消息推送
  ├── OA账号自动创建（含部门/岗位/角色）
  ├── ERP账号自动创建（含权限模板）
  ├── MES账号自动创建（含班组分配，待车间确认）
  └── PLM账号自动创建（含项目权限，待研发确认）
  ↓
特种工艺资质录入（如适用）
  ↓ 资质审批通过后
MES开放对应工序的派工权限
```

### 离职流程（最容易漏的坑）

```
HR在OA办理离职
  ↓ 触发消息推送
  ├── 所有系统账号立即禁用（不删除，保留审计记录）
  ├── MES未完成工单 → 自动转移给班组长
  ├── OA进行中的审批 → 自动转移给上级
  ├── PLM文件所有权 → 转移给部门负责人
  └── ERP未完成事务 → 告警，人工处理
```

### 调岗流程

```
HR在OA办理调岗
  ↓
  ├── OA权限按新岗位模板更新
  ├── ERP权限按新部门/岗位更新
  ├── MES班组重新分配
  └── 特种工艺资质：新岗位所需资质校验
        → 如资质不足，自动触发培训申请流程
```

## 四、SSO方案建议

| 方案 | 协议 | 优点 | 缺点 | 建议 |
|------|------|------|------|------|
| **方案A** | OAuth 2.0 + OIDC | 现代标准，移动端友好 | 需各系统支持 | **首选** |
