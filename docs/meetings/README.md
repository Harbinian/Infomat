# docs/meetings 说明

> 状态：会议记录与洽谈结论目录  
> 生效日期：2026-06-10  
> 范围：会议未决问题、供应商洽谈记录和阶段性方案讨论材料。

本目录保存会议记录、洽谈结论和阶段性讨论材料。会议材料可以解释当时的背景、问题和待办，但不自动替代当前真源、正式决策或已接受的架构规则。

## 当前文件

| 文件 | 作用 |

| `5月9日集成方案预审会_未决问题与解决方案.md` | 集成方案预审会问题与处理口径 |
| `MDM主数据治理解决方案.md` | 主数据治理会议或方案材料 |
| `PLM供应商洽谈结论（2026-05-07）.md` | PLM 供应商洽谈记录 |

## 使用边界

1. 会议记录中的待确认事项，只有同步到当前真源、计划或 ADR 后才视为正式口径。
2. 涉及部门、流程和项目数据时，仍以 `docs/organization/`、`docs/norms/` 和 PMO 当前计划为准。
3. 涉及长期架构决策时，应沉淀到 `docs/adr/`。
4. 涉及阶段计划或后续任务时，应沉淀到 `docs/plans/` 或 `docs/reports/`。

## 修改自检

- 新增会议记录时，写清会议日期、主题、参会范围和状态。
- 不把供应商口径、未决问题或讨论草案写成最终结论。
- 需要进入执行线的事项，应在对应真源或计划文件中另行维护。
