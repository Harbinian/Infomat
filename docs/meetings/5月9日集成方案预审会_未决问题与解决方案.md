## 一、总体判断

现有资料已经形成了系统集成的总体方向，但还没有达到“最终决策会”的输入成熟度。5月9日会议更适合定位为“集成方案预审会”：先确认组织职责、主数据治理路径、关键接口输入和供应商待确认清单，再决定哪些事项可以进入表决，哪些事项需要会后补资料。

本次预审建议按以下顺序推进：

1. 先定组织架构和责任机制。
2. 再收集各部门的“业务能力-业务流程-应用系统”映射。
3. 汇总业务流程涉及的数据对象、表单、单据、编码和术语。
4. 通过术语治理统一口径。
5. 在统一术语和数据对象基础上建立主数据底座，而不是直接先买或先建 MDM 平台。

## 三、MDM建设路径建议

### 3.1 推荐原则

MDM 不应从“先建平台”开始，而应从业务能力和流程开始。主数据不是孤立表格，它来自业务过程中的稳定对象，例如物料、BOM、客户、供应商、组织、人员、工装、设备、质量规范和项目。

建议采用以下路径：

```text
部门提交业务能力-业务流程-应用系统映射
  ↓
汇总每条流程涉及的数据对象、单据、字段、编码、状态和责任部门
  ↓
做术语治理：同名不同义、同义不同名、缩写、系统字段口径统一
  ↓
识别主数据域：组织、人员、物料、BOM、供应商、客户、工装、设备、质量规范等
  ↓
确定黄金源、创建权、审批权、修改权、只读系统和同步机制
  ↓
形成主数据底座和后续 MDM 平台需求
```

### 3.2 本项目MDM解决方案

本项目的 MDM 不建议一开始就建设成“大而全”的主数据平台。更稳妥的方案是先把“组织与身份”做成主数据底座的第一层，因为组织、人员、岗位、角色、资质和授权是所有流程审批、派工、检验、质量放行、ECO发布和适航审批的入口。业务系统可以保留本系统需要的本地账号、部门映射或缓存，但正式权威来源必须回到 OA/MDM。

本项目的 MDM 建设分两层推进：

```text
第一层：组织与身份MDM
  部门、人员、岗位、角色、资质、授权、登录认证、SSO

第二层：业务主数据MDM
  物料、BOM、供应商、客户、工装、设备、质量规范、术语词典、术语冲突
```

5月9日前优先确认第一层，不把会议拖入平台选型。第二层则以各部门提交的业务能力-业务流程-应用系统映射为输入，逐步识别数据对象、字段台账和黄金源。

| 方案要点 | 本项目处理原则 |
|---|---|
| 组织与人员权威 | OA/MDM 管部门、人员、岗位、工号、入转调离；ERP、MES、PLM、WMS 只消费或映射 |
| 本地缓存边界 | 业务系统可保留本地缓存或影子表，用于权限查询、接口性能和离线过渡，但不得作为正式权威源 |
| 部门唯一标识 | 不只用中文部门名，必须设计稳定的 `department_code` / `department_id`，避免部门改名导致权限和流程漂移 |
| 角色与资质控制 | 对派工、检验、质量放行、适航审批、ECO发布等高风险动作，角色或资质不明确时不默认放行 |
| 字段台账 | 各部门流程映射完成后，项目管理部汇总为“数据对象-字段-黄金源-维护部门-消费系统”台账 |
| 术语冲突 | 把“冻结”“需求/资料”“退回”“件号/物料号”“版次/构型”等冲突纳入术语治理清单，形成待确认、评审中、已解决、已驳回状态 |
| 接口契约 | 组织、人员、角色、资质、物料、BOM 等主数据接口必须定义字段、错误处理、同步频率和人工兜底 |

### 3.3 会前建议模板

各部门 2026-05-08 前提交一张表即可，不要求一次写得很完美，先把“真实业务链路”抓出来。

| 字段 | 填写说明 |
|---|---|
| 部门 | 例如工程技术部、质量管理部、物资保障部、复材车间 |
| 业务能力 | 例如工程发布、ECO变更、采购到货、预浸料出库、工序报工 |
| L3业务流程 | 用动词短语描述具体流程，例如“发布EBOM到PDM” |
| 当前应用系统 | 当前由哪个系统或表格承载 |
| 目标应用系统 | 未来应由哪个系统承载 |
| 涉及数据对象 | 物料、BOM、供应商、人员、设备、批次、工装、质量文件等 |
| 关键字段/单据 | 编码、版次、状态、数量、批次、有效期、审批单号等 |
| 数据创建部门 | 谁第一次创建该数据 |
| 数据审批部门 | 谁批准该数据生效 |
| 数据消费系统 | 哪些系统只读或引用该数据 |
| 术语疑点 | 存在歧义的词，例如件号、物料号、工艺规范、构型、批次 |

### 3.4 术语治理优先清单

5月9日前建议先治理以下高风险术语，避免会上各讲各话。

| 术语 | 必须统一的问题 |
|---|---|
| 物料编码 | 内部唯一编码，是否与对外交付件号完全分离 |
| 件号 Part Number | 主机厂件号、设计件号、内部物料编码之间的关系 |
| 版次 REV | 字母还是数字，是否独立字段，是否进入编码 |
| EBOM | 是否包含铺层、材料规范、固化规范、虚拟件 |
| MBOM | 谁负责转换，是否以工序、工装、定额为核心 |
| PBOM | 采购BOM与ERP-MM采购件、供应商清单的关系 |
| 构型 | 与适航状态、ECO、偏离/超差记录的关系 |
| 批次 | 供应商批次、WMS批次、MES消耗批次是否同源 |
| 资质 | 人员资质、检验授权、适航授权、岗位权限的边界 |
