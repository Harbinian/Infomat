## Slide 3 · 为什么主数据是一切的地基

### 航空复材场景下的真实事故链

```
场景：C919后机身前段上壁板（CFRP Fuselage Rear Frame Upper Panel）

PLM 叫：  PANEL-CFRP-RFFUP-001-A       （设计态，含铺层顺序）
ERP 叫：  1000045231                    （财务流水号）
MES 叫：  PART-PANEL-RFFUP-001          （车间自命名）
质量系统：后机身上壁板 PANEL-CFRP-RFFUP-001-A  （质检员手填）
OA采购：  XX级碳纤维预浸料或CMS-XX-XXX   （采购申请描述）

结果：
→ 预浸料批次与零件无法关联 → 适航审查无法提供材料追溯
→ NDT检测记录找不到对应零件 → 质量档案不完整
→ 固化炉工艺参数记录与零件脱节 → 无法证明工艺符合性
→ 适航局审查时，整批次零件被要求重新验证
```

**在航空制造，主数据混乱不只是效率问题，是适航符合性问题。**

## Slide 4 · 航空复材零部件的BOM体系特殊性

### 四态BOM在航空复材场景下的定义

```
┌─────────────────────────────────────────────────────────────────┐
│  EBOM（工程BOM）— PLM主导                                        │
│  · 设计视角，体现零件的几何定义与材料规范                          │
│  · 关键字段：铺层顺序（Ply Sequence）、纤维方向（Fiber           │
│    Orientation）、材料规范号（Material Spec No.）、               │
│    固化工艺规范（Cure Cycle Spec）                               │
│  · 含虚拟件（Virtual Item）：如"壁板组件"节点，仅用于设计         │
│    结构组织，不对应实物                                           │
├─────────────────────────────────────────────────────────────────┤
│  MBOM（制造BOM）— CAPP/MES主导                                   │
│  · 制造视角，体现零件如何被制造出来                               │
│  · 关键字段：工序分工（铺层→热压罐固化→脱模→修边→NDT→           │
│    表面处理→检验）、工装编号（模具/热压罐）、工时定额             │
│  · 航空特殊项：工艺规范号（Process Spec，如 PS-CURE-001）        │
│    必须与EBOM中的固化工艺规范一一对应                             │
├─────────────────────────────────────────────────────────────────┤
│  PBOM（采购BOM）— ERP-MM主导                                     │
│  · 采购视角，体现需要外购的原材料和外协件                         │
│  · 关键字段：预浸料规格（Prepreg Spec）、批次要求、               │
│    供应商资质（AS9100认证）、材料有效期（Shelf Life）             │
│  · 航空特殊项：原材料必须来自批准供应商清单（ASL）                │
├─────────────────────────────────────────────────────────────────┤
│  SBOM（构型BOM）— PDM/适航主导                                   │
│  · 适航视角，体现交付给主机厂的构型状态                           │
│  · 关键字段：件号（Part Number）、序列号（S/N）、                 │
│    适用性（Applicability）、构型偏离（Deviation/Waiver）         │
│  · 对应适航文件：符合性声明（SoC）、首件检验报告（FAI）           │
└─────────────────────────────────────────────────────────────────┘
```

### 航空复材BOM与普通制造BOM的核心差异

| 差异点 | 普通制造 | 航空复材制造 |
|--------|---------|------------|
| BOM最小单元 | 零件 | **铺层（Ply）**，一个蒙皮可能有数十层 |
| 材料属性 | 材料牌号 | **预浸料批次号 + 有效期 + 存储条件** |
| 工艺参数 | 工艺路线 | **固化曲线（温度/压力/时间）+ 热压罐编号**，必须记录到件 |
| 质量记录 | 检验合格 | **NDT报告（超声C扫/X射线）+ 孔隙率检测**，记录到件 |
| 版本管理 | 版次 | **构型状态 + ECO/EO变更单 + 偏离/超差记录**，适航局可查 |
| 追溯要求 | 批次追溯 | **序列号级追溯**，每个零件独立档案，终身保存 |
| 有效期管理 | 无 | **预浸料冷冻存储时间 + 环境暴露时间 + 上机时限**，超期作废 |

## Slide 6 · 物料编码规范

### 编码结构

```
XX  -  XXX  -  00000
│      │        │
大类   小类    流水号
(2位)  (3位)   (5位)

总长度：13位（含2个连字符）
版次REV：独立字段，不进主编码
```

### 航空复材特殊编码规则

| 规则 | 说明 |
|------|------|
| **件号（Part Number）与物料编码的关系** | 对外交付件号（主机厂要求格式）与内部物料编码分离，通过映射表关联。禁止直接用主机厂件号作为内部物料编码 |
| **预浸料有效期不进编码** | 预浸料的批次号、生产日期、有效期作为批次属性管理，不体现在物料编码中 |
| **工艺规范号单独字段** | 固化工艺规范（Cure Spec）、无损检测规范（NDT Spec）作为物料属性字段，不进编码 |
| **构型状态码** | 适航构型状态（如 TC/STC 适用性）作为独立属性，不进编码 |

## Slide 7 · BOM体系集成架构

### EBOM → MBOM 转换逻辑（最关键、最容易出错）

```
PLM中的EBOM（工程BOM）
  ├── 壁板组件（虚拟件，不对应实物）
  │     ├── 碳纤维后机身上壁板 CF-PNL-00001 Rev.A
  │     │     ├── 铺层定义（Ply Stack-up）
  │     │     │     ├── Ply-01: T300/197gsm, 0°, 区域A
  │     │     │     ├── Ply-02: T300/197gsm, 45°, 全幅
  │     │     │     ├── Ply-03: T300/197gsm, -45°, 全幅
  │     │     │     └── ... (共24层)
  │     │     ├── 固化工艺规范: PS-CURE-AUTOCLAVE-001
  │     │     └── 材料规范: MS-PREPREG-T300-001
  │     └── 碳纤维后机身下壁板 CF-PNL-00002 Rev.A
  └── 主梁组件（虚拟件）
        └── ...

          ↓ EBOM→MBOM转换（谁来做？规则是什么？）

CAPP/MES中的MBOM（制造BOM）
  ├── 碳纤维后机身上壁板 CF-PNL-00001 Rev.A
  │     ├── 工序10: 材料准备（预浸料下料、铺层样板准备）
  │     │     └── 消耗：T300预浸料 PM-CFP-00001, 定额：12.5m²
  │     ├── 工序20: 铺层（手工铺层/自动铺带ATL）
  │     │     └── 工装：铺层模具 TO-MDL-00001
  │     ├── 工序30: 预压实（每4层预压实一次）
  │     ├── 工序40: 热压罐固化
  │     │     ├── 工装：热压罐 HAC-001（设备号）
  │     │     ├── 工艺规范：PS-CURE-AUTOCLAVE-001
  │     │     └── 关键参数：180°C/6bar/120min（必须记录到件）
  │     ├── 工序50: 脱模与修边
  │     ├── 工序60: 无损检测NDT（超声C扫）
  │     │     └── 检测规范：NDT-SPEC-UT-001
  │     ├── 工序70: 尺寸检验
  │     └── 工序80: 表面处理/底漆
```

### EBOM→MBOM转换的三大难题

| 难题 | 说明 | 解决方案 |
|------|------|---------|
| **铺层展开** | EBOM中是铺层定义，MBOM中需要展开为工序和材料消耗定额 | CAPP系统负责展开，PLM提供铺层数据接口 |
| **虚拟件处理** | EBOM中的虚拟装配节点不对应实物，MBOM不需要 | PLM发布时标记虚拟件，PDM→ERP接口过滤虚拟件 |
| **工艺规范绑定** | EBOM中的固化规范号必须与MBOM工序中的工艺规范一一对应 | 工艺规范号作为物料属性字段，CAPP读取后自动关联工序 |

## Slide 9 · 预浸料有效期管理（航空复材核心难题）

> 这是航空复材制造中最容易被系统集成忽视、但最容易引发质量事故的环节

### 预浸料生命周期时间轴

```
供应商生产
    ↓
出厂日期（Manufacturing Date）
    ↓  冷冻运输（-18°C）
到货入库（WMS扫码入库）
    ↓  记录：批次号、生产日期、有效期、入库时间
冷库存储（-18°C）
    ↓  WMS监控：冷冻存储有效期倒计时
出库解冻（出冷库时间戳）
    ↓  WMS记录出库时间 → MES接收 → 开始计算"环境暴露时间"
室温存储（≤25°C）
    ↓  MES监控：环境暴露累计时间（通常≤30天）
铺层使用
    ↓  MES记录：使用批次、使用零件号、使用工序
固化
    ↓
剩余材料回库（如未超期）
    ↓  WMS更新：剩余量、累计环境暴露时间
超期报废
    ↓  ERP-MM库存核销 + 质量记录
```

### 系统集成要求

| 集成点 | 数据流 | 触发条件 | 告警机制 |
|--------|--------|---------|---------|
| WMS → MES | 预浸料批次号 + 出库时间 + 剩余有效期 | 出库扫码时实时推送 | 有效期<7天时告警 |
| MES → WMS | 实际使用量 + 使用零件号 | 工序完工报工时回写 | — |
| WMS → ERP-MM | 超期预警 + 报废申请 | 有效期到期前3天 | 自动触发OA报废审批流 |
| MES → 质量系统 | 批次-零件关联记录 | 工序完工时 | — |

## Slide 10 · 黄金源确认表

| 物料类型 | 黄金源 | 创建触发时机 | 同步目标 | 航空特殊要求 |
|---------|--------|------------|---------|------------|
| 复合材料结构件（CF/GF/HY） | **PLM** | 工程发布（首飞件：设计冻结后） | →ERP→MES→PDM→质量系统 | 必须携带材料规范号、工艺规范号 |
| 金属接头/机加件（ME） | **PLM** | 工程发布 | →ERP→MES | 含材料牌号（如 TC4钛合金） |
| 装配体/组件（AS） | **PLM** | 工程发布 | →ERP→MES | 含构型适用性 |
| 预浸料/胶膜（PM） | **ERP-MM** | 采购需求确认（来自ASL） | →WMS→MES | 必须含有效期字段、冷冻存储标识 |
| 辅助材料（RM） | **ERP-MM** | 采购需求确认 | →WMS→MES | 部分需批次管理 |
| 航空标准紧固件（FA） | **ERP-MM** | 采购需求确认（来自ASL） | →WMS→MES | 批次管理，含材料证书要求 |
| 工装模具（TO） | **MES** | 工装设计完成 | →ERP-CO（折旧成本） | 序列号管理，含使用次数上限 |
| 技术文件（DM） | **PDM** | 文件受控发布 | →MES（作业指导书）→OA | 版次受控，不得使用非受控版本 |

### ⚠️ 过渡方案（PLM选型未定期间）

```
PLM未上线前，复合材料结构件的黄金源临时由 PDM/ERP 代管：
  · 物料基础属性：ERP-MM 创建
  · 技术属性（材料规范、工艺规范）：PDM 维护，人工关联
  · PLM上线后：数据迁移 + 重新建立自动同步链路
  
风险：过渡期间技术属性与ERP物料的关联依赖人工维护，
      存在数据不一致风险，需要建立人工核查机制（每周一次）
```

  │   ├── 铺层记录：操作者工号 + 日期 + 铺层顺序符合性
  │   ├── 固化记录：热压罐编号 + 实际固化曲线（温度/压力/时间）
  │   │             + 工艺规范版次 + 操作者 + 日期
  │   ├── NDT记录：检测方法 + 设备编号 + 操作者资质 + 报告编号
  │   └── 尺寸检验：检验报告编号 + 检验员 + 日期

  ├── 适航文件：首件检验报告（FAI/FAIR）+ 符合性声明（SoC）

## Slide 12 · 组织架构主数据（航空复材专项）

### 航空制造特有的组织维度

```
普通制造的组织架构：
  公司 → 部门 → 岗位

航空复材制造需要额外维护：
  ├── 特种工艺操作资质（Special Process Qualification）
  │     · 铺层工（Layup Technician）资质等级 + 有效期
  │     · 热压罐操作工资质 + 有效期
  │     · NDT检测员资质（Level I/II/III）+ 有效期
  │     · 焊接工/胶接工资质 + 有效期
  │
  ├── 检验员授权（Inspection Authorization）
  │     · 首检员授权范围 + 有效期
  │     · 质量放行授权（Authorized Release）
  │
  └── 适航授权人员（Airworthiness Personnel）
        · 适航审定代表 + 授权范围
        · 质量保证代表
```

### 人员资质与系统集成的关系

| 集成场景 | 要求 |
|---------|------|
| MES工序派工 | 系统自动校验操作者是否持有该工序的特种工艺资质，且资质在有效期内，否则禁止派工 |
| MES固化工序 | 热压罐操作工资质校验 + 设备校准有效期校验，双重锁定 |
| 质量系统检验 | 检验员授权范围校验，无授权不得签署检验记录 |
| OA审批流 | 适航相关审批必须路由到持有适航授权的人员 |

### 建议方案：以OA为组织架构主源，资质模块单独管理

```
华天动力OA（组织架构主源）
  ├── 基础组织架构 → 同步到 ERP / MES / PLM
  └── 人员基础信息 → 同步到所有系统

资质管理模块（建议挂载在OA或质量系统）
  ├── 资质证书录入 + 有效期管理
  ├── 到期前30天自动触发OA培训/复证审批流
  └── 资质状态实时同步到MES（派工校验用）
```
