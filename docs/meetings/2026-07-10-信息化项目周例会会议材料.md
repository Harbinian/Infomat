## 二、本周要启动的工作

本周只启动一件主线工作：调研资料相关专题会议。启动顺序固定为“先培训，再启动具体工作”。培训不是讲概念，而是让每个责任对象知道三件事：带什么资料、怎么回执、缺资料时怎么登记。

| 环节 | 会议动作 | 现场要拿到的结果 |
| ---- | -------- | ---------------- |
| 1. 培训调研模板 | 用 DLV-901 说明访谈只问业务事实：谁做、做什么、用什么资料、交给谁、留下什么证据 | 参会人知道如何回答模板，不把系统模块名当成业务事实 |
| 2. 培训资料回执 | 用 DLV-902 说明资料回执字段：资料是否存在、资料位置、版本、可否提供样例、责任人、缺口说明 | 各部门知道回执不是发文件即可，而是要说明资料状态和责任 |
| 3. 培训会议排期 | 用 DLV-903 说明专题会前必须有会议包：参会范围、会前材料、资料准备、记录人和会后动作 | 各专题知道会前准备不齐时只能开说明会，不能形成结论确认 |
| 4. 培训评审和整改 | 用 DLV-904 说明通过、有条件通过、退回补充、暂缓决策的判断口径 | 后续评审问题能进入整改清单，不停留在口头意见 |
| 5. 培训组织人员标准 | 用 DLV-905 说明组织、部门、岗位、人员和项目角色的来源优先级与待确认处理 | 基础资料不混同权限角色，不把待确认人员事实写成正式口径 |
