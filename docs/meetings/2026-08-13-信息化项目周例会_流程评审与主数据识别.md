# 信息化项目周例会：流程评审与主数据识别

## 第一页：流程评审

各部门携带首批拟导入3000平台的流程，由MDM工作组按统一标准组织评审。

| 评审内容 | 通过标准 |
|---|---|
| 流程目的、范围和结束边界 | 业务部门确认流程事实 |
| A1业务行为和责任角色 | 单流程JSON符合`process-governance-v3`结构 |
| 条件分支、退回和跨部门承接 | 表单、字段和稳定引用不丢失 |
| 表单、业务对象和数据输入输出 | 待定项写明缺少的证据和确认主体 |

评审通过后，部门MDM审核员在3000核对预览并执行受控导入。

## 第二页：主数据识别

主数据从流程、业务对象和表单字段中识别，不从系统表或字段名称反推。

| 识别标准 | 主数据清单至少写明 |
|---|---|
| 被多个流程、部门或系统长期复用 | 主数据对象名称和业务含义 |
| 具有稳定的唯一标识 | 唯一标识和关键字段 |
| 新建、变更、停用规则清楚 | 权威来源、维护部门和确认主体 |
| 定义、维护和确认责任明确 | 使用该对象的流程和系统 |

同名不等于同一对象；业务表单和交易记录不得直接认定为主数据。

## 第三页：行动项

1. 各部门在MDM工作组指定时间内，前来评审首批拟导入3000平台的流程。
2. 工程技术部、行政人事部依据标准提交主数据清单。
