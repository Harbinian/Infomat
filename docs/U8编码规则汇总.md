## 1. 物料/存货编码 (Inventory/Material Code)

**来源：** PB_Bas_zh-CN/Basic.htm

| 属性 | 规则 |
|------|------|
| 编码字符 | 数字 `0-9`、字母 `A-Z`、**连字符 `-`** |
| 最大长度 | 30 位 |
| 是否必填 | 是，必须唯一 |
| 可否批量修改 | **不可**批量修改 |

> 原文：「存货编码必须唯一且必须输入，可参照存货档案录入。可输入最多30位数字或字符。可以用数字0-9或字符A--Z表示。」
>
> **注意：** 帮助文档原文仅列举 `0-9` 和 `A-Z`，未明确提及连字符。经与用友设计人员确认，物料编码**实际允许连字符 `-`**。文档中的字符范围描述为非穷举性列举。

## 13. 编码级次通用规则

**来源：** 综合各模块

### 共同原则：
1. **编码级次结构** 在【编码方案】中统一定义（分级方式 + 各级长度）
2. 可分级设置的档案包括：科目编码、客户分类编码、部门编码、存货分类编码、地区分类编码、货位编码、供应商分类编码、收发类别编码、结算方式编码
3. 新增下级编码时，上级编码**必须已存在**
4. 编码一经使用（被业务单据引用），**不可删除、不可修改**
5. 非末级分类**不可删除**
6. 末级不可再增加下级

### 级次结构示例：
- 规则 `XX-XXX`：2位一级 + 3位二级，如 `01-001`
- 规则 `* **`：1位一级 + 2位二级，上级编码 `1` → 下级 `101`
