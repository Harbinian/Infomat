# docs/U8SoftHelp 说明

> 状态：U8 帮助文件参考目录  
> 生效日期：2026-06-10  
> 范围：用友 U8 多模块简体中文帮助文件 Markdown 整理版。

本目录保存 U8 简体中文帮助文件的 Markdown 整理版，主要用于离线参考和术语查证。它不是当前流程输入基线、接口真源或实施结论。

## 当前内容

- `md/`：由简体中文 CHM 转换得到的 Markdown 检索版，入口为 `md/README.md`。
- 原 CHM 包已从仓库移除；如需重新生成 Markdown，应先把源 CHM 放回本目录，再运行 `scripts/convert-u8softhelp-chm-to-md.mjs`。
- `scripts/convert-u8softhelp-chm-to-md.mjs` 解包过程只使用系统临时目录，不在仓库内保留 CHM 解包结果。

## 使用边界

1. 引用本目录内容形成正式规范前，应在目标文档中标明来源模块和语言版本。
2. `md/` 是文本整理版，图片只保留源文件名提示；精确截图和嵌入媒体需回到原 CHM 或业务系统确认。
3. 不在本目录提交 CHM 解包目录、搜索缓存或临时导出。
4. 与公司流程、部门职责或 PMO 数据冲突时，以当前公司内部真源为准。
