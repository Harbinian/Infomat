### 人事风险管控

本产品是云服务产品，可查询人力资源领域相关的法律法规内容，定时推送最新法规解读，并可以搜索相关的法规内容。威科公司是用友人事风险管控模块的指定服务商。

【操作说明】

-

关于免费版和试用版的控制

1、不购买人事风险管控模块的服务时，只能查询免费版的内容：最新解决、双周精华、法规三个板块，其中加锁的信息，只能查看标题，点击具体内容时会提示：您目前是免费用户无法查看此数据，请向您的供应商提出采购请求，我们会尽快为您开通服务。

2、未正式购买人事风险管控服务时，系统提供60天的体验期，在60天内可以与付费用户一样查看到所有板块的内容，包括：最新解读、双周精华、法规、案例、新闻、专业解读、实用工具、专家问答。

3、从距离试用期到期的15天开始需要给出用户提示：您的法律合规试用期为60天，截止日期到某年某月某日，您还有15天到期。

-

各板块内容介绍

1、最新解读：提供给企业HR人员每日最新的劳动法规相关新闻，重点的案件分析和法规解读，以及劳动法的知识问答。

2、双周精华：每双周推荐一期这两周的精华内容，一共可查看距离当前最近的五期双周内容。

3、法规：搜索各类法规、新闻等。

4、案例：收录了建国以来官方公布的典型案例，并提供相关法律链接；邀请国内知名专业人士对精选案例进行评析，深入浅出剖析案件要点，提供实务建议，最大程度地为用户规避法律风险。

5、专业解读：律所的律师对人力资源领导法律法规的详细解读。

6、实用工具：包括四个智能图表，通过对比工具的应用，可以轻松获得全国多个城市最新劳动法规及最低工资、工伤待遇、住房公积金等最新数据，尤其便于企业进行多地人力资源合理管理。

7、专家问答：近一千个劳动法领域常问答，内容覆盖从招聘、劳动合同、薪酬福利到劳动争议解决等HR日常工作常见领域，可以根据地域及主题进行浏览及搜索。

【购买说明】

本产品是公有云产品，用户只需要像供货商正常提交订货订单，付款后会由用友供应商告知开通时间，我们的开通时间会在您付款后的7个工作日内完成。

提示：

-

当前登录的服务器若没有加密锁，不能体验试用期，只能查看免费版数据。

-

企业内任何有权限的操作员点击体验试用期后，做为试用的第一天开始计算。

-

同一个企业若创建了多个账套，只能有一个试用期。

-

试用期到期后若未购买人事风险管控模块的服务，只能查看上述的免费版的内容。

### 如何使用定位功能

定位功能搜索列表中某列或所有列是否包含要查找的内容，如找到则定位到第一个符合条件的记录并高亮显示，如没有找到则提示"搜索完毕，是否重新搜索?"

定位与查询/过滤/搜索不同，只在当前页查找符合条件的数据，并定位到第一个符合条件的记录；查询/过滤/搜索根据设置的条件重新从数据库筛选数据，并刷新数据。

-

设置查找匹配方式：

-

-

-

-

-

-

全部：从头开始搜索

-

向下：从当前位置向下搜索

-

向上：从当前位置向上搜索

-

-

再次定位：点击〖查找下一个〗按钮，自动定位到下一个匹配的记录

## 如何使用搜索功能

Source page: `howtosearch.htm`

### 如何使用搜索功能

在搜索按钮前的编辑框中输入要搜索的内容，按〖搜索〗按钮在数据库中筛选出符合条件的记录，并刷新显示查询结果。

定位、查询/过滤、搜索功能对比：

 |

操作 |
 |

说明 |

 |

定位 |
 |

在当前页查找符合条件的数据，并定位到第一个符合条件的记录，支持模糊或精确定位；只能对列表中的字段进行查找 |

 |

查询/过滤 |
 |

高级查询功能，可设置复杂的查询条件筛选数据，刷新显示查询结果 |

 |

搜索 |
 |

只支持模糊搜索，一般对某一字段或特定的几个字段进行模糊查询，刷新显示查询结果；一般只能搜索列表中的字段；搜索相当于简化的查询功能 |

【操作步骤】

-

选择要搜索的字段（有些模块的搜索功能未提供选择搜索字段的功能，按业务特点搜索默认的几个字段）

-

在搜索按钮前的编辑框中输入要搜索的内容

-

按回车键或点击〖搜索〗按钮，系统按模糊匹配的方式搜索符合条件的数据，并刷新数据

示例

【例1】：搜索姓张的人员

进入人员档案，在搜索按钮前的编辑框中输入"张"，按回车键找到所有姓张的人员。

注：人员档案默认搜索的字段有人员编号、姓名和email
