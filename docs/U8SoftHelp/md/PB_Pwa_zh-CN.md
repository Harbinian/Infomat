## 预警(定时任务)设置

Source page: `warningtaskset.htm`

-

名称：录入，在预警（定时任务）时提示给使用者的预警（定时任务）信息，如"存货保质期预警（定时任务）"。

-

预警（定时任务）源：选择，系统内置可以进行预警（定时任务）设置的内容。

-

预警（定时任务）源描述：根据预警（定时任务）源带入，可修改。

-

账套：选择，当前服务器的U8账套。

-

执行人：定时任务后台执行时，使用"执行人"进行相应的单据操作，并在相应单据上对应操作人字段显示"操作人"信息。例如，定时关闭的任务，单据上的"关闭人"显示为定时任务的"执行人"。

-

执行频率：设置频率，默认为1天执行一次，选择内容为年、月、天、小时、周。

-

下次执行时间：新增任务默认为当前时间，可以修改；已有的任务，系统根据上次执行时间、执行频率自动计算，可修改。

-

上次执行时间：显示上次执行的时间，不可修改。

-

服务器故障恢复后：选择，默认为忽略漏执行的预警(定时任务)，选择内容为忽略漏执行的预警(定时任务)、补漏执行的预警(定时任务)。若下次执行时间大于当前系统时间，则该任务是否需要执行根据该选项：

-

忽略，则该次任务不需执行。

-

补发，则对该次任务进行补发处理。

通知对象

-

通知类型：根据所选择的预警(定时任务)源带入，系统内置，不可修改。预警(定时任务)任务有多项通知类型的可复选，至少选择其中一项。

-

通知对象列表：按〖添加〗添加通知对象，按〖删除〗删除通知对象。当［通知所有］已选时，不可添加、删除通知对象。

-

通知所有：打勾选择，默认为选择。选择时，对所有相关的通知对象进行预警(定时任务)通知；否则只通知已经设置的相应通知对象。

-

通知方式：打勾选择，默认为两个方式都选择，选择内容为邮件通知、短信通知。

### 预警(定时任务)设置

用户可以新增预警(定时任务)，也可修改现有预警(定时任务)。

【菜单路径】

预警和定时任务管理－〖添加〗〖编辑〗

【操作步骤】

-

进入【预警和定时任务管理】功能界面，左树显示已经存在的预警(定时任务)源，右表为已设置的任务。

-

选中左树某预警（定时任务）源中某按〖添加〗，系统弹出预警(定时任务)设置窗口，可以设置预警源、计划、通知；按〖确定〗保存添加的预警(定时任务)。

-

将光标移到要修改的预警(定时任务)，按〖编辑〗进行修改；按〖确定〗保存修改的预警(定时任务)。

【栏目说明】

预警(定时任务)源栏目

计划栏目

通知栏目

【备注】

-

客户端执行预警(定时)任务，如果需要发送邮件通知，需要在客户端的【个人参数】-【个人选项】中配置邮件服务器；

-

服务器端执行预警(定时)任务，如果需要发送邮件通知，需要在服务器端的【应用服务器配置】-【消息中心参数配置】中配置邮件服务器

### 预警任务列表

系统显示预警(定时)任务列表，用户可以进行维护，可以设置通信设置、邮件设置。

【菜单路径】

【企业应用平台】－【系统服务】－【预警与定时任务】

【操作步骤】

-

-

可以新增预警（定时）任务，可以对已有的预警（定时）任务进行编辑，参见预警（定时）任务设置；可以删除已有的预警（定时）任务。

-

对于已启动的预警（定时）任务，按〖停止〗可以停止任务；对于已停止的预警，按〖启动〗可以启动任务。

-

### 智能报表监控

【菜单路径】

【企业应用平台】－【系统服务】－【定时任务源】－【公共服务】

【操作步骤】

1. 在公共目录设置-智能报表监控-节点下点击"增加"按钮，弹出发布设置窗体，如图

2. 从"报表视图"下拉列表中选择要发布的监控视图，选择发布类型和消息类型。如图

3. 设置时间和接收者，执行的周期时间可以按小时，天，周，月进行设置。如图

4. 设置报表的查询条件，可以设置固定条件进行查询，也可以设置谓词表达式进行查询。如图

5. 增加预警源后，在预警任务列表中增加固定时间任务和周期时间任务，可以进行修改。

6. 由预警源产生的报表，在报表中心-静态报表文件夹下存放。

7. 如果预警源设置了消息中心通知，则根据设置给接收人发送门户消息通知，接收人在消息中心-预警信息中可以看到此消息，双击消息打开此报表。

【栏目说明】

-

报表视图：下拉列表框中显示所有的监控视图。

-

发布类型：包括静态报表和邮件两种发布类型，可以同时选择。如果选择静态报表，生成的报表在报表中心-静态报表文件夹下；如果选择邮件通知，则预警监控时会发送邮件给接收人，邮件内容为报表预警的通知，不包含报表内容。

-

可以按固定时间和周期时间来设置监控时间，分别生成固定时间任务和周期时间任务在任务列表中。

-

消息类型：可以选择门户消息通知和手机短信通知。

-

接收者：接收者列表中的人为有此报表查询功能权限的人。

-

查询条件：可以选择固定条件参照或者手工录入条件，固定条件参照即使用报表本身的查询条件，手工录入时可直接录入条件值，也可对日期类型字段设置谓词表达式，如图。谓词表达式包括：本月第一日、上月第一日、今天，昨天、本月最后一日、本年第一日、会计月第一日、会计月最后一日，运行时根据客户端登录日期自动转换。

### 如何使用帮助

用友U8支持全程在线帮助，能够帮助您及时、快捷地获得所需要的帮助信息。

如何获取帮助

-

您可以在窗口界面点击〖帮助〗按钮，即可弹出帮助页面。

-

按F1快捷键获取帮助。

如何使用帮助

您点击左侧主题，右侧则显示相应的主题内容。在帮助中常用的格式有：隐藏内容、链接主题、链接页签、图形链接。

隐藏内容

-

为了保持帮助窗口的整洁性和条理性，我们对于部分内容或图表采取隐藏显示的形式，隐藏内容显示为绿色字体，点击绿色文字可打开隐藏的内容，再次单击，恢复隐藏。

-

链接主题

-

对于与当前主题内容有关的主题，帮助文件采取链接主题的形式。链接主题显示为蓝色字体，并加下划线，用户单击链接主题，则帮助跳到所链接的主题，文件左侧的目录也跳到相应的文件。

-

用户如返回原来的主题，可按〖后退〗；若跳了若干个主题，则按若干次〖后退〗。

-

用户点击过的链接主题，显示为红色字体。

-

帮助文件中的链接页签

-

帮助主题的内容较多时，可以将链接关联到相应主题的特定位置，再按〖后退〗则返回原来的主题。

-

链接页签与链接主题的区别是：前者链接到主题的页签位置，可以是同一个主题；后者链接到相应的主题。

-

帮助文件中的相关主题按钮

-

对于与当前主题内容有关的若干个主题，帮助文件采取相关主题按钮的形式。

-

用户点击按钮，则弹出相关主题菜单，用户可选择要查看的主题，帮助跳到所链接的主题，文件左侧的目录也跳到相应的文件。

-

帮助文件中图形的链接

-

对于帮助文件中的图形，当鼠标移动到有链接的功能框或按钮上，鼠标会改变为小手形状，用户可直接点击，链接到相关主题。
