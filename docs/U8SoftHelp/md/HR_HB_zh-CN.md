ASCII函数

返回字符表达式最左端字符的 ASCII 代码值。

语法

ASCII ( character_expression )

参数

character_expression

是类型为 char 或 varchar的表达式。

示例

ASCII('ab')，结果为97。

ASCII('a')，结果为97。

CHAR函数

将 int ASCII 代码转换为字符的字符串函数。

语法

CHAR ( integer_expression )

参数

integer_expression

介于 0 和 255 之间的整数。如果整数表达式不在此范围内，将返回 NULL 值。

注释

CHAR 可用于将控制字符插入字符串中。

示例

CHAR(97)，结果为字符"a"。

CHAR(256)，结果为NULL。

CHARINDEX函数

返回字符串中指定表达式的起始位置。

语法

CHARINDEX ( expression1 , expression2 [ , start_location ] )

参数

expression1

一个表达式，其中包含要寻找的字符的次序。expression1 是一个短字符数据类型分类的表达式。

expression2

一个表达式，通常是一个用于搜索指定序列的列。expression2 属于字符串数据类型分类。

start_location

在 expression2 中搜索 expression1 时的起始字符位置。如果没有给定 start_location，而是一个负数或零，则将从
expression2 的起始位置开始搜索。

示例

CHARINDEX('ab','cdab2ab')，结果为3。

CHARINDEX('ab','cdab2ab',5)，结果为6。

STARTSWITH函数

测试字符串表达式是否以某个字符串开头。

语法

STARTSWITH(expression1,expression2)

示例

STARTSWITH('abc','abcd')，结果为真。

STARTSWITH('abc','Dabc')，结果为假。

ENDSWITH函数

测试字符串表达式是否以某个字符串结尾。

语法

ENDSWITH(expression1,expression2)

示例

ENDSWITH('abc','abcd')，结果为假。

ENDSWITH('abc','Dabc')，结果为真。

STR函数

由数字数据转换来的字符数据。

语法

STR ( float_expression [ , length [ , decimal ] ] )

参数

float_expression

是带小数点的近似数字 (float) 数据类型的表达式。不要在 STR 函数中将函数或子查询用作 float_expression。

length

是总长度，包括小数点、符号、数字或空格。默认值为 10。

decimal

注释

float_expression 在指定长度内右对齐，长的 float_expression 则截断为指定的小数位数。例如，STR(12,10)
输出的结果是 12，在结果集内右对齐。而 STR(1223, 2) 则将结果集截断为 **。可以嵌套字符串函数。

## 如何定义统计条件

Source page: `howto_design_formula_of_stat.htm`

统计方式分求值、计数、最大、最小、平均、求和六种。

所有记录：如果选中，表示统计所有数据包括当前记录和历史记录；否则仅统计当前最后一条记录。（注：所有记录在全表条件中定义）

## 规则设置

Source page: `automatic_rules.htm`

### 规则设置

人力资源系统允许用户配置计算规则和校验规则，以便在录入时自动执行数据校验或计算，保证业务数据的有效性、准确性，避免非法数据进入系统。

计算规则：在离开相关编辑项目后，如果该项目发生变化，系统自动执行计算规则，并将结果写入指定的项目。相关项目指计算规则内容中涉及的项目。

校验规则：在离开相关编辑项目或者保存时，系统自动执行校验规则，如果校验结果为假，则提示录入错误。

规则分两层：数据字典层（信息结构）、业务层（业务单据）。

-

## 人事选项

Source page: `renshixuanxiang.htm`

### 人事选项

人事选项内分为六个页签：基本参数、权限参数、编制控制参数、黑名单选项、自定义人事业务、其他。

基本参数设置人员处理的控制选项，以及员工自助、经理自助所能处理的人事申请，和入职登记、调动登记、离职登记所能处理的业务范围。

权限参数页签内可以设置人事管理模块、劳动合同模块、考勤管理模块、薪资管理模块、保险福利模块是否需要启用部门权限；若相应产品的功能节点不启用部门权限，操作员可以看见全部部门的数据。若相应产品的功能节点启用了部门权限，对于有录入权限的部门操作员可以编辑数据，对于只有查询权限的部门只能进行数据的查看。

编制控制参数内可设置人事模块和招聘需求是否需要启用编制控制。

黑名单选项可设置系统是否启用黑名单。

自定义人事业务参数中可设置系统是否启用自定义人事业务。

其他参数中可设置组织机构树的展现形式，以及单据进入方式和系统是否启用条码扫描生单。

【操作说明】

基本参数页签

-

允许人员档案中中直接增加人员

若勾选，则可在人员档案中新增人员；若不勾选，则人员档案的增加按钮置灰，只能通过入职登记审核后生成人员。

-

允许入职登记中直接增加人员

若勾选，则可在入职登记中手工增加入职人员；若不勾选，则只能通过录用申请、重新入职申请、应聘单生成入职登记人员。

-

允许兼职职位的职级作为最高职级

若勾选，则任职情况中显示最高职级栏目，如果人员任职情况中的兼职任职记录标记为最高职级，则保存人员时，此兼职任职的职级、职等即为人员档案基本信息的职级、职等；

若不勾选，则任职情况中不显示最高职级栏目，保存人员时，任职情况中当前主任职的职级、职等即为人员档案基本信息的职级、职等。

-

重新入职人员生成新的人员档案

若勾选，重新入职人员审核后生成一个新的人员；若不勾选，则重新入职人员审核后覆盖原有人员信息。

-

员工自助可处理的人事申请

转正：若勾选，员工自助-人事申请中显示转正申请节点，员工可填写本人的转正申请；若不勾选，则员工自助-人事申请中不显示转正申请节点。

调动：若勾选，员工自助-人事申请中显示调动申请节点，员工可填写本人的调动申请；若不勾选，则员工自助-人事申请中不显示调动申请节点。

离职：若勾选，员工自助-人事申请中显示离职申请节点，员工可填写本人的离职申请；若不勾选，则员工自助-人事申请中不显示离职申请节点。

-

经理自助可处理的人事申请

转正：若勾选，经理自助-人事申请中显示转正申请节点，经理可填写部门下属人员的转正申请；若不勾选，则经理自助-人事申请中不显示转正申请节点。

调动：若勾选，经理自助-人事申请中显示调动申请节点，经理可填写部门下属人员的调动申请；若不勾选，则经理自助-人事申请中不显示调动申请节点。

离职：若勾选，经理自助-人事申请中显示离职申请节点，经理可填写部门下属人员的离职申请；若不勾选，则经理自助-人事申请中不显示离职申请节点。

-

入职登记可处理的业务范围:薪资、福利、合同

勾选薪资、福利、或合同业务后，入职登记界面中显示相应的业务信息，可对入职人员进行此业务处理。

-

调动登记可处理的业务范围:薪资、福利、合同、业务员

勾选薪资、福利、合同、或业务员业务后，调动登记界面中显示相应的业务信息，可对调动人员进行此业务处理。

-

离职登记可处理的业务范围:薪资、福利、合同

勾选薪资、福利、合同、或业务员业务后，离职登记界面中显示相应的业务信息，可对离职人员进行此业务处理。

权限参数页签

-

产品是否允许设置启用部门权限

只有在【数据权限控制设置】内启用了部门权限，才能够选择具体产品的功能节点是否启用部门权限。对于福利产品，还能够选择是否启用地区权限，对于在权限参数内是否允许进行启用的配置与是否允许启用部门权限的配置相同，需要在【数据权限控制设置】内启用福利地区权限。

-

启用部门权限的后的控制

若相应的产品选择启用部门权限，操作员登录到具体产品时，只能查看到有权限部门的数据。若要修改数据，需要有相应部门的录入权限。（在【数据权限分配】节点内对于不同的部门是否具有查询还是录入权限）

若选择为启用或仅提示，增加招聘需求时，当职位的拟招聘人数大于当前的部门、职位可用编制数时会不允许保存或给出提示。

### 如何定义校验规则

人力资源系统预置大量的表，其中有部分表或字段可以被删除；为避免因用户删除表或字段而导致为这些表编写的特殊业务规则出错，系统提供了由用户配置业务校验规则的功能。

日期常量（格式）：#yyyy-mm-dd# 或者 #yyyy/mm/dd#。

注释：分行注释//、块注释{}。

### 如何使用记事簿

1. 信息提示功能

用户在进行系统登录后，如果有对该用户的提示信息，系统会自动弹出提示信息窗口进行提示。

因为有一些信息可以在一段时间内提示，如果用户不希望继续提示目前所提示的信息，用鼠标单击&#8220是否显示&#8221复选框，去掉标志即可。如果提示信息有多页，可以通过拖曳垂直滚动条进行查看。

2. 记事簿的维护

-

如何新增提示信息

单击〖增加〗按钮，或点击鼠标右键，弹出快捷菜单，再用鼠标单击【增加】菜单，屏幕显示增加界面，界面中各项栏目的内容如下:

-

提示日期：即进行提示的时间。

-

提示事项：即提示内容。

-

执 行 人：即被提示人，如果不选择，表示提示所有登录系统的操作员。

-

控制天数：即提示的时间范围，如选择5天，则表示该提示事项从提示日期起5天内有效。

输入完上述信息后，用鼠标单击〖增加〗继续增加提示信息或〖关闭〗按钮保存新增信息并返回。
