### 能力域（L1）说明

| 能力域（L1） | 说明 | 核心制度依据 |
|-------------|------|-------------|
| 项目策划与启动管理 | 覆盖项目从商业论证后到正式启动的全流程策划，含启动文件编制、团队组建、阶段划分 | GLTX-XM-07-A、项目启动管理程序 |
| 生产计划与排产管理 | 三层计划体系（年度→月度→日计划）的编制、下达、调整和考核，以及排罐、表面处理等专项排产 | GLTX-XM-03-A、GLTX-XM-04-A、生产计划管理程序 |
| 项目进度与交付管理 | 进度监控、考核、产品包装设计/实施/发运全流程，以及跨工序横向交付协调 | GLTX-XM-01-A、GLTX-XM-02-A |
| 项目质量与技术管理 | 原材料/产品质量管理、材料代用、紧急放行、随炉件等质量技术活动 | GLTX-XM-01-A、产品紧急放行管理程序 |
| 项目成本与存货管理 | 目标成本测算与核算、存货从计划到处置的全生命周期管理 | GLTX-XM-01-A、GLTX-XM-05-A |
| 项目风险管理 | 风险识别、评估、应对、监控与复盘的全周期管理 | GLTX-XM-06-A |
| 工装业务联合管理 | 沈阳子公司与总部（景德镇）跨区域工装业务全生命周期的联合运作管理 | GLTX-XM-08-A |

## 二、MDM 建设要求

以下为从项目管理部制度文件中识别的主数据对象及建设建议。MDM 为后台数据治理平台，非员工操作前端系统，以下对象需在 MDM 中建立主数据标准。

### 2.1 项目主数据

| 数据对象 | 说明 | 关键属性 | 来源依据 |
|----------|------|----------|----------|
| 项目 | 公司与客户签订合同对应的项目实体 | 项目代号、项目名称、客户、合同编号、项目类型（批产/研制）、项目状态（启动/执行/收尾/关闭）、项目经理 | GLTX-XM-07-A §5.1.1 |
| 项目启动令 | 项目正式启动的授权文件 | 项目编号、项目简介、可交付成果、授权管理者、里程碑计划、资源需求、预算目标、质量目标、风险管理原则 | GLTX-XM-07-A §5.1.4 |
| 项目阶段 | 项目生命周期阶段划分 | 项目编号、阶段名称（并行工程/工艺准备/生产准备/PPV/FPQ/批产）、阶段起止时间、转阶段评审结果 | GLTX-XM-07-A §5.4 |
| 项目工作包 | 项目工作分解结构最低层级 | 项目编号、工作包编码、工作包名称、所属阶段、负责部门、计划起止时间、成本预算 | 项目启动管理程序 §6 |
| 里程碑节点 | 项目关键进度控制点 | 项目编号、里程碑名称、计划日期、实际日期、状态（未开始/进行中/已完成/延期）、责任部门 | GLTX-XM-01-A §5.2.2.1 |

| 数据对象 | 说明 | 关键属性 | 来源依据 |
|----------|------|----------|----------|

| 月度二层计划 | 月度排产计划（含物料/专项/批产子计划） | 月份、项目编号、计划类型（物料/专项/批产）、零件图号、工序路线、计划起止日期 | GLTX-XM-03-A §5.2 |
| 三层日计划 | 班组级每日作业计划 | 日期、班组编号、零件图号、工序号、计划数量、计划工时、执行人 | GLTX-XM-03-A §5.3 |
| 罐前计划 | 热压罐排产计划 | 罐号、固化程序、排罐日期、零件图号、投罐数量、固化时间、投影仪占用时间 | 内部排罐管理程序 §4-§6 |

## 三、部门待确认事项（MDM 相关）

1. **项目代号标准化**：当前各项目使用不同代号体系（S19、ARJ 等），建议在 MDM 中统一项目主数据编码规则。
2. **计划编码体系**：三层计划当前以 Excel 管理，缺少系统化编码，建议在 MDM 中建立计划编号规则。
3. **存货台账数字化**：GLTX-XM-05-A 规定了完整的存货管理流程，但当前是否已有系统支撑（ERP/手工）需部门确认。
4. **风险清单模板化**：GLTX-XM-06-A 要求建立风险清单和档案，当前是否使用标准模板需确认。
5. **工装主数据归属**：GLTX-XM-08-A 涉及跨区域（沈阳-景德镇）业务，工装主数据的管理归属（总部/子公司）需明确。
