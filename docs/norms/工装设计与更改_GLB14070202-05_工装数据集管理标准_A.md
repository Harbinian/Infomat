# 5  规定

## 5.1 工装数据集来源

工装数据集主要来源于顾客提供、自行设计、翻译设计、翻译复制等。

> **English:** The tooling dataset mainly come from customers, Self-design, Translation Design, Translation and Duplication, etc.

## 5.2  编号原则

每一个功能独立的工装都应有单独的工装图号，效率工装图号相同，但应有单独的系列号加以区分。每套工装数据集只能有一个图号，不得重复使用，作废的图号不得再用。

> **English:** Each tooling with independent functions shall have a separate tooling drawing number. The efficiency tooling drawing number is the same, but it should be distinguished by a separate serial number. Only one single number is available for every set of tooling drawings, with no repeated use allowed. An obsolete drawing number shall no longer be used.

## 5.3  编号方法

> **English:** □-ZH-□□□□-S□N

> **English:** Shop's self-made tooling code (non-self-made tooling is not applicable to this item)

> **English:** Code of designing and requesting department

### 5.3.1  设计、申请单位代号按公司机构代码的规定执行。

> **English:** The codes of designing and requesting departments shall accord with Corporate Organizations Codes.

### 5.3.2  工装识别号：是工程图号和分号，也可以是规定的其它图号和分号。同一工装重新设计，原工装不作废，在工装识别号后加A、B、C等。

> **English:** Tooling Identifier: referred to the engineering drawing number and semicolon. It can also be other drawing numbers and semicolons as specified. Redesign of the same tool shall not obsolete the original tooling, and the tooling identifier is to be suffixed with A……

### 5.3.3  工装类别代码：是由一组表示该工装功能或它所执行的工作种类的字母组成，通常是工装英文名称的缩写（见附录A）。

> **English:** Tooling Type Code: consisting of a group of letters indicating the function of this tooling or the type of work this tooling performs. It is usually the acronym of the English tooling nomenclature (refer to Appendix A).

### 5.3.4  工装用途首码：表示工装的用途（见附录B）。

> **English:** Tooling Purpose Prefix: indicating the purpose of the tooling (Refer to Appendix B).

### 5.3.5  工装顺序号：通用工装从0001顺延，省略工装识别号、工装

类别代码、工装用途首码。当一系列工装都有相同的工装类别代码，且用于同一个零件的不同工序时，附加序列首号表示使用顺序，用2，3，4等（第1号工装顺序号1省略）。如：

第1号工装：FAJ5-50000-1

Tooling No. 1: FAJ5-50000-1

第2号工装：2FAJ5-50000-1

Tooling No. 2: 2FAJ5-50000-1

第3号工装：3FAJ5-50000-1

Tooling No. 3: 3FAJ5-50000-1

> **English:** Tooling Sequential Number: When a series of tooling bear the same tooling type code, and are used in different operations of the same part, then the Tooling Sequential Number is supplied additionally to show the sequence of operations with 2, 3, 4……(Sequential No 1 is omitted). Example:

> **English:** Tooling No. 1: FAJ5-50000-1

> **English:** Tooling No. 2: 2FAJ5-50000-1

> **English:** Tooling No. 3: 3FAJ5-50000-1

### 5.3.6  工装顺序号、工装用途首码和工装类别代码的最大总位数为6个字符。

> **English:** The maximum total number of digits in any tooling sequence number, tooling purpose prefix and tooling type code shall not exceed 6 characters.

### 5.3.7  组合夹具代号仅限于在工装制造采用组合夹具拼装时使用。

> **English:** Code of setting-up fixtures shall only be applicable to assembling the toolings by setting-up fixtures.

### 5.3.8  项目代码按GLC231007中的附录A的规定（有特殊要求的除外）。

> **English:** Program code shall be in accordance with the requirements in Appendix A of GLC231007, unless otherwise specified.

### 5.3.9  工装图样编号示例见附录C。

> **English:** Refer to Appendix C for examples of tooling drawing numbering.

> **English:** The drafting requests, numbering principles and revision management of tooling technique documents should comply with the regulation in GLC231007.

### 5.6.1  工装图样应符合本标准的规定。

> **English:** Tooling drawing should comply with this procedure regulation.

### 5.6.2  工装数据集编号应符合本标准的规定。

> **English:** Tooling Dataset code should comply with this procedure regulation.

### 5.6.3  如顾客对工装编号有特殊要求的，按顾客要求执行。

> **English:** The customers' requirements shall be respected if they have established special requirements for numbering of tools.

> **English:** Discussion with standardization department is necessary if increase (or decrease) the group code.
