# 行政人事部部门-能力-流程-系统映射关系

> 来源：`docs/norms/行政人事部业务资料/`
> 文件范围：共 54 个资料文件（.docx 27，.txt 27）。
> 本次口径：`部门（D1）→ 能力域（L1）→ 业务能力（L2）→ 业务流程（L3）→ 应用系统（S1）`；业务行为（A1）作为审核明细并入本文件。
> 系统边界：应用系统（S1）只使用 OA、MES、PLM、ERP；MDM不作为应用系统节点，只在 `行政人事部能力层与MDM建设要求.md` 中说明。
> 状态：重做版，待行政人事部确认。

---

## 使用方式

1. 先看“全域映射”，确认能力域（L1）、业务能力（L2）、业务流程（L3）的命名是否贴合制度标题、条款标题和部门实际职责。
2. 再看“业务行为（A1）明细”，确认执行角色、触发情景、前置条件、验收标准是否能被制度原文、流程图或上下文支撑。
3. 对“核验提醒”中标出的角色泛化、验收标准缺口、流程图依据、条款待补等问题，由部门在“部门确认意见/是否调整/调整建议”列反馈。
4. 系统建议只用于信息化蓝图讨论，不代表现有系统已经具备该功能。
