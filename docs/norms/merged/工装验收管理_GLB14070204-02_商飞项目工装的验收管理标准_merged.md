# 商飞项目工装的验收管理标准

# 1  范围

本管理标准规定了工装的验收要求。

本管理标准适用于商飞项目生产。

本管理标准依据SR0006和GLC14070204的要求制定。

# 5  规定

## 5.1 在工装验收过程中，对于在生产现场安装的装配类工装（包括装配检验工装），工装使用单位的工装检验人员需现场通过便携式数字化测量设备检验工装工具球点/面的正确性，在该测量设备出具的测量报告封面上盖检验印章并注明日期。

## 5.2 中国商飞控制的工装项目在新制合格并通过验收后，需由中国商飞质量代表检查工装验收依据及工装实物，合格后方可进行产品的生产。

## 5.3 对于中国商飞控制工装项目，除非另有委托授权，否则新制、安装地点改变、重新启用、或者改制的Ⅱ类工装和作了重大返修的Ⅰ类工装均需由中国商飞代表参与验收，合格后方可投入生产使用。
