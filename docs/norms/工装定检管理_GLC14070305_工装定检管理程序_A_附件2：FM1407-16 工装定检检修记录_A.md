# 填写说明 Instruction for Filling

（1）：工装定检测量人员填写工装图号, 如为效率工装，在工装图号后加套数信息，即“图号加（第X套）”。

Periodical tooling inspection measurement operator fills in tooling drawing number. In case of duplicated tooling, fills in the number of sets of tooling number, such as "tooling number plus （X set）".

（2）：工装定检测量人员填写工装系列号。工装无系列号，此栏填写“N/A”或“/”

Periodical tooling inspection measurement operator fills in the tooling serial number. If the tooling has no serial number, fill in "N/A" or "/" in this column.

（3）：工装定检测量人员填写派工号。

Periodical tooling inspection measurement operator fills in the working number.

（4）：工装定检测量人员填写工装温度，如多次测量工装温度，填写任意一次的工装温度。

Periodical tooling inspection measurement operator fills in the tooling temperature. If tooling temperature is measured several times, one of measured temperature should be filled.

（5）：工装定检测量人员填写工装版次

Periodical tooling inspection measurement operator fills in tooling revision.

（6）：工装定检测量人员填写标尺的理论值。

Periodical tooling inspection measurement operator fills in certified value of scale bar.

（7）：工装定检测量人员填写使用数字化测量设备完成工装定检测量的日期。

Periodical tooling inspection measurement operator fills in date of completion of periodical tooling inspection using digital measurement device.

（8）：工装定检的测量人员签字并注明日期。

Periodical tooling inspection measurement operator fills signature and notes date.

（9）：工装定检的测量人员填写测量起始和结束阶段标尺的测量值，如果测量有多个站位，填写任一站位的起始和结束阶段标尺测量值。

Periodical tooling inspection measurement operator fills in measured scale bar values of start and end stage of measurement. If there are several station in the measurement, any one of measured scale bar values of start and end stage of measurement shall be filled.

（10）：工装定检测量人员填写测量设备的编号。

Periodical tooling inspection measurement operator fills in the number of measurement device.

（11）：测量检验人员盖章并注明日期。

Measurement inspector stamps and notes date.

（12）：工装定检测量人员填写工装工具球的名称。

Periodical tooling inspection measurement operator fills in name of tooling ball.

（13）：工装定检测量人员填写工装工具球的理论值，包括工装基准实测值转化成的理论值。

Periodical tooling inspection measurement operator fills in theoretical value of tooling ball, includes tooling datum value that are transformed by measured value.

（14）：工装定检测量人员填写工装工具球的公差。

Periodical tooling inspection measurement operator fills in tolerance of tooling ball.

（15）：“调整前测量值和偏差值”是指工装定检时，应先在不对工装进行返修的情况下，对工装进行测量所得的测量值和偏差值。工装定检测量人员将相应值填入此栏。

"Measured value and error value before adjustment" means tooling shall be measured before repair. Periodical tooling inspection measurement operator fills in relevant measured value and error value in this column.

（16）：“调整后偏差值”是指工装定检时，已对工装经过返修的情况下，对工装进行测量所得的偏差值。工装定检测量人员将相应值填入此栏。

"Error value after adjustment" means the error value after tooling repair. Periodical tooling inspection measurement operator fills in relevant error value in this column.

（17）：工装定检测量人员填写该记录共几页，当前页面为第几页。

Periodical tooling inspection measurement operator fills in total pages and current page.
