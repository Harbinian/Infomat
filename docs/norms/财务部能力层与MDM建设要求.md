# 财务部 · 能力层与MDM建设要求

## 概述

本文档从财务部6个GLTX-CW程序文件中提取稳定的主数据对象，作为MDM（主数据管理）建设需求输入。MDM定位为后台数据治理平台，不替代ERP/OA等员工面向前端系统。

## 一、能力层架构

### 能力域（L1）与业务能力（L2）一览

| 能力域（L1） | 业务能力（L2） | 业务流程（L3）数 | 核心主数据对象 |
|-------------|---------------|-----------------|---------------|
| 成本管理 | 成本核算管理 | 5 | 会计科目、成本中心、成本要素、物料、BOM、生产订单、工时定额 |
| 成本管理 | 成本测算管理 | 2 | 工种、设备、小时费率、废品率 |
| 资产管理 | 固定资产管理 | 5 | 固定资产、资产类别、折旧方法、保险险种 |
| 资产管理 | 无形资产管理 | 1 | 无形资产、知识产权类别 |
| 资金管理 | 银行账户与存款管理 | 2 | 银行账户、账户类别 |
| 资金管理 | 现金与票据管理 | 2 | 票据类别 |
| 资金管理 | 资金计划与备用金管理 | 2 | 资金计划模板 |
| 费用报销管理 | 差旅费管理 | 2 | 费用类型、差旅标准、职等 |
| 费用报销管理 | 财务报销与付款管理 | 2 | 付款类型、审批流模板 |

### 能力层与系统关系

```
财务部（D1）
├── 成本管理 ──────── ERP（核算）、MES（执行数据）、OA（定额审批）
├── 资产管理 ──────── ERP（台账折旧）、OA（处置审批）
├── 资金管理 ──────── ERP（收付核算）、OA（计划审批）
└── 费用报销管理 ──── OA（申请审批）、ERP（入账付款）
```

## 二、主数据对象识别

### 2.1 会计科目（COA）

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-01-A §5.4.2 |
| 描述 | 生产成本核算使用的科目体系，含一级科目和明细科目 |
| 关键字段 | 科目编码、科目名称、科目类别（资产/负债/权益/成本/损益）、余额方向、是否末级 |
| 核心科目举例 | 生产成本、直接材料、直接人工、制造费用、委外加工费、存货-产成品 |
| 跨系统引用 | ERP（核算引擎）、OA（报销科目映射） |
| MDM治理范围 | 科目编码规则、科目名称标准、科目新增/停用/变更审批流程 |

### 2.2 成本中心

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-01-A §5.2.2、§5.4 |
| 描述 | 成本费用归集的责任单元，含各复材车间和职能部门 |
| 关键字段 | 成本中心编码、成本中心名称、所属部门、成本中心类型（生产/管理/销售）、生效日期、失效日期 |
| 跨系统引用 | ERP（成本归集）、OA（费用报销归属） |
| MDM治理范围 | 成本中心编码规则、与组织单元的映射关系、新增/拆分/合并流程 |

### 2.3 成本要素

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-01-A §5.3.3、§5.4.3；GLTX-CW-06-A §5.1 |
| 描述 | 成本构成的分类维度，用于成本归集和分析 |
| 关键字段 | 成本要素编码、成本要素名称、要素类别（直接材料/直接人工/制造费用/委外加工费/废品损失/期间费用）、对应科目 |
| 跨系统引用 | ERP（成本核算）、MES（工时和物料数据标签） |
| MDM治理范围 | 成本要素编码标准、与会计科目的映射、要素新增/调整流程 |

### 2.4 固定资产分类与编码

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-02-A §5.1 |
| 描述 | 固定资产的类别体系和编码规则 |
| 编码规则 | 格式：年份(2位) + 月份(2位) + 类别代码(2位) + 序列号(4位)，如 `24 06 02 0002` |
| 类别代码 | 01房屋、02建筑物、03机器设备、04电子设备、05运输设备、06办公家具、07后勤家具（可由财务部扩展） |
| 关键字段 | 资产编码、资产名称、规格型号、生产厂家、功率、使用部门、购置日期、原值、折旧方法、使用年限、残值率、存放位置 |
| 跨系统引用 | ERP（固定资产模块）、OA（资产标签打印）、MES（设备台账） |
| MDM治理范围 | 资产类别代码维护、编码规则统一、资产编码唯一性校验 |

### 2.5 无形资产分类

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-02-A §5.5、术语定义 |
| 描述 | 公司拥有或控制的无实物形态的可辨认非货币性资产 |
| 类别 | 土地使用权、专利权、专有技术、商标权、著作权、特许经营权 |
| 关键字段 | 资产编码、资产名称、资产类别、取得日期、原值、摊销方法、摊销年限、权属证书编号、保管部门 |
| 跨系统引用 | ERP（无形资产模块）、OA（知识产权文档管理） |
| MDM治理范围 | 无形资产分类标准、编码规则、权属证书台账 |

### 2.6 银行账户

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-03-A §5.1 |
| 描述 | 公司开立的银行结算账户 |
| 类别 | 基本账户、一般账户、专项账户（贷款账户、保证金账户、募集资金账户） |
| 关键字段 | 账户编号、账户全称、开户银行、账号、账户类别、币种、开户日期、账户状态（正常/已销户/久悬）、是否网银 |
| 跨系统引用 | ERP（银行对账、资金管理）、OA（开户/销户审批） |
| MDM治理范围 | 银行账户主数据统一管理、账户状态变更流程、与会计科目映射 |

### 2.7 票据类别

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-03-A §5.5 |
| 描述 | 公司收到和开具的票据分类 |
| 类别 | 银行承兑汇票、商业承兑汇票、支票等 |
| 关键字段 | 票据编号、票据类别、出票人、收票人、票面金额、出票日期、到期日期、状态（持有/已背书/已贴现/已到期） |
| 跨系统引用 | ERP（应收/应付票据） |
| MDM治理范围 | 票据台账标准字段定义 |

### 2.8 费用类型

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-04-A §5.2；GLTX-CW-05-A §5.1 |
| 描述 | 报销和付款的费用分类 |
| 类别 | 城际交通费、市内交通费、住宿费、误餐补助、打车费、办公费、快递费、招待费、服务费、货款 |
| 关键字段 | 费用类型编码、费用类型名称、所属大类、适用报销标准、对应会计科目 |
| 跨系统引用 | OA（报销申请分类）、ERP（费用科目映射） |
| MDM治理范围 | 费用类型标准化、报销标准配置、与会计科目映射 |

### 2.9 差旅标准

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-04-A §5.2、附件 |
| 描述 | 按职等和地区分类的差旅费用限额标准 |
| 维度 | 职等（公司级干部/中层干部/一般工作人员）、地区（一线城市/其他地区/境外）、费用类别（交通/住宿/误餐补助/市内交通津贴）、出差类型（短期/长期） |
| 关键字段 | 标准编号、职等、地区分类、费用类别、限额金额、币种、生效日期、失效日期 |
| 跨系统引用 | OA（报销限额自动校验）、ERP（费用超标预警） |
| MDM治理范围 | 差旅费用标准主数据维护、版本管理 |

### 2.10 职等分类

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-04-A §5.2.1 |
| 描述 | 用于费用标准和审批权限的职等划分 |
| 分类 | 公司级干部（副总及以上）、中层干部（部门/车间助理级及以上）、一般工作人员 |
| 关键字段 | 职等编码、职等名称、级别顺序、适用费用标准 |
| 跨系统引用 | OA（审批路由、费用限额匹配）、ERP（权限控制） |
| MDM治理范围 | 与组织/岗位主数据的职等字段对齐，确保差旅标准正确匹配 |

### 2.11 工种分类

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-06-A §5.3 |
| 描述 | 用于小时费率测算的工种划分 |
| 关键字段 | 工种编码、工种名称、技能等级、所属车间 |
| 跨系统引用 | ERP（人工成本测算）、MES（工时采集） |
| MDM治理范围 | 工种编码标准化、与岗位体系的映射 |

### 2.12 设备分类

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-06-A §5.2 |
| 描述 | 用于设备台时成本率测算的设备分类 |
| 关键字段 | 设备编码、设备名称、设备类别、所属车间、折旧年限、原值 |
| 跨系统引用 | ERP（设备成本率计算）、MES（设备运行台时采集） |
| MDM治理范围 | 与固定资产分类的对齐、设备编码唯一性 |

### 2.13 小时费率

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-06-A §5.1、§5.9 |
| 描述 | 测算得出的设备和人工单位时间成本率，用于产品报价和经营分析 |
| 构成 | 设备成本率 + 人工成本率 + 制造费用分摊率 + 废品损失 + 期间费用 + 税金及附加 + 利润 |
| 关键字段 | 费率编号、费率类型（设备/人工/综合）、适用工种或设备、费率值、币种、测算基准日期、有效期、审核状态 |
| 跨系统引用 | ERP（报价模块、成本测算模块） |
| MDM治理范围 | 费率版本管理、审核发布流程、年度复核机制 |

### 2.14 废品率

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-06-A §5.6 |
| 描述 | 零件或工序的历史废品率统计值，用于成本测算 |
| 关键字段 | 零件编码/工序编码、废品率、统计周期、统计样本量 |
| 跨系统引用 | ERP（成本测算）、MES（废品数据来源） |
| MDM治理范围 | 废品率数据质量校验、历史版本追溯 |

### 2.15 审批流模板

| 属性 | 说明 |
|------|------|
| 来源 | GLTX-CW-05-A §6 |
| 描述 | 报销与付款的审批流程定义 |
| 标准流程 | 申请人提交→财务审核签字→财务部长审批→副总审批→总经理审批→董事长审批→出纳付款 |
| 关键字段 | 流程编码、流程名称、审批节点列表、节点审批人角色、超时规则、适用业务类型 |
| 跨系统引用 | OA（流程引擎） |
| MDM治理范围 | 审批流模板版本管理、角色映射维护 |

## 三、MDM建设优先级建议

| 优先级 | 主数据对象 | 理由 |
|--------|-----------|------|
| P0 | 会计科目 | 所有财务核算的基础，ERP上线首需 |
| P0 | 固定资产分类与编码 | 编码规则已定义（CW-02 §5.1），可直接落地 |
| P1 | 成本中心 | 与组织单元关联紧密，需与行政人事部组织主数据协同 |
| P1 | 成本要素 | 成本核算和分析的基础分类 |
| P1 | 费用类型 | 报销和付款的入口分类，影响OA和ERP双向 |
| P1 | 差旅标准 | 影响全员费用报销，变更频繁需版本管理 |
| P2 | 银行账户 | 主数据量小但合规要求高 |
| P2 | 工种分类 | 依赖行政人事部岗位主数据 |
| P2 | 小时费率 | 年度复核型数据，变更频率低 |
| P3 | 票据类别 | 台账级数据，治理紧迫性较低 |
| P3 | 废品率 | 统计型参数，可后置 |
| P3 | 审批流模板 | 属OA流程引擎配置，非传统主数据范畴 |

## 四、跨部门主数据依赖

| 财务部主数据对象 | 依赖部门 | 依赖对象 |
|----------------|---------|---------|
| 成本中心 | 行政人事部 | 组织单元（org_unit）、部门 |
| 职等分类 | 行政人事部 | 岗位、职等 |
| 工种分类 | 行政人事部 | 岗位、技能等级 |
| 设备分类 | 运维安环部、物资保障部 | 设备台账 |
| 物料/原材料 | 物资保障部、工程技术部 | 物料编码、BOM |
| 工时定额 | 经营发展部 | 工时积分定额标准 |
| 差旅标准 | 行政人事部 | 职等 |
| 废品率 | 质量安环部 | 废品统计 |

## 五、审查待确认事项

| 序号 | 事项 | 说明 |
|------|------|------|
| 1 | 固定资产类别扩展 | CW-02 §5.1.1 注明"如类别不足可由财务部增加"，需确认是否已有扩展类别 |
| 2 | 会计科目编码体系 | 源文件未定义科目编码规则，需确认是否沿用用友ERP科目编码体系 |
| 3 | 小时费率复核周期 | CW-06 §5.9 规定"每年至少复核一次"，需确认是否纳入MDM定期数据质量检查 |
| 4 | 差旅标准版本 | CW-04 附件含详细境外差旅标准表（含150+国家/地区），需确认MDM是否需要维护此级别粒度 |
