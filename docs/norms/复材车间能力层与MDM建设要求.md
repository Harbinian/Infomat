## 一、能力层分析

### 1.1 已覆盖的能力

| 能力域（L1）| 业务能力（L2）| 制度覆盖状态 |
|-----------|------------|:--:|
| 生产执行管控 | 班组排产管理 | 已覆盖（内部排罐管理程序） |
| 生产执行管控 | 在制品工序管理 | 已覆盖（横向工序管理方案） |
| 生产执行管控 | 随炉件与理化检测管理 | 已覆盖（随炉件移交规定） |
| 生产保障管理 | 内部物流管理 | 已覆盖（快递管理程序） |
| 生产保障管理 | 车辆调度管理 | 已覆盖（车辆使用规定） |

### 1.2 当前制度未覆盖但已知存在的能力

以下能力在关联部门的文档中被频繁引用，但复材车间侧尚无制度文件：

| 业务能力 | 证据来源（关联部门文档） | 说明 |
|---------|----------------------|------|
| 工装现场使用 | 物资保障部 GLC14070301《工艺装备使用管理》 | 复材车间为工装主要使用单位，现有制度仅有工装状态确认（排罐流程中），缺失：工装日常点检、故障上报、限用/禁用配合 |
| 工序检验配合 | 质量管理部 SYCXQMS-P5-07《产品检验管理程序》 | 操作者自检互检、专检配合、不合格品现场标识与隔离 |
| 设备操作与维护 | 运维安环部 GLC260507《设备设施运维管理》 | 设备日常操作、一级维护保养、报修申请 |
| 不合格品现场处理 | 质量管理部 SYCXQMS-P5-10《不合格品控制管理程序》 | 现场不合格品标识（挂签/粘签）、隔离（MRCC）、审理单发起 |
| 产品紧急放行申请 | 项目管理部《产品紧急放行管理程序》 | 复材车间为紧急放行的主要申请方 |
| 材料领用与退库 | 物资保障部、财务部 GLTX-CW-01-A | 车间领料、退料、物料消耗记录 |

## 二、MDM建设要求

### 2.1 主数据对象

| 主数据对象 | 当前状态 | 建设要求 |
|-----------|:------:|---------|
| **班组** | 未纳入MDM | 复材车间下设脱模/五坐标、无损检测/X光、表面准备、喷漆交付等班组，需建立班组主数据（编码、所属车间、班组长、工序类型） |
| **工序/工位** | 未纳入MDM | 罐前计划中涉及排罐固化时间、投影仪使用、出入罐准备等标准工时参数，需工序标准工时主数据支持产能核算 |
| **热压罐/关键设备** | 运维安环部管理 | 排罐需基于设备可用性和固化程序匹配，需设备产能日历和状态主数据 |
| **随炉件** | 未纳入MDM | 随炉件与生产批次绑定，需建立随炉件主数据（编号、关联批次/零件、出罐时间、理化检测状态） |
| **关键件** | 未纳入MDM | 横向工序管理中的关键件清单需与项目管理部的项目计划中的关键件定义保持一致 |

### 2.2 跨系统数据需求

| 数据流向 | 源系统 | 目标系统 | 说明 |
|---------|:-----:|:------:|------|
| 排罐计划 | MES | ERP | 排罐结果影响生产成本核算（热压罐运行成本分摊） |
| 开工条件 | OA | MES | 物料/工装/文件等跨部门确认结果同步至MES排罐模块 |
| 随炉件状态 | OA（移交群） | MES | 随炉件出罐→移交→理化结果状态关联生产批次 |
| 关键件进度 | MES | OA | 关键件工序进度同步至项目管理部计划跟踪 |

## 三、信息化建议

1. **排罐管理模块（MES）**：复材车间当前排罐依赖Excel表格和OA沟通，建议在MES中建设排罐管理模块，固化工序标准工时、设备日历、并罐规则，减少人工核算
2. **关键件跟踪看板（MES→OA）**：当前关键件问题跟踪表为Excel，建议以MES工序数据为基础，OA中展示关键件进度看板和问题看板
3. **随炉件管理（OA+MES）**：当前依赖微信群管理，建议将随炉件生命周期（出罐→移交→检测→结果）纳入系统化跟踪
