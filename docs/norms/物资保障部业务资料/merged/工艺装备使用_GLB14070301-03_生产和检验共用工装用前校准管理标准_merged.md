# 生产和检验共用工装用前校准管理标准

# 1  范围

本文件规定了生产和检验共用工艺装备（简称共用工装）检验前校准内容、方法与要求。。

本文件适用于公司的所有项目生产管理。

本文件依据GLC14070301制定。

> **English:** This document specifies the calibration content, methods, and requirements for production and inspection shared process equipment (referred to as shared fixtures) before inspection..

> **English:** This document applies to all project production management of the company.

> **English:** This document is developed based on GLC14070301.

# 4  术语和定义

## 4.1 共用工装

既用于加工制造产品，又用来检查验收产品的工装称为共用工装。

> **English:** The tooling used for both processing and manufacturing products, as well as inspecting and accepting products, is called shared tooling.

## 4.2 共用工装检验前校准

共用工装用于检验时，在使用前为证明其能作为检查产品是否合格的依据，采用简便实用的有效方法和手段（如目视、外观检查等）进行的校验。

> **English:** When using shared fixtures for inspection, in order to prove that they can be used as a basis for checking whether the product is qualified, simple and practical effective methods and means (such as visual inspection, appearance inspection, etc.) are used for verification before use.

# 5  规定

## 5.1  校准要求

### 5.1.1  用于钣金、机加、焊接、非金属、部件装配的共用工装，如敲检模、锉修检验模（夹具）、配套检验夹具、焊接检验夹具及生产和检验共用的装配工装，应进行检验前的校准工作（零件制造工装每批使用前；部件装配工装每架使用前）。

## 5.2  校准方法与内容

共用工装使用前，工装使用单位检验人员使用FM1407-120共用工装检验前校准表对工装进行校准，校准合格后方可使用。

> **English:** Before using the shared tooling, the inspection personnel of the tooling using unit shall calibrate the tooling using the FM1407-120 shared tooling pre inspection calibration table. Only after passing the calibration can it be used.

### 5.2.1  外观校准

（1）共用工装是否完整,有无缺件；

（2）共用工装是否损伤,有无压坑、变形、磨损、开裂；

（3）共用工装活动部位是否灵活，是否涂油防锈；

（4）共用工装零件边缘线及其它标注线是否清晰、完好。

> **English:** (1) Whether the shared tooling is complete and whether there are any missing parts;

> **English:** (2) Whether the shared tooling is damaged, whether there are pressure pits, deformations, wear, and cracks;

> **English:** (3) Whether the movable parts of the shared tooling are flexible and whether they are coated with oil for rust prevention;

> **English:** (4) Whether the edge lines and other marking lines of shared tooling parts are clear and intact.

### 5.2.2  批次校准

共用工装所生产的上批零、组、部件，有无因工装问题而影响装配的情况，若工装有问题是否已解决。

> **English:** Are there any issues with the shared tooling that may affect the assembly of the previous batch of parts, components, and assemblies? If so, have the tooling problems been resolved.

### 5.2.3  定检校准

共用工装按管理程序GLC14070305规定是否进行定检定查,记录是否齐全。

> **English:** According to the management procedure GLC14070305, whether the shared fixtures have undergone calibration checks and whether the records are complete.

## 5.3  校准流程

使用单位技术室技术员编制FM1407-47民机校准共用工装品种表，每批（架）次使用工装前，使用单位检验员按FM1407-47民机校准共用工装品种表检查工装实物，检查合格后使用单位检验员填写FM1407-120共用工装检验前校准表并将表归档备查。若检查不合格，使用单位技术室技术员按GLC14070303提出工装返修。

> **English:** The technical staff of the using unit shall prepare the FM1407-47 Civil Aircraft Calibration Shared Tooling Variety Table. Before using the tooling for each batch (rack), the inspector of the using unit shall inspect the physical tooling according to the FM1407-47 Civil Aircraft Calibration Shared Tooling Variety Table. After passing the inspection, the inspector of the using unit shall fill out the FM1407-120 Shared Tooling Pre Inspection Calibration Table and archive it for future reference. If the inspection is not qualified, the technical personnel of the using unit's technical room shall propose tooling repair according to GLC14070303.
