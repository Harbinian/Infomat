填写说明Instructions for Filling：

（1）-（9）由使用单位工艺员填写

(1) - (9) Filled in by the technologist of the user unit

（1） 填写操作类型，选填新建、换版。

Fill in the operation type, and select New and Version Change.

（2） 填写产品项目号，如S5A，S3B等。项目代号见MPG 040-02。

Fill in the product project code, such as S5A, S3B, etc. See MPG 040-02 for project code.

（3） 填写样板/数据集申请单编号。

Fill in the template/dataset application form number.

编号原则：项目代号－CY ×××××－× ××

Numbering principle: project code -	序号Serial number

# 机构代码Organization code

样板/数据集申请单代号(参见Q/1ADM-31) Code of sample/data set application form (see Q/1ADM-31)

（4） 填写版次。按A、B、C……依次排列（不允许使用I、O、S、X、Z）,首次申请为A版。样板/数据集申请单最新版次有效。

Fill in the revision. In order of A, B, C... (I, O, S, X, Z are not allowed), the first application is version A. The latest version of the template/dataset application form is valid.

（5） 填写使用单位名称，如零件制造中心等。

Fill in the name of the user, such as the parts manufacturing center.

（6） 填写工作包。

Fill in the work package.

（7） 填写使用此样板/数据集的产品图号。

Fill in the product drawing number using this template/dataset.

（8） 按需填写使用此样板/数据集的共用产品图号。

Fill in the common product drawing number using this template/dataset as required.

（9） 填写技术要求。要求列出样板/数据集设计和制造的依据，如工程数据集的编号和版次，工程图样的页次和版次，零件供应状态表，样板/数据集名称、样板代码等。

Fill in technical requirements. It is required to list the basis for the design and manufacture of the sample/data set, such as the number and revision of the engineering data set, the page and revision of the engineering drawing, the part supply status table, the name of the sample/data set, the sample code, etc.

（10） 样板/数据集使用单位工艺员签字。

The template/data set is signed by the technologist of the user unit.

（11） 样板/数据集使用单位技术室主任签字。

Signature of the director of the technical office of the user of the template/dataset.

（12） 样板/数据集使用单位技术副厂长签字。

Signature of the deputy technical director of the unit using the template/dataset.

（13） 技术办公室主管技术员签字。

Signature of the technician in charge of the technical office.

（14） 工装设计室设计员签字。

Designer of tooling design room signs.

（15） 工艺装备室主管签字。

Signature of the director of the process equipment room.

（16） 技术办公室主管副总工艺师签字。

Signature of the deputy chief technologist in charge of the technical office.
