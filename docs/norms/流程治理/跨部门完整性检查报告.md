# 跨部门完整性检查报告

> 版本：V1.0
> 生成日期：2026-06-01
> 前置输入：`跨部门流程识别报告.md` V1.1
> 方法：遍历已映射部门的A1表中所有非空 `输入来源部门` / `输出目标部门` 字段，逐条核对其在目标部门的覆盖状态
> 口径：只检查昌兴内部部门之间的交互完整性；外部实体（沈飞民机/客户/政府等）标注但不纳入风险评级

---

## 一、检查范围与状态定义

| 状态 | 含义 |
|------|------|
| **已映射-有对应** | 目标部门存在映射文档，且有覆盖该交互的 业务流程（L3）/业务行为（A1）|
| **已映射-待确认** | 目标部门存在映射文档，但交互覆盖情况需人工判断 |
| **已映射-待复核** | 目标部门已完成映射，但历史跨部门引用尚需逐条核对闭环 |
| **未映射-待建模** | 目标部门已确认将独立建模，但尚未完成 |
| **未映射-无文档** | 目标部门无映射文档且无制度文件 |
| **外部实体** | 指向沈飞民机、客户、供应商、政府等，不纳入内部完整性风险评级 |
