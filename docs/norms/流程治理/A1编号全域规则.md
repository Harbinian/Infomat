# A1编号全域规则

> 适用范围：`docs/norms/` 下各部门 `部门-能力-流程-系统映射关系.md`、对应部门桑基图页面、`pmo/dashboard.html` 的跨部门衔接风险表。

## 一、统一格式

业务行为（A1）编号统一采用：

`{部门拼音缩写}-L3-{两位业务流程序号}-A{两位业务行为序号}`

示例：

| 部门 | 示例 |
|---|---|
| 经营发展部 | `JY-L3-32-A03` |
| 运维安环部 | `YW-L3-18-A07` |
| 项目管理部 | `XM-L3-01-A03` |

## 二、部门拼音缩写

| 部门 | 缩写 |
|---|---|
| 经营发展部 | JY |
| 行政人事部 | XZ |
| 物资保障部 | WZ |
| 财务部 | CW |
| 质量管理部 | ZL |
| 项目管理部 | XM |
| 复材车间 | FC |
| 运维安环部 | YW |

## 三、编号原则

- `L3-{两位业务流程序号}` 取部门内业务流程（L3）的稳定顺序号，不直接沿用 `0101`、`0702`、`ZL-02-09` 等部门内部旧分组码。
- `A{两位业务行为序号}` 保留该 L3 下业务行为的顺序号。
- 源文件、部门桑基图、跨部门风险表必须使用同一 A1 编号；驾驶舱不得再临时补前缀。
- 若历史报告中的 A1 编号在当前部门源表中找不到，不新造编号，标记为“待核实”。

## 四、与旧编号的关系

旧编号只作为内部溯源线索保留在历史文本中，不再作为跨部门主键使用。

| 旧样式 | 新样式 |
|---|---|
| `0101-A03` | `JY-L3-01-A03` / `XM-L3-01-A03` 等，按来源部门确定 |
| `L3-18-A07` | `YW-L3-18-A07` |
| `ZL-02-09-A03` | `ZL-L3-37-A03` |
