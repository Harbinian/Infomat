### 3.2 引用工程技术部的情况

工程技术部是跨部门交互中出现频率较高的部门之一（多个已映射部门均频繁引用）。当前已建立首轮 DCM/BBM 正式映射、A1 明细、MDM 建设要求和部门桑基图；以下跨部门引用仍需逐条核验是否存在受控输出物传递，不能仅凭岗位协同或泛称自动填写输入来源部门/输出目标部门。

| 来源部门 | 引用场景 |
|---------|---------|
| 经营发展部 | 技术方案可行性评估、报价技术方案编制、工艺规程与工时定额衔接、技术条款审查、工程咨询/质疑处理 |
| 项目管理部 | BOM/技术方案、包装设计、材料定额、工时定额、技术判定与审批代用方案、开工评审 |
| 财务部 | 接收BOM用于成本核算、协同分析成本升降原因 |
| 质量管理部 | 归零管理故障定位分析、工程图纸目录编制 |
| 行政人事部 | 保密培训考核参与、离职办理确认、技术资料有效性管理 |
| 运维安环部 | 未直接引用，但涉及工艺/技术相关管控 |

**效果**：跨部门流程中指向工程技术部的交互已有目标侧流程骨架；后续重点从“补建目标部门”转为“核验受控传递、角色边界和应用承接入口”。应用承接按 PLM/PDM、PLM/工程项目管理、PLM/MBOM-CAPP、MES 等已确认口径展示，MDM 不作为应用系统（S1）。
