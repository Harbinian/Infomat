# 工程技术部能力层与MDM建设要求

> 来源：`docs/norms/工程技术部部门-能力-流程-系统映射关系.md`，以及本轮已回源的工程技术部资料包。
> 口径：MDM 作为跨流程、跨系统的数据治理基础设施，不作为应用系统（S1）节点；按部门确认口径和既有说明会 H5 口径，工程技术部产品设计和开发全生命周期统筹可纳入 PLM，PDM 作为 PLM 的产品数据管理模块，可承接工程数据、构型、设计数据集、EBOM、EDRN 和设计更改对象链；工程项目管理作为 PLM 模块，可承接产品设计阶段计划、任务分解、DRD进度、评审组织、行动项闭环、工艺网络计划、制造方案、装配协调和产能规划等过程对象；MBOM/CAPP 作为 PLM 一期能力，可承接制造数据、工艺路线、工序工步、定额、资源要求和结构化工艺规程；MES 承接关键工序、关重件和工艺过程的现场执行与记录闭环；MDM 负责对象编码、版本、状态、责任和追溯口径治理，不替代 PLM/MES 执行业务动作。
> 状态：首轮建设要求稿，待工程技术部确认。

---

## 一、能力层建设口径

本文件服务于工程技术部能力层审核和 MDM 建设讨论：先确认 `能力域（L1）→ 业务能力（L2）→ 业务流程（L3）` 是否准确，再判断哪些稳定对象需要纳入 MDM 治理。流程记录、审批单、评审材料和一次性过程表单不直接等同于主数据；只有被长期复用、跨流程引用、需要统一编码、版本、状态、责任和追溯关系的对象，才建议进入 MDM。

| 能力域（L1） | 业务能力（L2） | 业务流程（L3）数量 | 首轮 A1 数量 | 核心管理对象 |
|---|---|---:|---:|---|
| 产品设计和开发管理 | 产品设计全生命周期管理、产品设计策划、产品设计需求定义、产品设计需求确认、产品设计需求验证、概念定义阶段设计、初步定义阶段设计、详细定义阶段设计、设计评审、设计更改、工艺性审查 | 11 | 51 | 产品生命周期状态、需求、PBS、DRD、构型、工程数据、EBOM、AMO、评审和更改对象 |
| 制造工艺策划 | 制造工艺策划统筹、工艺网络计划管理、制造总方案管理、装配协调方案管理、产能控制管理 | 5 | 15 | 工艺策划输入输出、工艺网络计划、制造总方案、装配协调方案、产能基础数据和评估报告 |
| 制造工艺设计 | 制造工艺设计统筹、关键工序控制、关重件控制、工艺过程管控、零件制造工艺文件管控 | 5 | 15 | MBOM、关键特性、关键工序、关重件、工艺文件、制造记录和现场管控记录 |

## 三、跨域关联关系

```text
项目 / 产品
  ├─ PBS
  │  ├─ 产品需求清单
  │  │  ├─ 专业需求清单
  │  │  ├─ 需求确认矩阵 / 确认证据
  │  │  └─ 需求验证矩阵 / 验证证据
  │  └─ DRD列表 / DRD进度控制列表
  ├─ 构型项 / 工程数据 / EBOM
  │  ├─ 设计评审对象包
  │  ├─ 设计更改对象
  │  └─ 工艺性审查对象
  └─ 制造工艺策划对象
     ├─ 工艺网络计划
     ├─ 制造总方案 / 装配协调方案
     ├─ PFMEA / 生产过程控制计划
     └─ 产能基础数据 / 产能规划报告

制造工艺设计
  ├─ MBOM / 零组件供应状态
  ├─ 关键工序目录 / 三定目录
  ├─ 关重件目录
  ├─ 工艺现场管控记录
  └─ 零件制造工艺文件
```

关键关联规则：

1. PBS 是设计对象分解基础，应能追溯到需求、DRD、工程数据和 EBOM。
2. 产品需求和专业需求需要保持上级需求、来源、版次、确认矩阵、验证矩阵之间的关系。
3. 工程数据、构型项、EBOM、AMO 和设计更改需要共享项目、产品/零件、版本和状态口径。
4. 制造总方案、装配协调方案、PFMEA、控制计划和产能规划需要能追溯到项目、产品、工艺策划输入和工艺网络计划。
5. MBOM、关键工序、关重件、工艺文件和制造记录需要与质量检验、生产执行和后续问题闭环保持对象编号一致。

| 工艺方案版本 | 制造总方案、装配协调方案、PFMEA、控制计划应有版本、会签、批准状态 | 会签岗位和批准规则是否固定 |

| 工艺文件分类 | CAPP工艺规程、制造大纲、复材零件制造大纲等需统一分类；结构化工艺文件先按 PLM（CAPP）承接口径管理 | 归档位置、现场副本、CAPP与MES消费接口和工艺数据库维护责任 |

## 五、建设优先级建议

| 优先级 | 建设内容 | 理由 |
|---|---|---|
| P0 | 项目、PBS、需求、DRD、工程数据、EBOM 基础对象 | 是设计开发到制造工艺的主干对象，跨需求、评审、更改、工艺策划和质量检验复用。 |
| P1 | 需求确认/验证矩阵、评审对象、设计更改对象 | 支撑需求闭环、设计评审和构型变更控制，状态和追溯要求高。 |
| P1 | 制造总方案、工艺网络计划、PFMEA、生产过程控制计划 | 是制造策划与生产执行、质量控制衔接的核心对象。 |
| P2 | MBOM、零组件供应状态、关键工序、关重件目录 | MBOM/CAPP 先按 PLM 承接，关键工序和关重件现场执行先按 MES 承接；MDM 统一对象编码、版本、状态和追溯口径。 |
| P2 | 工艺文件、工艺现场管控记录、产能基础数据 | 工艺文件先按 PLM（CAPP）承接，现场管控记录先按 MES 承接，产能规划先按 PLM（工程项目管理）承接；再分清主数据属性和过程记录属性。 |
| P3 | 资源获取评估、设计关键点、各类总结报告 | 可先作为过程台账治理，待字段稳定后再判断是否纳入 MDM。 |

## 八、与系统桑基图的关系

> 工装管理边界：说明会 H5 另有“工程技术部 — 工装管理”旧映射，但当前工程技术部正式 DCM/BBM 尚未纳入工装 L3；该部分需与物资保障部工装主线、工程技术部参与角色和复材车间使用角色共同核验后再入库。


系统桑基图回答“流程在 OA、MES、PLM、ERP 等应用中的承接是否已有证据”；本文件回答“流程反复引用哪些稳定数据对象，需要怎样统一编码、分类、版本、状态、责任和追溯”。产品设计和开发全生命周期统筹、项目阶段计划、DRD进度、评审行动项、工艺网络计划、制造方案、装配协调和产能规划等过程对象先行按 PLM（工程项目管理）承接口径展示；工程数据、构型、设计数据集、EBOM、EDRN 和设计更改对象链先行按 PLM（PDM）承接口径展示；MBOM/CAPP和结构化工艺文件先行按 PLM（MBOM/CAPP）承接口径展示；关键工序、关重件和工艺过程现场记录先行按 MES 承接口径展示；MDM 不进入应用系统（S1）节点。
