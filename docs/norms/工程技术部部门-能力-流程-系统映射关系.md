## 待部门确认事项

1. 部门口径：源文件中出现“工程研发事业部”“科技创新部”“技术办公室”等组织名，本文件统一按仓库组织真源归入“工程技术部”，需部门确认承接关系。
2. 应用承接：当前只确认流程对象和受控资料对象，未把流程落到 OA、MES、PLM 或 ERP；后续需由工程技术部确认应用边界和处理入口。
3. A1 业务行为：候选桑基图中已有大量候选条目，但尚未逐条回源核验执行角色、审批链、输入输出部门和验收标准，本文件暂不入库。
4. MDM 建设要求：工程数据、需求、DRD、工艺文件、关键特性、关重件、工艺网络计划等对象具备主数据候选价值，但需另行形成 `工程技术部能力层与MDM建设要求.md`。
5. 外部来源：涉及沈飞民机侧部门或业务域资料时，应保留“昌兴侧承接确认”证据，不直接等同为工程技术部职责。
