# 经营发展部部门-能力-流程-系统映射关系

> 来源：`docs/norms/经营发展部业务资料/`  
> 口径：沿用 `部门（D1）→ 能力域（L1）→ 业务能力（L2）→ 业务流程（L3）→ 应用系统（S1）` 分层结构。  
> 说明：应用系统只采用 OA、MES、PLM、ERP 四类面向员工使用的系统；MDM不作为应用系统节点，仅在能力层与MDM建设要求文档中单独说明。  
> 命名校验：业务能力优先采用制度标题、条款标题或正文中的业务用词；如果能力名需要合并多份制度，合并词必须能从引用条款中找到对应动作或对象。  
> 状态：初稿，待经营发展部确认。
