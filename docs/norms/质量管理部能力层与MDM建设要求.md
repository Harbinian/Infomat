# 质量管理部能力层与MDM建设要求

> 来源：`docs/norms/质量管理部业务资料/` 全部昌兴程序和民机程序文件
> 口径：MDM 作为后台数据治理基础设施，不出现在应用系统（S1）节点中。本文从质量管理部制度文件中提炼稳定数据对象、编码规则、分类体系、状态机、有效期等待确认主数据，供MDM平台建设参考。

## 2. MDM主数据对象识别

以下主数据对象从质量管理部制度条款中提炼，按通用主数据框架组织。

### 2.1 组织与人员域

| 主数据对象 | 来源依据 | 关键属性 | MDM建设要点 |
|---|---|---|---|
| 质量审核员（内审员） | SYCXQMS-M2-02/A §5.2.1-§5.2.7 | 姓名、学历、专业、培训证书编号及有效期、复训记录、审核员级别、所属部门、授权审核范围 | ①内审员资质有有效期（至少每3年复训）；②审核员不应审核其直接负责的工作，系统需支持利益冲突校验；③内审员资质数据库已有制度要求（§5.2.5），MDM应作为人员资质的权威来源。 |
| 无损检测人员 | SYCXQMS-P5-09/A §5.1.1-§5.1.6 | 姓名、检测方法（超声/射线）、鉴定等级（Ⅰ/Ⅱ/Ⅲ级）、培训记录、体格检查记录、工作经历、从岗能力评估记录、检验印章编号 | ①NDT人员分级（Ⅰ/Ⅱ/Ⅲ级）有严格资质要求；②Ⅲ级人员可考核Ⅰ/Ⅱ级人员；③定期从岗能力评估（§5.1.4）；④与质量审核员有部分重叠但鉴定体系独立。 |
| 不合格品审理人员 | SYCXQMS-P5-10/A §5.3；SYCXQMS-P5-14/A §5.1-§5.5 | 姓名、授权范围（审理层级/产品类别/项目）、授权日期、授权书编号、授权状态、变更记录 | ①须经总经理（或顾客授权）授权；②不同层级对应不同审理权限；③授权变更需通知并重新授权。 |
| 顾客质量代表（驻厂） | SYCXQMS-P5-04/A；SYCXQMS-P5-05/A | 姓名、所属客户、授权项目、授权检验范围、QAR点授权清单 | ①外部人员但需在内部系统登记；②授权范围和变更需维护。 |

## 3. MDM跨域关联关系

```
组织/人员 ──────┐
  ├─ 质量审核员 ──┤
  ├─ NDT人员 ────┤
  ├─ 审理人员 ────┤
  └─ 顾客代表 ────┤
                  ├──→ 质量事件 ──────→ 纠正措施 ──→ 归零报告
产品/零件 ────────┤         │                  │
  ├─ 检验方案 ────┤    不合格品记录          纠正措施记录
  ├─ FAIR ───────┤    质量逃逸事件
  ├─ NDT技术文件 ─┤
  └─ 制造记录 ────┤
                  │
测量设备 ─────────┤
  ├─ 测量设备台账 ┤
  ├─ 测量软件 ────┤
  └─ 计量标准 ────┘
```

**关键关联规则**：
1. 不合格品记录 → 制造记录（零件追溯）→ 产品/零件主数据
2. 纠正措施记录 ← 审核发现（内审/外审/顾客反馈/管理评审）→ 组织/人员（责任部门/责任人）
3. FAIR → 产品/零件（批架次）→ 测量设备（检验用设备需可追溯且在校准有效期内）
4. NDT技术文件 → NDT人员（Ⅲ级批准）→ 测量设备（设备校准状态）
5. 交付文件 → 产品/零件（批架次）→ 顾客主数据

## 4. 状态机与生命周期

### 4.1 纠正措施生命周期

```
不合格发现 → 下发纠正措施报告 → 责任部门答复（7-20个工作日）→ 
纠正措施实施 → 10个工作日内验证实施结果 → 3个月内验证持续有效性 →
（影响实物：连续验证3架份；体系：下次内审验证）→ 关闭
```

### 4.2 归零报告生命周期

```
质量问题触发 → 判定归零类型（技术/管理）→ 签发归零通知单 →
组建归零团队 → 实施归零（执行"十条"要求）→ 编写归零报告 →
组织归零评审（通过/修改后通过/不通过）→ 审批归档 →
跟踪验证（技术：5架份/零件1批次；管理：1年）→ 关闭
```

### 4.3 不合格品处置生命周期

```
操作者自检发现 → 检验人员确认 → 标识（挂签/粘签）→ 隔离（MRCC）→
预检(PI)标记 → 提交偏差记录单 → 逐级审理（审理小组→常设机构→委员会）→
确定处置方式（返工/返修/报废/让步/降级/返回供方）→ 
涉及返修/原样使用时提请顾客批准 → 执行处置 → 关闭
```

### 4.4 测量设备生命周期

```
需求提出 → 选型审查（质量安环部）→ 购置审批 → 采购实施 →
到货开箱验收 → 入厂校准（合格入库/不合格退货）→ 粘贴标识 →
建立台账 → 投入使用（使用前校准）→ 周期校准 → 
状态变更（准用/封存/降级/报废）→ 禁用标识与隔离 → 报废处置
```

### 4.5 质量记录生命周期

```
表格模板创建（统一编号、版次控制）→ 现场填写（耐久墨水、规范填写）→
错误更改（杠改+签字+日期）→ 归档（按项目/批架次分类、逐页审查）→
入库保存（环境适宜、防篡改）→ 借阅（2个工作日内归还）→ 
保存期满 → 销毁审批 → 销毁执行（记录销毁单归档）
```

## 5. MDM建设优先级建议

| 优先级 | 主数据对象 | 理由 |
|---|---|---|
| P0-紧急 | 产品/零件主数据 | 为制造记录、FAIR、不合格品、交付文件、检验方案等所有质量记录提供锚点 |
| P0-紧急 | 测量设备台账 | 直接影响检验结果有效性；制度要求建立维护数据库（S3-03 §5.4.3） |
| P1-高 | 质量审核员/NDT人员/审理人员资质 | 人员资质直接影响审核、检验、审理工作的合法性和有效性 |
| P1-高 | 不合格品记录分类与编码 | 数据量大、跨系统引用频繁（MES→OA→PLM→ERP） |
| P2-中 | 纠正措施/归零报告 | 与不合格品、审核发现强关联，闭环周期长，需状态跟踪 |
| P2-中 | 质量记录表格模板与编码规则 | 全公司统一编号和版次控制的基础设施 |
| P3-低 | 测量软件清单 | 数量有限、变更频率低，可在测量设备台账中作为附属属性管理 |

## 7. 待确认事项

1. 测量设备唯一性编号规则：制度仅要求"唯一性标记"（S3-03 §5.5.5），未规定具体格式。建议在MDM中统一制定编码规则。
2. 质量记录表格编号规则：制度要求"按填表说明中的编号规则进行统一编号"（S1-06 §5.2.2），但各程序中的表格编号规则不统一（有些以"FM-程序号-序号"格式，有些简写）。建议MDM建立全局表格编号注册表。
3. 安全环保数据对象：若质量管理部承担安全、环保职能且有独立制度文件，需补充对应的主数据对象（如安全事件、环保监测记录等）。
4. 人员资质有效期监控：审核员、NDT人员、审理人员的资质有效期和复训到期提醒需要MDM支持自动预警。
