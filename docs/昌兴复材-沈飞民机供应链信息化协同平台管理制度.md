# 沈飞民机供应链信息化协同平台管理制度

**文件编号**：CX-SACC-001
**版本号**：V1.0（草案）
**编制**：＿＿＿＿＿＿
**审核**：＿＿＿＿＿＿
**批准**：＿＿＿＿＿＿
**生效日期**：＿＿＿＿年＿＿月＿＿日

---

## 1. 目的

为规范昌兴复材在沈飞民机供应链信息化协同平台（以下简称"平台"）上的操作行为，明确经营发展部与项目管理部的职责边界与协作关系，确保从接收询价到完成结算的全业务链路操作受控、时限明确、责任可追溯，特制定本制度。

## 2. 范围

### 2.1 适用部门

本制度适用于昌兴复材以下部门及其在平台上执行操作的人员：

- **经营发展部**：室主任、计划员，以及参与审批的部长、经营副总
- **项目管理部**：部长、部长助理、项目助理、计划员

### 2.2 适用业务

本制度覆盖通过沈飞民机供应链信息化协同平台（https://sacc-supplychain.avicnet.cn/）进行的以下业务活动：

1. 三年需求预测查询
2. 订单接收管理（查看明细、订单接收）
3. 订单查询与导出
4. 用友U8订单转化
5. 零件交付计划调整报告管理
6. 生产过程管理（生成数据及质量编号、分卡、生产状态录入）
7. 打印封面及合格证
8. 反馈问题管理
9. 产品交付清单管理
10. 产品交付确认
11. 报价管理（含询价函接收、预算定额报价、审批、盖章、上传）
12. 结算核对与反馈

### 2.3 适用人员

所有使用平台账号的昌兴复材员工，以及参与上述业务流程审批但可能不直接登录平台的管理人员。

## 3. 术语和定义

| 序号 | 术语 | 定义 |

| 3.2 | 订单流水号 | 平台为每笔订单生成的唯一标识，用于全链路追溯 |
| 3.3 | 派工号 | 沈飞民机生产运营部下达的派工编号，格式 PGH + 日期 + 序号 |

| 3.5 | 零件交付计划调整 | 供应商对已确认订单的交付日期提出变更申请，经沈飞民机审批后生效 |
| 3.6 | 生产状态 | 零件从任务下达到已交付的关键状态节点，包括：任务下达、缺料、生产准备、加工、装配、半检、移交表处、表处、终检、待交付、已交付 |
| 3.7 | 用友U8（U8系统） | 昌兴复材内部使用的企业资源计划（ERP）系统，订单从平台接收后需转化录入U8 |

| 3.9 | 订单接收 | 供应商在平台上确认接收沈飞民机生产运营部发布的订单，接收后订单转为正式可执行状态 |

| 3.11 | 购料方式 | 订单中约定的材料采购责任归属，包括"购料"、"来料加工"等类型 |
| 3.12 | 工艺代码 | 由沈飞民机制定的加工工艺标识编码，关联零件制造工艺路线 |

## 5. 工作程序

### 5.1 报价管理

#### 5.1.1 询价接收

| 项目 | 内容 |
|------|------|
| **触发条件** | 沈飞民机供应链管理部通过平台或其他正式渠道发送询价函 |
| **执行人** | 经营发展部室主任 |
| **具体动作** | (1) 查收并确认询价函内容；(2) 识别询价产品/零件的规格、数量、交付要求；(3) 通知相关岗位启动报价准备 |
| **输出物** | 询价函记录（登记于《报价审批单》CX-001） |
| **验收标准** | 询价函信息完整获取，零件号、数量、交付要求无误 |
| **时限** | 接收当日 |

#### 5.1.2 预算定额报价

| 项目 | 内容 |
|------|------|
| **触发条件** | 询价函接收完成 |
| **执行人** | 经营发展部室主任 |
| **具体动作** | (1) 依据材料成本、加工工时、工艺难度等核算预算定额；(2) 按报价要求编制报价单（含单价、总价、币种、有效期等）；(3) 将报价单及询价背景提交审批 |
| **输出物** | 报价单（附预算定额明细），登记于《报价审批单》CX-001 |
| **验收标准** | 预算定额依据充分，报价单格式符合沈飞民机要求，单价/总价/币种清晰无误 |

#### 5.1.3 报价审批与上传

| 项目 | 内容 |
|------|------|
| **触发条件** | 报价单编制完成 |
| **执行人** | 经营发展部室主任（起草）、部长或经营副总（审批） |
| **具体动作** | (1) 室主任将报价单及《报价审批单》提交部长或经营副总审批；(2) 审批人对定价依据、利润空间、合同风险进行审查并签字；(3) 室主任对已审批的报价单加盖公章；(4) 室主任或计划员将盖章版报价单上传至平台（或按沈飞民机指定方式提交）；(5) 在平台或《报价审批单》中记录上传时间与状态 |
| **输出物** | 已审批盖章的报价单（纸质扫描件或电子版） |
| **验收标准** | 报价单已审批、已盖章、已成功提交平台（有上传确认回执或截图），《报价审批单》签字完整 |
| **时限** | 自收到询价函起，全部流程须在 **3个工作日** 内完成。超时未报价可能导致平台自动接收订单并造成经济损失 |

### 5.2 订单管理

#### 5.2.1 订单接收

| 项目 | 内容 |
|------|------|
| **触发条件** | 沈飞民机生产运营部在平台发布新订单 |
| **执行人** | 经营发展部室主任或计划员 |
| **具体动作** | (1) 登录平台进入"订单接收管理-查看明细"，查看待确认接收的订单；(2) 逐项核对订单中的零件号、零件名称、数量、需求日期、合同号、购料方式、单价、总价等信息；(3) 确认无误后，在"订单接收管理-订单接收"页面确认接收；（注意：若在规定时限内未主动确认，平台将自动转为接收状态，视为已确认） |
| **输出物** | 已确认接收的订单记录，登记于《订单接收登记表》CX-002 |
| **验收标准** | 订单信息与合同/报价一致，订单状态变更为"已接收"，《订单接收登记表》记录完整 |

#### 5.2.2 U8订单转化

| 项目 | 内容 |
|------|------|
| **触发条件** | 平台订单确认接收完成 |
| **执行人** | 经营发展部计划员 |
| **具体动作** | (1) 提取平台订单中的零件号、数量、需求日期、合同号、订单流水号等关键信息；(2) 在用友U8系统中录入对应订单，关联合同号；(3) 在U8中下达生产指令，通知项目管理部启动生产；(4) 在《订单接收登记表》中记录U8订单编号，建立平台订单流水号与U8订单号的双向追溯 |
| **输出物** | U8订单记录（U8订单号），《订单接收登记表》CX-002 更新 |
| **验收标准** | U8订单信息与平台订单一致，双向追溯编号已建立，生产指令已下达 |
| **时限** | 平台订单接收后 **1个工作日** 内完成 |

### 5.3 零件交付计划调整

| 项目 | 内容 |
|------|------|
| **触发条件** | 因生产异常（如原材料延误、设备故障、工艺变更等）无法按原计划交付日期交付零件 |
| **执行人** | 项目管理部项目助理（发起）、经营发展部室主任（审核上传） |
| **具体动作** | (1) 项目助理从"订单查询-导出"获取需调整的订单数据；(2) 获取"订单流水号"作为更新唯一标识；(3) 填写《零件交付计划调整申请表》CX-003，说明调整原因（情况说明）、装配影响、建议的新交付日期；(4) 提交经营发展部室主任；(5) 室主任审核调整合理性后，登录平台"零件交付计划调整报告管理"上传调整申请；(6) 跟踪沈飞民机审批结果，及时反馈项目管理部 |
| **输出物** | 《零件交付计划调整申请表》CX-003，平台调整报告提交回执 |
| **验收标准** | 申请表三项必填内容完整（情况说明、装配影响、调整后计划交付日期），已提交平台，审批结果已跟踪反馈 |
| **时限** | 项目管理部发起到经营发展部上传：**1个工作日** 内完成 |

### 5.4 生产过程管理

#### 5.4.1 生成数据及质量编号

| 项目 | 内容 |
|------|------|
| **触发条件** | U8生产指令下达后，零件进入生产过程 |
| **执行人** | 项目管理部部长助理或计划员 |
| **具体动作** | (1) 登录平台"生产过程管理-生成数据&质量编号"；(2) 按订单流水号关联，为每批次/每件零件生成生产数据；(3) 编制或确认质量编号，确保编号唯一且可追溯；(4) 将质量编号回写U8系统或生产台账 |
| **输出物** | 生产数据记录、质量编号 |
| **验收标准** | 每批次零件均有对应质量编号，质量编号唯一，与订单流水号关联正确 |

#### 5.4.2 分卡

| 项目 | 内容 |
|------|------|
| **触发条件** | 需要将一批订单按工序或工位拆分管理 |
| **执行人** | 项目管理部部长助理或计划员 |
| **具体动作** | 登录平台"生产过程管理-分卡"，按工序需要将生产任务拆分至对应工作卡 |
| **输出物** | 分卡记录 |
| **验收标准** | 分卡与订单流水号关联正确，工序归属明确 |

#### 5.4.3 生产状态录入

| 项目 | 内容 |
|------|------|
| **触发条件** | 零件生产状态发生变更 |
| **执行人** | 项目管理部部长助理（起草录入）、部长（审核） |
| **具体动作** | (1) 部长助理跟踪零件实际生产进度；(2) 以下五种状态变更发生后，在 **1个工作日** 内于平台"生产状态录入"页面完成状态更新：**任务下达**（生产指令已发放至车间）、**缺料**（原材料或外协件短缺影响生产）、**终检**（零件完成全部加工工序并通过最终检验）、**待交付**（零件已完成终检且具备交付条件）、**已交付**（零件已实际交付沈飞民机）；(3) 其余状态（生产准备、加工、装配、半检、移交表处、表处）在实际发生时正常录入；(4) 当数据量大时，使用"生产状态录入-批量导入"功能：先从"生产过程管理"页面导出待录入数据，填选目标状态，再导入Excel文件完成批量更新；(5) 部长对起草的生产状态录入内容进行审核 |
| **输出物** | 平台生产状态记录，《生产交付状态台账》CX-005 |
| **验收标准** | 平台状态与实际生产进度一致，五种关键状态（任务下达/缺料/终检/待交付/已交付）在发生后1个工作日内已更新，部长审核通过 |
| **时限** | 任务下达、缺料、终检、待交付、已交付五种状态：发生后 **1个工作日** 内；其余状态：发生后及时录入 |

### 5.5 打印封面及合格证

| 项目 | 内容 |
|------|------|
| **触发条件** | 零件终检完成后，进入待交付阶段 |
| **执行人** | 项目管理部项目助理 |
| **具体动作** | 登录平台"打印封面及合格证"，选择对应订单流水号，打印交付所需的零件封面和质量合格证 |
| **输出物** | 打印的封面、合格证（纸质） |
| **验收标准** | 封面信息与订单一致，合格证与质量编号对应，按规定份数打印 |

### 5.6 产品交付清单管理

| 项目 | 内容 |
|------|------|
| **触发条件** | 零件具备交付条件，准备发货 |
| **执行人** | 项目管理部项目助理 |
| **具体动作** | 登录平台"产品交付清单管理"，创建或维护交付清单，录入即将交付的零件信息 |
| **输出物** | 产品交付清单 |
| **验收标准** | 交付清单与待交付零件实物一致，零件号、数量、订单流水号准确 |

### 5.7 产品交付确认

| 项目 | 内容 |
|------|------|
| **触发条件** | 零件已实际交付沈飞民机 |
| **执行人** | 项目管理部部长 |
| **具体动作** | (1) 确认零件已实际运送至沈飞民机指定地点并签收；(2) 登录平台"产品交付确认"，对已交付的零件进行最终确认操作；(3) 确认后通知经营发展部关注后续结算 |
| **输出物** | 平台交付确认记录 |
| **验收标准** | 交付确认与实际签收一致，确认后平台订单状态更新为"已交付" |
| **时限** | 零件实际交付签收后 **1个工作日** 内 |

### 5.8 反馈问题管理

| 项目 | 内容 |
|------|------|
| **触发条件** | 生产或交付过程中出现质量、交期、工艺等问题 |
| **执行人** | 项目管理部项目助理 |
| **具体动作** | 登录平台"反馈问题管理"，录入问题描述、关联订单流水号、影响范围、建议处理方案，跟踪问题处理进度 |
| **输出物** | 问题反馈记录 |
| **验收标准** | 问题描述清晰、关联订单正确、处理进度有跟踪 |

### 5.9 结算核对

| 项目 | 内容 |
|------|------|
| **触发条件** | 沈飞民机生产运营部每月6-10日发送上月零件交付清单 |
| **执行人** | 经营发展部室主任（核对）、部长或经营副总（审批） |
| **具体动作** | (1) 室主任接收沈飞民机发来的上月零件交付清单；(2) 逐项核对：交付零件号、数量、单价、总金额、合同号、订单流水号；(3) 将核对结果及差异说明填入《结算核对确认表》CX-004；(4) 提交部长或经营副总审批；(5) 审批通过后将核对结果反馈沈飞民机生产运营部；(6) 若有差异，跟踪沈飞民机处理直至解决 |
| **输出物** | 《结算核对确认表》CX-004，反馈沈飞民机的核对结果 |
| **验收标准** | 金额、合同号逐条核对无误，差异有说明，审批签字完整，已反馈沈飞民机 |
| **时限** | 收到清单后 **3个工作日** 内完成核对、审批并反馈 |

### 6.1 全链路流程概览

```
沈飞供应链管理部 ──询价函──▶ 昌兴经营发展部

                                  │
沈飞生产运营部 ──发布订单──▶ 平台 ──▶ 昌兴经营发展部
                                        │
                              室主任/计划员确认接收
                              计划员转化U8下单
                              （1个工作日内）
                                        │
                              通知项目管理部
                                        │
项目管理部 ◀──────────────────────────────┘
    │
    部长助理生成数据/质量编号

    部长审核

    项目助理管理交付清单
    ├── 需调整交付日期？
    │        │
    │   项目助理发起调整申请
    │   室主任审核上传平台
    │        │
    └── 正常交付 ──▶ 部长进行产品交付确认（交付签收后1个工作日内）
                                │
沈飞生产运营部 ──每月6-10日发交付清单──▶ 昌兴经营发展部
                                                │
```
