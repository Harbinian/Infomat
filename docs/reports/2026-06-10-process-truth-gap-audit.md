## 3. `综合管理部` 口径

当前组织真源未列出 `综合管理部`。核验到的出现位置如下：

| 位置 | 出现形态 | 初步判断 |
|---|---|---|
| `docs/norms/运维安环部部门-能力-流程-系统映射关系.md` `YW-L3-14-A06` | 业务行为名称和执行角色中出现综合管理部行政事务室、兼职安全管理员 | 来源为 `GLC260704-D` 原文引用，需确认是否为旧组织名称、客户方/外部组织、还是应映射到当前行政人事部或其他部门。 |
| `docs/norms/运维安环部部门-能力-流程-系统映射关系.md` `YW-L3-32-A07` | 制度依据中出现综合管理部将上级文件呈报公司领导阅批 | 来源为 `GLC260808-B` 原文引用，当前 A1 执行角色仍是各部门业务负责人。 |
| `docs/norms/流程治理/跨部门流程识别报告.md` | 外部实体表列出综合管理部，归属沈飞民机，说明为汽油统计与上报 | 更像外部组织或历史名称记录，不应直接加入昌兴当前组织真源。 |
| `docs/company-sankey-data.json` | 5 处命中，包含节点名、链路和证据引用 | 由现有映射和报告生成，不作为独立来源。 |

初步处理建议：

1. 在修改任何映射前，先回看 `GLC260704-D` 和 `GLC260808-B` 原始制度，确认 `综合管理部` 是昌兴旧称、沈飞民机组织、还是制度沿用文本。
2. 若确认是昌兴旧组织名称，应补一张历史别名表，再映射到当前组织真源中的正式部门。
3. 若确认是客户方或外部组织，应保留为外部实体或制度原文引用，不并入 `OU-DEP-*`。
4. 若证据不足，维持待确认，不要为了消除 JSON 命中而改 A1 文字。
