# docs/norms 制度原文与映射关系一致性审计报告

生成日期：2026-06-09  
审计范围：`docs/norms/` 下部门业务资料、部门 DCM 映射 Markdown、BBM 业务行为（A1）增补内容、既有 `_quality-report.md`。

## 一、审计口径

本次只做一致性识别和遗漏检查，未修改 `docs/norms/` 流程输入基线。审计过程中运行了 `scripts/check-dcm-bbm.mjs --no-fail`，该脚本会重写生成型文件 `docs/norms/_quality-report.md`；本报告将其视为质检输出，不视为制度或流程输入基线。

- **制度原文/附件**：各 `{部门}业务资料/` 下文件，排除 `~$` Office 临时文件、`_extracted/` 抽取缓存和辅助脚本。
- **DCM 映射**：`{部门}部门-能力-流程-系统映射关系.md` 中的 `部门（D1）→ 能力域（L1）→ 业务能力（L2）→ 业务流程（L3）→ 应用系统（S1）` 主表。
- **BBM 映射**：同一 Markdown 文件内的 `业务行为（A1）映射（BBM增补）`。
- **未命中**：原始文件名、文件编号、表单编号或可识别标题未在对应映射文档中出现。未命中不等于必然遗漏，可能是参考副本、更改单、重复版本或非本部门主责资料，但需要人工复核。
- **表格/图片计数**：用 Word 结构读取 `.docx` 的表格和内嵌图示数量，只作为遗漏风险提示，不代表每个表格都必须成为独立流程。

## 二、总览结论

1. DCM 主表整体可用。8 个部门/车间映射文件共识别 252 条业务流程（L3）；除复材车间 2 条流程依据偏粗、物资保障部 4 条流程在现有质检中提示条款号可能不足外，大多数 DCM 行已有文件号和条款依据。
2. BBM 层一致性问题较重。现有 `check-dcm-bbm` 输出 `BLOCK=215 / WARN=1828 / INFO=3`，其中 206 条为 A1 表核心列缺失，375 条为 A1 挂接的业务流程（L3）未在 DCM 主表中找到。另有 7 条 HTML 静态资产 BLOCK 与当前 AGENTS 规则冲突，应视为质检合同待更新，不纳入本次映射缺陷判断。
3. 流程图/流程说明遗漏风险最高。运维安环部业务资料中有 95 个流程模型 `.vsd` 和 78 个流程说明 `.xls/.xlsx`，但 `docs/norms/` 下没有发现独立的 `*流程图.md`、`*流程模型*.md` 或 `*流程说明*.md` 归纳文件。
4. 表格/表单归纳不均衡。现有 `_tables.md` 只发现 13 个，全部位于物资保障部业务资料；其他部门 Word 原文中有大量内嵌表格和表单附件，尚未证明已被系统性归纳到 BBM 表单/台账子表。
5. 组织/交付物口径存在缺口。`_quality-report.md` 统计了 7 个部门，未把 `复材车间` 纳入 L3/A1 统计；同时提示工程技术部、复材一车间、复材二车间尚未形成 DCM 三件套。

## 四、主要一致性问题

### 1. BBM 与 DCM 主表脱节

现有质检中，`CROSS` 问题 375 条，集中在：

| 部门 | A1 挂接的 L3 未在 DCM 主表找到 |
|---|---:|
| 质量管理部 | 362 |
| 项目管理部 | 13 |

这说明部分 A1 行已经拆到更细的流程名称，但 DCM 主表没有同步新增或归并。整改时应先确认这些 A1 是需要回归既有 L3，还是确实要补充 DCM 主表；不要直接在 A1 层继续扩展。

### 2. A1 表字段契约不统一

现有质检中，206 个 A1 表提示缺少核心列，分布为：

| 部门 | 缺核心列的 A1 表 |
|---|---:|
| 物资保障部 | 44 |
| 行政人事部 | 39 |
| 运维安环部 | 33 |
| 质量管理部 | 90 |

常见缺失包括 `是否调整`、`调整建议`，质量管理部还出现 `业务行为（A1）编号`、`触发情景`、`前置条件`、`核验提醒`、`部门确认意见` 等列缺失。这会影响部门审核稿闭环。

### 3. 证据类型和条款粒度仍需修正

- 物资保障部有 2 条 A1 的 `证据类型` 被写成条款号，未使用 BBM 枚举值。
- 物资保障部有 4 条 DCM 流程在质检中提示制度依据可能缺少条款号。
- 复材车间有 2 条 DCM 流程依据仅写为 `生产部横向工序管理方案`，未达到“文件号/版次/条款”的证据粒度。

### 4. 应用系统（S1）留白基本有解释

未发现把 MDM 作为应用系统（S1）的直接问题。项目管理部和运维安环部存在少量 S1 留白，但均有“不强行对应”或现有记录载体说明：

- 项目管理部：`随炉件出罐通知、移交领取确认、理化结果按时反馈`；`申请台账/合同台账/挂账回款台账建立与 BI 系统信息录入`。
- 运维安环部：`节能环保能源统计、环境统计报表`；`法规识别、适用性确认、法规清单、合规评价项`。

### 5. 质检合同存在静态资产口径冲突

当前 AGENTS 规则要求 `docs/norms/` 下的部门桑基图页面引用本目录内 `echarts.min.js`，即 `<script src="echarts.min.js"></script>`。但本次重新运行 `check-dcm-bbm` 后，`_quality-report.md` 新增 7 条 HTML BLOCK，要求这些页面引用 `../echarts.min.js`。

这与当前项目规则相反。建议先更新 `scripts/check-dcm-bbm.mjs` 或其合同配置，再把 HTML 静态资产检查纳入整改清单。

## 五、遗漏风险清单

### 1. 流程图/流程模型

BBM 技能要求：存在流程图时，不应只写“参见原文件流程图”，应抽取为独立 Markdown，描述节点、判断、泳道和流转关系。

当前发现：

- 运维安环部：95 个流程模型 `.vsd`、78 个流程说明 `.xls/.xlsx`，对应映射文档仅出现少量“流程说明/流程图”字样，未发现独立流程图 Markdown。
- 项目管理部：4 条 A1 使用 `原文明确-流程图`，集中在产品紧急放行流程，但未发现独立流程图 Markdown。
- 经营发展部：A1 备注中多次提示“请确认证据来源为正文、流程图还是表单”，说明部分流程图/表单证据尚未完成二次校验。

优先建议先处理运维安环部，因为其流程模型和流程说明附件规模最大。

### 2. 表格、表单和台账

当前仅发现 13 个 `_tables.md`，全部在物资保障部业务资料下。其他部门虽然有大量 Word 内嵌表格和表单附件，但缺少相同粒度的表格归纳成果。

高风险部门：

- 运维安环部：67 个表单/台账类附件未在映射文档中命中。
- 质量管理部：24 个表单/台账类附件未在映射文档中命中。
- 项目管理部：3 个表单/模板未命中，包括 `各部门涉及民机质量程序文件清单 (1).xlsx`、`浑南专用物资出门申请单模版.jpg`、`车辆使用申请单模版.jpg`。
- 经营发展部：2 个表单未命中，包括 `FM-M1-03-02函件.docx`、`FM-P3-08-02供应商质量沟通记录.docx`。

这些附件应先判断是否属于正式表单、参考副本、历史模板或非本部门主责，再决定是否进入 BBM 的表单/台账子表。

### 3. 源文件覆盖

未命中数量较高的部门：

| 部门 | 未命中总数 | 主要类型 |
|---|---:|---|
| 运维安环部 | 271 | 流程模型、流程说明、表单/台账、部分正文/更改单 |
| 质量管理部 | 50 | 民机程序正文、FM 表单、部分新版/重复正文 |
| 经营发展部 | 4 | 职能对应关系提取、个别 FM 表单、合同评审 B 版 |
| 项目管理部 | 3 | 质量程序清单和图片模板 |
| 复材车间 | 2 | `交付组管理流程.txt`、`内部排罐管理程序-1113更新.txt` |
| 行政人事部 | 2 | `GLTX-XZ-28-A领导干部管理规定（5.7.1）` docx/txt |

质量管理部的未命中项中，民机程序文件占比较高，需要判断是“故意排除的参考资料”还是“尚未纳入 DCM/BBM 的原文来源”。

## 六、优先整改顺序

### P0：先修主链一致性

1. 确认质量管理部 362 条、项目管理部 13 条 A1 挂接缺口：回归既有 L3 或补充 DCM 主表。
2. 确认 `复材车间` 与组织真源的命名关系：是合并视图，还是应拆为复材一车间/复材二车间。
3. 确认工程技术部是否本阶段暂不建模；如不是暂缓，应补 DCM 三件套。

### P1：补流程图和流程说明

1. 以运维安环部为第一批，按流程模型和流程说明附件生成独立流程图 Markdown。
2. 对项目管理部 `产品紧急放行管理程序` 中已标为 `原文明确-流程图` 的 A1，补独立流程图归纳文件。
3. 将流程图中的角色泳道、节点、判断分支回写到 A1 的角色、触发、前置、审批类型和核验提醒。

### P2：补表格/表单台账

1. 以未命中附件为入口，逐个判定“正式表单/参考副本/重复版本/非本部门主责”。
2. 对正式表单补入 BBM 表单/台账子表，至少记录表单名称、关键字段、填报角色、流转方向。
3. 对 Word 内嵌表格进行抽样复核，优先处理包含审批链、字段说明、台账模板、流程步骤表的表格。

### P3：统一契约和质检口径

1. 补齐 A1 表核心列，特别是 `部门确认意见`、`是否调整`、`调整建议`。
2. 修复物资保障部 A1 证据类型枚举值和 DCM 条款号提示。
3. 统一组织真源文件名引用：当前实际文件为 `docs/organization/组织架构和部门职责.md`，合同和部分规则仍写作 `组织架构与部门职责.md`。
4. 更新 DCM/BBM 质检合同中的 ECharts 引用规则，使其与当前 AGENTS 约定一致。

## 七、审计限制

- `.vsd` 文件内容未被解析，只按文件名和映射引用关系识别遗漏风险。
- `.doc` 和 `.pdf` 未进行全文结构解析；本次主要通过文件名、编号、表单号和映射文本命中关系判断。
- Word 内嵌表格计数包含封面、修订页、签发表、正文表格和表单表格，后续需要人工或脚本二次分类。
- “未命中”是复核清单，不直接等同于错误。
