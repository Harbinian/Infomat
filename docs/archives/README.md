# docs/archives 说明

> 状态：历史归档目录  
> 生效日期：2026-06-10  
> 范围：已退出当前执行线、但仍需要长期追溯的资料、方案和迁移记录。

本目录用于保存后续迁移进来的历史材料。当前执行基线或真源不要放在这里；如果某份资料仍会被流程 parser、PMO 页面、MDM 平台或测试脚本直接读取，应保留在原主责目录。

## 1. 归档条件

资料进入本目录前，应先确认：

1. 已不再作为当前基线、真源或执行入口。
2. 不被脚本、页面或测试直接引用。
3. 已有报告或提交说明记录迁移原因。
4. 文件名或 README 能说明原路径和归档日期。

## 2. 不应放入

- 当前部门流程输入基线。
- PMO 当前计划 Markdown。
- MDM 运行源码、测试或数据库。
- 可重新生成且无需追溯的截图、日志、缓存和临时输出。

## 3. 与相近目录的关系

- `docs/reports/`：放审计和整改记录。
- `docs/plans/`：放阶段性计划。
- `docs/superpowers/`：保留历史设计和 AI 计划。
- `pmo/archive/`：放 PMO 局部历史页面快照或项目材料归档。
