## 1. 归档条件

资料进入本目录前，应先确认：

1. 已不再作为当前基线、真源或执行入口。
2. 不被脚本、页面或测试直接引用。
3. 已有报告或提交说明记录迁移或保存原因。
4. 文件名或 README 能说明原路径、保存日期及历史用途。

## 2. 不应放入

- 当前部门流程输入基线。
- PMO 当前计划 Markdown。
- MDM 运行源码、测试或数据库。
- 可重新生成且无需追溯的截图、日志、缓存和临时输出。
