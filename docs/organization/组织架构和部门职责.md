# 沈阳昌兴复材航空科技有限责任公司

## 组织架构与部门职责

---

## 一、组织架构图

```
总经理
├── 经营副总
│   ├── 财务部
│   ├── 人事部

│   ├── 物资保障部
```

---

## 二、领导层职责

### 总经理

- 主持公司全面工作
- 负责战略决策和重大人事任免

### 经营副总

- 主持经营线条日常工作
- 分管财务、人事、工程技术、质量管理、物资保障、经营发展等部门

### 生产副总

- 主持生产线条日常工作
- 分管项目管理、复材车间、运维安环等部门

---

## 三、部门职责说明

### 经营线条

| 部门 | 职责范围 |
|------|---------|
| **财务部** | 财务管理、预算核算、资金管理 |
| **人事部** | 人力资源规划、招聘培训、绩效考核 |
| **工程技术部** | 工艺文件编制、工艺规程制定、技术支持 |
| **质量管理部** | 质量检验与控制、检验规程、不合格品管理 |
| **物资保障部** | 物料采购、仓储、配送、工装管理 |
| **经营发展部** | 商务、合同、供应商管理、项目推进 |

### 生产线条

| 部门 | 职责范围 |
|------|---------|
| **项目管理部** | 架次进度管理、里程碑跟踪、交付文件管理 |
| **复材车间** | 生产执行、零件加工制造、任务接收与报工 |
| **运维安环部** | 设备维护、安全环保、设备运行管理 |

## 四、MES 需求评审平台部门入口

需求评审闭环平台支撑 8 个资料包入口，用于需求收集、一级审核、退回补正和 M1 冻结：

| 序号 | 部门入口 | 平台用途 |
|------|----------|---------|
| 1 | 经营发展部 | 商务、合同、供应商、项目推进需求 |
| 2 | 保密办 | 涉密合规、内网部署、资料流转合规需求 |
| 3 | 复材车间 | 生产执行相关需求 |
| 4 | 工程技术部 | 工艺文件、MBOM 相关需求 |
| 5 | 质量管理部 | 检验规程、NCR 相关需求 |
| 6 | 项目管理部 | 制造大纲、架次进度相关需求 |
| 7 | 物资保障部 | 物料、库存相关需求 |
| 8 | 运维安环部 | 设备、安环相关需求 |

## 五、部门对接要求

| 规则编号 | 规则名称 | 说明 |
|---------|---------|------|
| 对接01 | 职责主体 | 各业务部门须指定副职及以上人员作为 MES 项目对接责任人 |
| 对接02 | 需求冻结机制 | M1 里程碑（2026年5月）后，需求冻结，新增需求纳入二期池 |
| 对接03 | 需求确认流程 | 所有需求变更须经对接责任人书面确认后方可纳入开发范围 |
| 对接04 | UAT 参与要求 | 用户验收测试阶段，各部门须派员全程参与 |
| 对接05 | 上线支持义务 | 系统上线后，各部门须指定操作人员并完成培训 |

---

## 六、需求评审平台定位说明

> **重要说明**：本平台是**需求评审收集与闭环管理平台**，负责收集、评审和追踪各部门提交的 MES 需求，**不实现**物料/工装/设备/工艺/生产执行等 MES 业务功能。
