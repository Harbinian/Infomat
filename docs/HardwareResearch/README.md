## 使用边界

1. 本目录可以支持基础设施方案和招标准备，但不能直接改变流程地图、MDM 平台或 PMO 项目计划。
2. 引用本目录内容形成正式方案时，应标明来源材料和适用范围。
3. 如果材料转为正式项目计划，应沉淀到 `docs/plans/` 或 PMO 真源文件。
4. 如果材料转为长期架构决策，应沉淀到 `docs/adr/`。

## 修改自检

- 新增资料时，写清来源、日期和适用范围。
- 不提交解包目录、临时导出、下载缓存或未脱敏材料。
- 大体量资料迁移前，先写迁移提案并查清引用关系。
