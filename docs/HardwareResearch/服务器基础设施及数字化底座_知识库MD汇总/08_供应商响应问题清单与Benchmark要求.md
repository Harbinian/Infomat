# 供应商响应问题清单与 Benchmark 要求

## 一、总体要求

本项目不接受仅基于硬件规格的笼统响应。所有服务商应按资源池、业务系统、数据库、备份、容灾、License、功耗和验收指标逐项响应。

## 二、发给浪潮/服务器厂商的问题

### 1. 超融合平台

1. 当前三节点 IR5280M7 方案是否仅覆盖 PLM/MES/ERP/OA 管理系统底座？
2. 是否不包含 Ansys Fluent、AI 大模型、vGPU 图形虚拟化、大规模 VDI？
3. 请补全 CPU、内存、硬盘、RAID/HBA、网卡、电源、功耗、维保明细。
4. 请按 PLM/MES/ERP/OA 输出资源落位表。
5. 三节点两副本可容忍何种故障？
6. 单节点故障后是否仍能保障全部核心业务运行？
7. 数据重建时间和重建期间性能影响是多少？
8. 软件授权按节点、CPU 还是容量授权？
9. 三年后续保费用和过保影响是什么？

### 2. GPU 服务器

1. NF5468A7 配置中 H100 80GB 的数量是多少？
2. 是否支持后续扩展至 8 张 GPU？
3. CPU、GPU、NVMe 的 PCIe 拓扑是什么？
4. 本地 NVMe 是否可作为 Fluent 临时盘和结果缓存？
5. 现有双万兆网卡是否满足需求，是否建议升级 25GbE/100GbE？
6. 最大功耗、典型功耗、PDU、UPS、散热要求是什么？
7. 现有 42U、8 位 10A、2500W 机柜是否可承载？
8. 是否提供 Ansys Fluent GPU Solver 代表模型 Benchmark 支持？
9. 是否联合 Ansys 原厂或授权代理商出具适配说明？

## 三、发给 Ansys 原厂/代理商的问题

1. 我司计划使用的 Ansys Fluent 版本是什么？
2. 该版本 Fluent GPU Solver 对 CUDA、NVIDIA Driver、操作系统有什么要求？
3. 湍流模型 k-epsilon、k-omega SST、LES/DES 是否支持 GPU Solver？
4. 能量方程是否支持 GPU Solver？
5. 共轭传热 CHT 是否支持 GPU Solver？
6. 薄壁/抽壳/壳导热建模是否支持 GPU Solver？
7. 辐射模型是否支持 GPU Solver？
8. UDF 是否支持 GPU Solver？
9. 若部分功能不支持 GPU Solver，CPU 求解兜底方案是什么？
10. 4 × 80GB GPU 能支撑多少 Cells 的模型？
11. 48GB GPU 是否足够，适用于什么模型规模？
12. Ansys HPC / GPU 授权如何消耗？
13. GPU Solver 与 CPU Solver 的结果一致性如何验收？
14. 是否能基于我司代表模型进行 Benchmark？

## 四、Ansys Fluent Benchmark 要求

### 1. 代表模型

| 模型 | 规模 | 目标 |
|---|---:|---|
| 小型局部模型 | 50万～200万 Cells | 验证边界条件、湍流模型、抽壳方式 |
| 中型工装模型 | 300万～800万 Cells | 工程主力热分布分析 |
| 大型瞬态模型 | 800万～2000万 Cells | 升温曲线、温度滞后、温度均匀性 |
| 多工况扫描 | 中型模型 ×10～30 工况 | 夜间批量计算 |

### 2. 测试组合

每个模型至少测试：

1. CPU only
2. 1 GPU
3. 2 GPU
4. 4 GPU

### 3. 记录指标

1. 总运行时间
2. 单步迭代时间
3. 峰值内存
4. 峰值显存
5. GPU 利用率
6. CPU 利用率
7. 临时文件峰值
8. 结果文件大小
9. Ansys License 消耗
10. 是否收敛
11. 结果温度场是否一致
12. 是否存在 GPU Solver 不支持项

## 五、发给 PLM/MES/ERP/OA 服务商的问题

### 1. 数据库

1. 是否支持 Oracle 数据库？
2. 是否支持 Oracle RAC？
3. 是否支持 Oracle Data Guard？
4. 若不支持 Oracle，请提供原厂证明和偏离说明。
5. 数据库表空间、索引、日志、归档如何规划？
6. 生产、测试、培训、灾备环境是否分离？
7. 是否支持统一备份平台做数据库一致性备份？

### 2. 性能

1. 并发用户数如何测算？
2. 峰值连接数是多少？
3. 关键业务写入频率是多少？
4. 是否提供慢 SQL 优化责任？
5. 是否提供上线前性能基线测试？
6. 是否提供上线后性能观察期？

### 3. 备份与容灾

1. RPO/RTO 建议是多少？
2. 是否支持数据库时间点恢复？
3. 是否支持虚拟机整机恢复？
4. 是否支持文件级恢复？
5. 是否支持定期恢复演练？
6. 是否支持统一监控和告警？

## 七、验收原则

本项目验收不应只验收硬件到货，而应验收：

1. 服务器硬件配置。
2. 软件授权清单。
3. 虚拟化资源池可用性。
4. Oracle 数据库集群可用性。
5. 备份恢复能力。
6. 容灾切换能力。
7. Ansys Fluent 代表模型 Benchmark。
8. vGPU 图形虚拟化体验。
9. 网络和功耗适配。
10. 运维文档和监控纳管。
