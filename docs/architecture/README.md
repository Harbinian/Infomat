## 使用边界

1. 长期结构说明放在本目录。
2. 已接受的决策记录放在 `docs/adr/`。
3. 一次性审计或整改记录放在 `docs/reports/`。
4. 阶段性执行计划放在 `docs/plans/` 或 `docs/superpowers/plans/`。
5. 不在本目录放生成物、截图、运行日志或业务真源。
