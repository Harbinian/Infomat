# 物料编码怎么看——给工艺兄弟们的说明

## 先讲点大白话

咱们厂要给每一样东西编个号，跟身份证号一个道理。以后不管是在图纸上、系统里、还是仓库货架上，看到这个号，就知道说的是同一件东西。

编号最长 30 位，中间用短横杠 `-` 隔开，分成几段。你不需要会编，那是系统自动干的活儿。你只需要**看得懂**就行。

下面按东西的类型分开说。

***

## 零件、工艺组件、工装（PRT / PRC / TLG）

这三类的编号格式一样，都是 26 位。区别就在开头三个字母：

- **PRT** — 零件
- **PRC** — 工艺组件（比如拆分出来的虚拟件）
- **TLG** — 工装

### 长什么样

```
PRT - C91 - 5382 - 01200 - PAG01 - 6
 ↑     ↑      ↑       ↑       ↑     ↑
类型  哪个   机身    工程    属性   校验
      机型   部位    编号    信息   码
```

### 一段一段看

| 段     | 几位  | 啥意思                                    |
| ----- | --- | -------------------------------------- |
| 类型码   | 3 位 | PRT 零件、PRC 工艺组件、TLG 工装                 |
| 项目号   | 3 位 | 哪个飞机型号。C91 = C919，以后有新机型就加新的           |
| 部段号   | 4 位 | 飞机的哪个部位。比如 5382：538 = 后机身，2 = 压力框      |
| 说明型编号 | 5 位 | 工程师在 PLM 里给的具体编号，你可以理解成"这个东西在这一块里的第几个" |
| 扩展位   | 5 位 | 记录批产还是研制、是不是交付件、有什么变体                  |
| 校验位   | 1 位 | 系统自动算的，防输错                             |

### 扩展位里记了什么

这 5 位其实分三小段：

- 第 1 位：P = 批产，D = 研制，R = 科研，S = 试制
- 第 2 位：A = 交付件，I = 中间产物，V = 虚拟件，T = 工装件
- 后 3 位：构型或材质的变体编号

举个例子：`PAG01` 就是说这是个批产交付件，后面 `G01` 是它的变体号。

> 这些字母具体用啥，后面开会最终定，但大概就是这个意思。

***

## 材料（MTR）

材料的编号 23 位。

```
MTR - 1 - CP037 - 342 - PAG01 - 9
 ↑    ↑     ↑       ↑      ↑      ↑
材料  分类  规范号  型类级  扩展   校验
```

| 段    | 啥意思                                |
| ---- | ---------------------------------- |
| MTR  | 就是材料                               |
| 分类   | 1=上机常温，2=上机低温，3=上机金属，4=上机胶漆，5=工艺辅料 |
| 规范短码 | 材料规范的代号，对应一个完整规范号                  |
| 型类级  | 型、类、级三个数字，比如 342 = III 型 IV 类 II 级 |
| 扩展位  | 牌号和规格的引用码                          |
| 校验位  | 防输错                                |

***

## 标准件（FST）

螺栓、铆钉、衬套、垫圈这些。

```
FST - BO - NAS1580 - 00001 - 9
 ↑    ↑       ↑        ↑     ↑
标准件 类型   标准短码  流水号  校验
```

类型是两个字母，比如 BO=螺栓，RI=铆钉，BU=衬套，WA=垫圈。

标准短码和标准号的关系：你平时用的标准号（比如 NAS1580、HB1-101）有些里面带了短横杠、斜杠、空格，这些符号不能直接写进编码。所以系统里存了一个对照表，把原始标准号转成干净的短码再拼进编码。比如 HB1-101 可能对应短码 HB1101。这个转换是系统自动做的，你不用管，知道是这么回事就行。

流水号是同一个类型 + 同一个标准短码下从 00001 开始往后排。

***

## 刃具、工具、量具、设备、机物料

这几类简单，就是分类 + 流水号，系统自动往后排。

### 刃具（CTL）— 16 位

```
CTL - 01 - H - 00001 - 9
 ↑    ↑    ↑     ↑     ↑
刃具 大类  材料  流水   校验
```

材料用一个字母：H = 高速钢，C = 硬质合金，R = 陶瓷，D = 金刚石。

### 一般工具（TLS）— 14 位

```
TLS - 01 - 00001 - 5
 ↑    ↑     ↑     ↑
工具 分类   流水   校验
```

### 量具（GAG）— 22 位

```
GAG - 01 - M - H - 5 - 3 - 00001 - 9
 ↑    ↑    ↑   ↑   ↑   ↑     ↑     ↑
量具 分类 公制 手持 精度 检周  流水   校验
```

- 公英制：M = 公制，I = 英制
- 手持固定：H = 手持，F = 固定
- 精度：0-9，数字越大精度越高
- 检周：0 = 首检，1 = 1 年一检，2 = 2 年……9 = 9 年及以上

### 设备（EQP）— 15 位

```
EQP - PRD - 00001 - 3
 ↑    ↑      ↑     ↑
设备  分类   流水   校验
```

分类：PRD=生产设备，MSR=测量设备，SUP=保障设备，SAF=安全设备。

### 机物料（CSM）— 15 位

```
CSM - LBP - 00001 - 3
 ↑    ↑      ↑     ↑
机物料 分类   流水   校验
```

分类：LBP=低值易耗品，CHM=化工耗材，LAB=劳保用品，OFF=办公用品。

***

## 几点记住就行

1. **编码不会变**。一个东西的编号定了就定了，就算以后不用了也不会改。
2. **需要新编号时跟系统要**。不用你自己编，MDM 系统会自动给。
3. **零件、工艺组件、工装这三类**，编码是在 PLM 里填好各段信息，系统帮你拼出来。
4. **其他类的**（材料、刃具、工具等），告诉系统分类就行，流水号系统自己加。
5. **校验位最后一位**，是系统自动算的，用来防手输打错。可能是数字也可能是字母 X。
6. **短横杠是分隔符**，不算校验，纯粹是为了人看着清楚。

***

## 校验位是怎么防错的（MOD11）

上面说了校验位能防输错，这里展开讲讲它到底是怎么防的。不用记，知道个大概就行。

### 先看个例子

假设系统生成了这段编码（去掉短横杠，只看字母和数字）：

```
PRT C91 5382 01200 PAG01
```

要算出最后一位校验码，系统会做三步：

**第一步：字母换成数字。** A=10, B=11, C=12……一直排到 Z=35。所以 P=25, R=27, T=29, C=12, G=16。

**第二步：从右往左，给每位配一个"权重"。** 权重从 2 开始，3、4、5、6、7、8、9，到 9 之后回到 2 继续循环。

```
字符:   P   R   T   C   9   1   5   3   8   2   0   1   2   0   0   P   A   G   0   1
数值:  25  27  29  12   9   1   5   3   8   2   0   1   2   0   0  25  10  16   0   1
权重:   5   4   3   2   9   8   7   6   5   4   3   2   9   8   7   6   5   4   3   2
     ←─────────────────────────────────────────────────────────────────────────←
     从右往左配权重，最右边是 2，往左递增：3,4,5,6,7,8,9，到9后回到2继续循环
```

**第三步：每位数值 × 权重，加起来，除以 11，看余数。**

- 余数是 0~9 → 校验位就是 0~9
- 余数是 10 → 校验位就是字母 **X**

上面这个例子算出来余数是 6，完整编码就是 `PRT-C91-5382-01200-PAG01-6`。

### 为什么能揪出打错的

人输编码最容易犯两种错：

- **敲错一个字符**。比如把 C 敲成 D，那一位的加权值变了，总和除以 11 的余数就对不上，系统当场就知道错了。
- **相邻两位敲反了**。比如 53 敲成 35，因为 5×8 + 3×9 = 67，但 3×8 + 5×9 = 69，结果不一样——同样是余数露馅。

这两种错覆盖了手工录入绝大多数的翻车现场。比"让你再输一遍"靠谱，因为再输一遍只能防手滑，防不了你**脑子里一直以为那个号就是那样**。

## 常见问题

**问：为啥有的 26 位有的才 14 位？**

不同的东西需要记录的信息不一样多。零件要记机型、部位这些，东西多；一般工具就记个分类就行。位数用不完就空着，不强求填满。

**问：PRT 和 PRC 有什么区别？**

PRT 是实际做出来的零件。PRC 是工艺上拆出来的虚拟组件，不一定真做出来，但工艺路线里要用到。

**问：标准件编码里怎么看不到我熟悉的那些标准号？**

原始标准号有些带了短横杠、斜杠、空格（比如 HB1-101），这些符号按规定不能写进编码。系统里有一张对照表，把原始标准号转成干净的短码，编码里用的就是那个短码。你想查原始标准号的话，系统里能反查出来。
