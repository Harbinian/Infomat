# docs/screenshots 说明

> 状态：历史截图样例目录  
> 生效日期：2026-06-10  
> 范围：用于说明或回顾的少量截图和截图索引。

本目录保存历史截图样例。截图只能作为当时界面状态的视觉参考，不作为当前 PMO、MDM 或流程数据真源。

## 当前内容

- `*.png`：历史页面或功能截图。
- `screenshots-base64.json`：截图的 base64 汇总记录，属于生成型辅助材料。

## 使用边界

1. 判断当前界面状态时，应重新打开页面或运行对应测试，不从截图反推。
2. 新增截图前，确认它是否真的需要长期保留；临时截图应放入本地输出目录或测试产物目录。
3. 大量截图或 base64 汇总后续迁移前，应先写提案并确认引用关系。
