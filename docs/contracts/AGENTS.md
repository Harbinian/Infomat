# AGENTS.md — 机器可读结构规则

根目录 `AGENTS.md`、`CODEX.md` 和仓库边界文件继续有效。本文件规定 `docs/contracts/` 的本地维护边界。

## 目录责任

本目录只保存机器可读的结构规则、校验规则和版本历史。规则用于约束脚本、3001、3000 和受限辅助工具的输入输出，不替代 `docs/norms/` 的流程输入基线、制度或表单原文，也不替代 `docs/organization/` 的组织真源。

## 修改规则

1. 修改前先列出实际消费方、受影响字段、当前发布版本和旧数据来源，确认规则字段确实被实现读取。
2. 已发布的 `process-governance-vN` 不在同一版本内改变摘要、必填字段、枚举、引用规则或导入导出结构；需要改变时发布新版本，并把旧数据迁移或兼容读取作为同一项工作。
3. 不为填满结构而补造流程、部门职责、业务行为、责任主体、来源证据或正式主数据认定。
4. 不新增与现行规则并行但无迁移关系的重复 Schema，也不让历史兼容规则重新成为当前导出入口。
5. 结构文件不得包含密码、令牌、私钥、真实连接信息或未脱敏业务内容。

## 固定验证

按影响范围运行 `README.md` 列出的结构规则回归。涉及 `process-governance-v*` 时，至少验证上一支持版本导入当前版本、当前版本导出后重新导入、重复迁移和迁移失败后源文件及当前草稿不变。
