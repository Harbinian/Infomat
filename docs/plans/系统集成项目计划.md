## 项目概述

**项目名称**：沈阳昌兴复材航空科技有限责任公司制造企业数字化运营平台系统集成项目

**项目目标**：实现 ERP（用友U8）、MES（北京虎蜥）、OA（华天动力）、PLM（暂定）、PDM、CAPP、WMS、SCIM 等八套系统的互联互通，建立统一数据底座，支撑端到端业务协同。

**项目范围**：

| 系统 | 供应商（暂定） | 定位 |
|------|-------------|------|
| ERP | 用友U8 | 企业资源计划核心层 |
| MES | 北京虎蜥 | 制造执行层 |
| OA | 华天动力 | 流程协同层 |
| PLM | 翎瑞鸿翔（一期） | 产品全生命周期管理 |
| PDM | 翎瑞鸿翔（一期，MBOM模块） | BOM管理 & 工艺数据管理 |
| CAPP | 暂定 | 工艺设计 |
| WMS | 暂定 | 仓储管理 |
| SCIM | 暂定 | 供应商协同门户 |

## 接口链路清单

### 研发域集成链

```
需求管理软件 → PLM平台（暂定供应商）
    ├── LCA（生命周期评估）
    ├── CPM（研发计划与关键路径）
    ├── CATIA + MBD（三维设计与模型定义）
    ├── EBOM管理
    ├── 更改管理（ECR/ECO）
    └── 文档管理（设计资源受控）
           ↓ 受控发布
         PDM（BOM管理 & 工艺数据管理）
           ↓                ↓
       CAPP              ERP-PP（用友U8）
   （工艺设计）         （生产计划）
   工艺路线/定额/         MBOM+分工
   三维工艺/工装            +定额下达
         ↓                     ↓
   工程解构               MES（北京虎蜥）
   制造说明              （制造执行）
```

### 采购供应链集成链

```
ERP-PP（用友U8/MRP运算）→ 计划管控 → ERP-MM → SCIM → 合同管理 → WMS → MES
```

### 制造执行闭环

```
ERP-PP下达生产订单 → MES（排产/工艺/执行/工时/数据采集/现场质量）→ ERP反馈 → 成本归集 → 财务核算
```

### OA流程协同（横向贯穿）

```
OA（华天动力） ↔ 合同管理系统（审批流）
OA ↔ ERP-MM（采购申请/审批）
OA ↔ ERP-FI/CO（费用凭证）
OA ↔ PDM（ECO变更/文件会签）
OA ↔ 一体化平台（项目审批节点）
OA → 全系统（单点登录）
```
