# 昌兴公司06B厂房接入民机非密园区网实施方案

## 1. 项目背景

昌兴公司与民机公司为两个独立法人实体，但在管理架构上，昌兴公司隶属于民机公司零件制造中心管理。为支撑零件制造中心的业务协同与信息化系统运行，昌兴公司需通过专线方式接入民机公司非密园区局域网络。

本项目源于民机公司信息化工作例会会议行动项 — 关于昌兴公司06B厂房网络接入事宜的决议。项目实施遵循"统一规划、分步实施、适度超前"的总体原则。

## 2. 建设目标

1. 实现昌兴公司06B厂房安全接入民机公司非密园区局域网
2. 支撑昌兴公司业务信息系统稳定运行，保障零件制造中心业务协同
3. 建成符合等保三级要求的网络安全防护体系
4. 预留面向后续业务系统对接的扩展接口
5. 避免重复建设，降低长期运维成本

## 3. 需求分析

### 3.1 接入边界

- 昌兴公司06B厂房仅接入民机公司**非密园区局域网**，不涉及涉密网络
- **明确排除**：食堂卡务系统、安防监控网络不在本次接入范围内，上述网络由昌兴公司自行管理
- 接入边界以防火墙为界，防火墙以内（昌兴侧）为昌兴公司内部网络，防火墙以外（民机侧）为民机公司非密园区网

### 3.2 系统归属矩阵

| 系统名称 | 系统归属 | 互联对象（民机侧） |
|----------|----------|-------------------|
| OA 办公系统 | 昌兴自建（含零件制造中心二级开发模块） | 民机 OA |
| ERP 企业资源计划 | 昌兴自建 | **不接入民机 SAP** |
| MES 制造执行系统 | 昌兴自建 | 民机 MES / 数据中台 |
| PDM 产品数据管理 | 昌兴自建 | 民机 PDM / 数据中台 |
| QMS 质量管理系统 | 昌兴自建 | 民机 QMS / 数据中台 |
| WMS 仓储管理系统 | 昌兴自建 | 民机 WMS / 数据中台 |

### 3.3 用户规模

| 指标 | 数值 |
|------|------|
| 同时在线终端数（桌面 PC） | 约 120 台 |
| PDM 系统用户（大文件传输） | 30 人 |
| OA/ERP 日常办公用户 | 90 人 |
| 高频使用设备（每日） | 约 30 台 |
| 中频使用设备 | 约 50 台 |
| 低频使用设备 | 约 40 台 |

### 3.4 互联模式需求

五个互联模式全部需要支持：

| 模式 | 说明 | 典型场景 |
|------|------|----------|
| 数据回写（Write-back） | 昌兴系统向民机系统写入数据 | MES 生产数据上报、QMS 质量数据报送 |
| 数据读取同步（Read-sync） | 昌兴系统从民机系统读取并缓存数据 | WMS 库存同步 |
| 实时查询（Real-time Query） | 昌兴系统实时调用民机接口获取数据 | MES/PDM 实时工艺文件查询 |
| 文件交换（File Exchange） | 跨系统文件传输 | PDM 图纸、工艺文件交换 |
| 联邦身份（Federated Identity） | 统一身份认证 | OA 流程跨实体审批 |

## 4. 网络架构方案

### 4.1 拓扑结构

```
昌兴06B厂房 → 防火墙（昌兴侧部署，民机策略管理）→ 1Gbps 专线 → 民机核心交换机 → 非密园区局域网
```

整体采用双模式架构设计：

- **通道 A**：内部用户直接访问模式 — 昌兴用户通过专线直接访问民机 OA/SAP 等内部系统
- **通道 B**：可控系统互联模式 — 昌兴自建系统通过防火墙受控策略连接民机对应系统

| **Combo 口** | ≥ 8 个 |

| **并发连接数** | ≥ 150 万 |
| **新建连接数** | ≥ 2.5 万/秒 |
| **IPS/AV 吞吐量** | ≥ 800Mbps |
| **全威胁吞吐量** | ≥ 500Mbps |
| **功能** | 路由/透明/混合模式、USB 零配置上线、AI 策略分析、资产扫描、加密流量检测、应用审计、数据安全、网页过滤、带宽管理、IPS、AV、SSL VPN/IPsec VPN、国密算法、IPv6 |

### 4.3 双模通道设计

**通道 A — 内部用户直接访问**

- 昌兴06B厂房用户视为民机非密园区网内部用户
- 通过专线直接访问民机 OA、SAP 及其他内部业务系统
- 使用民机公司域账号进行身份认证
- 防火墙策略配置为白名单模式，仅放行经审批的访问目标

**通道 B — 可控系统互联**

- 昌兴自建系统（MES/PDM/QMS/WMS）与民机对应系统之间的系统级对接
- 所有通道 B 流量均经过防火墙深度包检测（DPI）
- 接口访问采用 API Key + IP 白名单双重认证
- 禁止通道 B 流量直接访问民机内部用户终端

### 4.4 QoS 流量分级

| 优先级 | 类别 | 说明 | 带宽限制 |
|--------|------|------|----------|
| 1（保障级） | OA/ERP HTTP 流量 + MES/PDM 实时查询 | 办公协同与生产实时业务 | 不限 |
| 2（限制级） | PDM 大文件传输 | 图纸/工艺文件传输 | 单流 300Mbps，合计 600Mbps |
| 3（尽力级） | 系统批量数据同步 | 后台批量同步任务 | 不限 |
| 4（背景级） | 文件交换 | 非实时文件交换 | 最低保障 |

### 4.5 冗余策略

| 决策 | 说明 |
|------|------|
| 专线单链路 | 以成本优先原则，暂不铺设第二条物理专线 |
| 防火墙双交流电源 | 设备层面供电冗余 |
| SSL VPN（15 用户）| 专线中断时关键岗位应急接入 |
| 链路冗余风险接受 | 经评估，单链路中断影响可控，接受为已知风险 |

### 4.6 等保定级

依据《信息安全技术 网络安全等级保护基本要求》（GB/T 22239-2019），本网络互联系统定级为**等保三级（S3A3G3）**。

| 等级 | 适用标准 | 关键要求 |
|------|----------|----------|
| 三级 | GB/T 22239-2019 | 双因子认证、加密传输、数据库审计、年度测评 |

## 5. 系统对接矩阵

| 昌兴系统 | 民机对接目标 | 数据流向 | 互联模式 | 实时性要求 |
|----------|-------------|----------|----------|-----------|
| OA 办公系统 | 民机 OA | 零件制造中心审批单/工令，双向读写 | Write-back + Read-sync | 准实时 |
| ERP 企业资源计划 | — | **不接入民机 SAP** | — | — |
| MES 制造执行系统 | 民机 MES / 数据中台 | 生产数据上报、工艺文档下发 | Real-time Query + Write-back | 实时 |
| PDM 产品数据管理 | 民机 PDM / 数据中台 | 图纸/工艺文件（B 模式实时拉取）| Real-time Query + File Exchange | 实时 |
| QMS 质量管理系统 | 民机 QMS / 数据中台 | 质量数据报送 | Write-back | 可接受异步 |
| WMS 仓储管理系统 | 民机 WMS / 数据中台 | 库存同步 | Write-back + Read-sync | 可接受异步 |

### PDM 大文件传输专项说明

- 传输模式：B 模式实时拉取（B-mode real-time pull）
- 用户规模：30 人（PDM 用户）
- 网络限制：QoS 分级管控，单流 ≤ 300Mbps，合计 ≤ 600Mbps

## 6. 身份认证方案

| 场景 | 认证方式 | 说明 |
|------|----------|------|
| 通道 A：用户直接访问民机系统 | 民机域账号 | 昌兴用户分配民机域账号，直接登录民机 OA/SAP 等系统 |
| 通道 B：系统间接口对接 | 独立账号 + 映射表（初期）；SAML/OIDC 联邦（后期）| 初期通过接口账号映射表管理；后期建设联邦身份，以民机 IdP 为主认证源 |
| 平板终端（PAD）| 仅在昌兴侧使用 | 不经专线跨接，无需民机侧认证 |

**AD/LDAP 延伸方案评估**：不推荐将民机 AD/LDAP 域控延伸至昌兴06B。两实体为独立法人，跨法人实体的域延伸在安全合规层面存在显著风险，且不符合等保三级对网络边界隔离的要求。

## 7. 信息安全与合规

### 7.1 等保三级合规要求清单

| 编号 | 要求项 | 落实方式 |
|------|--------|----------|
| 1 | 双因子认证 | 所有远程访问（含 SSL VPN）必须启用双因子认证 |
| 2 | 加密传输 | 所有跨专线流量强制 TLS 1.2 及以上加密 |
| 3 | 数据库审计 | 部署数据库审计系统，日志留存 ≥ 6 个月 |
| 4 | 年度测评 | 每年委托有资质的第三方测评机构进行等保测评及整改 |
| 5 | 安全事件应急预案 | 制定网络中断、数据泄露、恶意代码等场景的应急处置预案 |
| 6 | 网络边界监控 | 防火墙全流量日志 + NTA 流量分析 |
| 7 | 访问控制 | 最小权限原则，按岗位/角色分配系统访问权限 |
| 8 | 安全日志集中分析 | 防火墙、服务器、应用日志统一汇聚至日志管理平台 |

### 7.2 防火墙安全策略管理

- 策略制定权归属民机公司网络信息办公室
- 所有防火墙策略变更须经民机网络信息办公室审批后执行
- 防火墙策略每季度由民机网络信息办公室进行合规审计
- 昌兴公司负责防火墙设备的物理环境和日常运行维护

## 10. 实施计划

| 阶段 | 时间节点 | 实施内容 |
|------|----------|----------|
| 第一阶段 | 2026 年 8 月底前完成 | **专线建设 + 防火墙部署 + 通道 A 上线**：铺设 1Gbps 专线，完成防火墙安装调试，通道 A 开通 120 台终端接入民机 OA/SAP，等保三级定级备案 |
| 第二阶段 | 2026 年 10 月 — 11 月 | **OA 系统对接**：实现昌兴 OA ↔ 民机 OA 双向读写（零件制造中心审批/工令模块上线） |
| 第三阶段 | 不早于 2027 年 Q3 | **全业务系统对接 + 联邦身份**：MES/PDM/QMS/WMS 全面集成，联邦身份认证体系上线。**前置条件**：昌兴自建各系统开发完成 + 民机数据中台就绪 |
