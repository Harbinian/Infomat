# 3001 交互缺陷收口与批量数据编辑升级

> 状态：隔离候选已完成技术验证，尚未发布
> 日期：2026-08-21
> 适用对象：流程编制人、业务核对人、MDM 工作组接收人
> 结构版本：`process-governance-v7`

本设计包用于收口 3001 七步编制中的交互设计缺陷，并增加从 Excel 或 WPS 表格复制粘贴后批量编辑数据对象、对象字段和数据行为关系的能力。

本次升级只调整浏览器内的编辑行为，不改变 v7 JSON 结构，不新增数据库、服务端草稿、浏览器持久化、3000 通信、AI 分析或网络分析。用户下载 JSON 仍是唯一持久化动作。
