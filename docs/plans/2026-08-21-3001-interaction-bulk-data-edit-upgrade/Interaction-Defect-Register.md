# 3001 交互设计缺陷台账

> 记录日期：2026-08-21
> 证据范围：3001 v7 第 5 步真实浏览器检查和现有前端代码核对

| 编号 | 问题类型 | 已确认现象 | 用户影响 | 处置原则 |
|---|---|---|---|---|
| UX-01 | 提示阶段错位 | 进入编制步骤即显示整份流程待补充项 | 用户尚未完成输入就被要求处理后续核对事项 | 第 1 至第 5 步改为主动“检查本轮” |
| UX-02 | 角色责任混淆 | 生命周期、业务关系和交接事项在编制人页面混合出现 | 用户无法判断由本人处理还是交给后续角色 | 按编制、自检、业务核对和交接四类分层 |
| UX-03 | 问题类型混杂 | 技术错误、业务待定和填写建议统一称为“待补充项” | 严重程度和处理方式不清 | 技术结构错误、业务核对项、交接检查事项分别命名 |
| UX-04 | 信息层级失衡 | 问题面板默认展开并位于主要编辑器前 | 当前任务被大量问题文本遮挡 | 默认收起或不渲染，主要编辑器优先 |
| UX-05 | 导航负担 | 第 5 步包含多层视图、卡片和逐项编辑入口 | 用户需要记忆当前对象、字段和关系上下文 | 保留单项编辑，增加集中批量工作区 |
| DM-01 | 重复录入 | 对象字段只能逐行新增和编辑 | 同一业务流程的大量公共字段重复输入 | 支持 Excel/WPS 复制粘贴和复制当前数据 |
| DM-02 | 上下文切换 | 数据对象、字段和行为关系分散编辑 | 容易选错对象或遗漏关系 | 三类固定表格、统一预览和定位错误 |
| DM-03 | 缺少变更预览 | 当前逐项操作立即改变草稿 | 批量输入时难以发现误更新或误删除 | 先在副本计算差异，再一次应用 |
| DG-01 | 引用歧义 | 数据对象和业务行为可能重名 | 按名称自动匹配可能连接错误记录 | 技术标识优先；重名时阻止并要求补标识 |
| DG-02 | 删除破坏引用 | 对象字段可能被多个表单字段引用 | 删除后产生悬空引用或数据丢失 | 显式删除并执行引用影响检查 |
| DG-03 | 部分成功 | 多行逐条写入可能在中途失败 | 用户不知道哪些行已经生效 | 整批校验、整批应用、整批撤销 |
| SEC-01 | 剪贴板隐私 | 自动读取剪贴板会扩大数据暴露范围 | 用户无法控制页面读取的内容 | 只处理主动粘贴，不请求剪贴板读取权限 |

以上问题不是单一“页面不好用”，而是交互流程、信息架构、批量效率、数据治理安全和隐私边界共同作用的系统性问题。修复顺序应先消除阶段与角色错位，再提供批量编辑，最后用引用检查、预览和撤销控制批量变更风险。
