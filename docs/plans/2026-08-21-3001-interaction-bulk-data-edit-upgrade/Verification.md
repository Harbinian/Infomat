## 3. 真实浏览器

### 3.1 提示阶段与角色

- 新建草稿进入步骤2时，没有自动展开待补充项，只显示“检查本轮”。
- 主动检查后，步骤标签显示“自检6项”，正文显示“本轮自检项”。
- 修改流程名称后，自检面板立即移除，按钮恢复为“检查本轮”，步骤状态恢复“编制中”。
- 步骤6显示“业务核对项”，步骤7显示“交接检查事项”。

### 3.2 Excel/WPS批量编辑

- 数据对象表格：粘贴新增“财务凭证”，预览显示1项新增，一次应用后数据对象列表出现该对象。
- 错误恢复：将信息类型填写为“错误类型”时，预览定位到第2行“信息类型”，应用按钮禁用，当前流程不变。
- 对象字段表格：只用唯一对象名称定位“财务凭证”，新增“凭证编号”字段，预览和一次应用通过。
- 字段类型目录：新增字段填写“任意自定义类型”时，预览定位到第2行“字段类型”，整批阻止且应用按钮禁用；批量入口没有绕过现有受控字段类型目录。
- 数据行为关系表格：只用唯一对象名称和行为名称定位，新增“财务凭证/审核付款/使用”关系，预览和一次应用通过。
- 撤销：应用数据对象批次后点击一次“撤销”，整批新增对象被移除，重做按钮可用。

### 3.3 布局与控制台

在1920×1080、1536×864和1280×720三档浏览器内容可视区检查：

- 页面级`scrollWidth`等于`clientWidth`，没有横向溢出。
- 批量表格类型、操作顺序、粘贴区、预览和一次应用均正常渲染。
- 浏览器控制台没有新增错误。
- 控制台保留既有Cytoscape自定义滚轮灵敏度警告；本次没有修改图缩放参数，该警告不属于本次新增缺陷。
