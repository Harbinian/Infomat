# 3001 交互缺陷收口与批量数据编辑测试计划

## 1. 自动化测试

| 组别 | 必测内容 |
|---|---|
| TSV 解析 | CRLF/LF、列重排、空行、双引号、单元格内换行、双引号转义、缺失列头、重复列头 |
| 数据对象 | 新增、更新、不变、显式删除、重复标识、无效信息类型、同名不误匹配 |
| 对象字段 | 新增、更新、跨对象移动阻止、删除被表单引用字段阻止、对象重名阻止 |
| 数据行为关系 | 新增、更新、删除、无效操作、对象或行为引用不明确、创建行为冲突 |
| 原子性 | 任一行失败时原文档不变；成功批次一次撤销恢复全部变更 |
| 提示分层 | 第 1 至第 5 步默认不展开；主动检查后显示；修改后检查失效；第 6、7 步名称正确 |
| 回归 | 现有 service contract、v6 图编辑、v7 生命周期、v7 字段复用和七步工作流测试通过 |

## 2. 迁移与恢复

1. 上一受支持版本导入当前版本后执行批量编辑。
2. 当前版本导出后重新导入，批量编辑结果保持一致。
3. 对同一历史文件重复执行迁移，结果稳定。
4. 粘贴解析失败、引用解析失败或候选结构校验失败后，当前草稿和源文件保持不变。

## 3. 真实浏览器

固定验证三档桌面视口：1920×1080、1536×864、1280×720。

每档至少验证：

- 第 5 步主要编辑区不会被默认展开的问题面板遮挡。
- 单项编辑与 Excel/WPS 批量编辑切换清楚。
- 复制列头、粘贴、错误定位、差异预览、应用和撤销可操作。
- 长字段定义、20 行以上粘贴内容和错误列表不造成页面横向溢出。
- 键盘焦点、按钮禁用状态、成功或失败反馈清楚。
- 浏览器控制台无新增错误。

## 4. 性能样本

使用至少 30 个数据对象、200 个对象字段、120 条数据行为关系的代表性样本：

- 粘贴和预览不应造成超过 1 秒的可感知页面冻结。
- 一次应用后页面可继续编辑和撤销。
- 批量区不重复渲染整张关系图，图形只在成功应用后刷新一次。

## 5. 发布门槛

只有在自动化、迁移恢复、三档浏览器和正式服务健康检查全部通过后，才能形成发布候选。真实脱敏流程的业务核对属于使用中验证，不得被自动化测试替代。
