# 3001流程结构规则v4迁移与验收计划

## 迁移核对

- 分别导入v1、v2、v3样例，核对流程、行为、关系、数据、跨部门承接、表单、字段、术语和稳定标识的保留数量。
- 核对旧产生和输出引用转换为“创建”，旧使用和输入引用转换为“使用”；冲突创建转换为“待确认”。
- 核对旧表单行为关系操作为空，旧字段关系为待确认，不按名称补造关系。
- 对同一输入重复规范化，核对关系数量、技术标识和内容不继续变化。
- 制造非法枚举和断开引用，确认校验失败且当前页面内容和源文件保持不变。

## 往返核对

- v4当前页面导出后重新导入，核对新关系、来源线索、表单区域、字段顺序和迁移信息。
- 检查序列化、回读、再次规范化和`/api/validate`，任何内容丢失都阻断导出。

## 代表性规模

使用约40个业务行为、30个数据对象、10张表单、200个字段和80条字段来源关系执行页面操作、校验、导出和重新导入。自动视觉验证只使用1920×1080及以上窗口。

## 业务场景

覆盖本地创建、更新和使用；多行为处理一张表单；主表和多张明细表；字段直接取值和依赖数据；一字段多个来源作用；流程开始可用和指定行为后可用；跨流程来源信息不完整；数据重名；被引用对象删除保护；关系总览；版本说明与当前文件迁移摘要。
