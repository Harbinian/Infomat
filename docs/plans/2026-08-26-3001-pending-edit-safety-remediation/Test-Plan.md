## 1. 状态控制器

自动测试至少覆盖：

- 创建、修改、应用、放弃和重置编辑会话；
- 同一时间只能有一个显式编辑会话持有未应用修改；
- 候选、对象种类和稳定标识隔离；
- 未修改会话可以无提示关闭；
- 已修改会话触发应用、放弃和继续编辑三项保护；
- 不完整向导不能应用；
- 应用失败保留工作副本；
- 同字段冲突阻止应用，并保留输入；
- 非本编辑器字段变化时，字段补丁仍安全合并；
- 成功安装新数据后，全部临时状态原子清理。

## 2. 属性补丁

| 场景 | 可验证结果 |
|---|---|
| 修改业务行为名称 | 动作说明、完成标准、会签和其他步骤字段保持不变 |
| 修改流程关系类型或端点 | 关系条件保持不变 |
| 修改数据对象名称、说明或信息类型 | 对象字段、行为关系、来源关系和生命周期保持不变 |
| 同字段被其他入口修改 | 应用被阻止，页面列出冲突字段，输入保留 |
| 对象已删除 | 旧编辑会话不能应用到其他对象 |
| 导入含相同稳定标识的新文件 | 旧候选工作副本不得出现或覆盖新内容 |
| 引用对象字段 | 只同步技术归属、类型和空白显示名称，不按引用先后推断权威录入、沿用已有值或取值方式 |

## 3. 真实页面切换矩阵

分别以业务行为属性、流程关系属性、数据对象属性、数据行为操作、新流程关系向导、新数据行为关系选择和网页表格为未应用来源，逐项执行：

- 选择另一个对象、图节点或关系；
- 切换步骤和同一步骤视图；
- 切换数据流/生命周期；
- 切换业务式/表格式编辑；
- 使用顶部和侧栏切换候选；
- 撤销和重做；
- 问题定位跳转；
- 新建、导入和清空；
- 阶段下载和最终下载。

每个可应用场景验证“应用修改并继续”“放弃修改并继续”“继续编辑”、应用校验失败和同字段冲突。用户选择继续编辑后，页面恢复原候选、控件值、滚动位置、图形焦点和键盘焦点。顶部候选下拉框恢复原值。

图命令之后再修改普通即时写入字段时，撤销和重做必须因来源变化而阻止，当前JSON和历史记录均不得被旧快照覆盖或消耗。

## 4. 原问题专项回归

1. 编制人修改数据对象名称、说明或信息类型，但不点击应用。
2. 编制人尝试进入生命周期。
3. 页面先显示统一三项保护，不得静默切换或提交。
4. 选择继续编辑后，页面保留原输入。
5. 选择应用后，当前JSON包含修改，其他对象字段和关系保持不变。
6. 选择放弃后，属性卡显示已经应用的值。
7. 编制人从生命周期点击“返回数据流编辑对象信息”，页面返回同一对象的属性区，不克隆旧对象。
8. 属性卡任何可编辑状态都必须存在有效编辑会话；“应用修改”不得静默无效。

## 5. 下载、替换和离页

- 当前JSON与下载基线一致、只有属性未应用时，页面显示“有未应用修改”，下载不得直接开始。
- 应用后下载并重新导入，文件包含修改；放弃后下载并重新导入，文件不包含修改。
- 只有未应用修改时，刷新和关闭仍触发浏览器离页保护。
- 下载成功后，只有实际进入文件的JSON成为新基线。
- 新建、导入和清空先处理未应用修改，再处理未下载修改。
- 导入失败或取消后，当前JSON、编辑会话、候选、选择、撤销记录和焦点保持不变。
- 页面不得同时显示“当前内容已下载”和尚未处理的可见输入。
- 新建流程后、首次成功下载前显示“尚未下载”，不得显示“当前内容已下载”。
- 原生v7导入后显示“当前内容与导入文件一致”，不得把导入基线写成本次会话已下载。
- 只有文件实际生成成功，且进入文件的JSON成为新基线后，页面才显示“当前内容已下载”。

## 6. 生命周期纯读取

分别记录操作前后的JSON指纹、未下载状态和撤销记录数量。数据流/生命周期切换、选择对象、展开生命周期详情、展开主数据提示依据和普通重绘后，三项结果必须保持不变。

显式重新分析结果有变化时，只形成一次撤销记录和一次未下载变化；结果无变化时，不新增记录。已核对、已否决和不适用决定不得被覆盖。分析失败时，当前JSON保持不变。

## 7. 删除安全

对数据对象、对象字段、数据行为关系、数据来源关系、表单、表单区域、表单字段、表单行为关系、字段取值来源、流程关系、孤立业务行为和术语分别验证：引用阻断、显示名称和影响的确认、取消删除、确认删除、一次撤销、撤销后完整恢复、无静默级联、下载后重导入一致。

另行验证生命周期路径引用阻止删除流程关系，生命周期事件引用阻止删除触发行为。引用阻断后当前JSON和撤销记录不得变化。
