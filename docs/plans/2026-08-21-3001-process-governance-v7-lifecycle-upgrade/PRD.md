# PRD：3001 v7数据生命周期编制

## 1. 目标

业务人员先定义数据对象及其字段，再让同一流程中的表单主表和明细表引用这些字段。3001据此减少同一字段在多张表单中的重复维护，并自动汇总对象关联的业务行为和流程关系，生成可追溯的生命周期事实或待确认建议。用户按数据对象集中核对，不需要逐张表单或逐个业务行为重新定义数据。

3001仍只输出单流程、未审核JSON。业务部门确认当前流程事实；3000负责跨流程一致性、主数据认定、审核证据和版本发布。

## 2. 用户路径

1. 用户导入v1至v7文件或新建v7草稿。
2. 用户在步骤5建立数据对象字段，填写字段名称、类型和业务定义。
3. 用户在表单主表或明细表中引用对象字段，并确认权威录入、引用已有值、计算生成、外部来源或待确认。
4. 用户确认数据对象及其`create`、`update`、`use`关系。选择`update`时，用户在弹窗中从当前数据对象的对象字段里多选本次实际更新的字段。
5. 页面自动分析当前对象；用户也可以重新分析当前对象或全部对象。
6. 用户在“数据流”和“生命周期”视图之间切换，核对入口状态、路径事件和出口状态。
7. 用户处理字段复用冲突、待确认、高风险和来源变化项；已确认或已否决内容不会被重新分析覆盖。
8. 步骤7以“数据生命周期与异常处理”作为第六个评审方面。
9. 结构错误阻止下载；字段复用冲突、生命周期缺口和主数据提示不阻止下载。

## 3. 范围

- 区分生效、停用、重新启用、作废、失效、归档、恢复在用保管、销毁和不可逆匿名化。
- 分别记录业务效力、保管状态、可识别性及适用性。
- 每个对象记录入口状态；每条已建路径记录事件和出口状态。
- 生命周期事件记录触发、结果、作用范围、责任、例外、来源和核对状态。
- 数据对象统一定义当前单流程内可复用的字段；表单通过稳定引用使用对象字段。
- 表单继续单独记录主表或明细表位置、必填、填写说明和顺序，字段类型从对象字段继承。
- 字段值使用方式区分权威录入、引用已有值、计算生成、外部来源和待确认。
- 更新关系记录本次实际更新的一个或多个对象字段；不把整个数据对象笼统视为全部字段均已更新。
- 流程闭环核对提示显示关系起点和终点，点击后定位终点业务行为。
- 前端提供非阻断的主数据认定提示；不保存正式主数据结论。
- 支持v1至v6导入到v7、v7往返、重复迁移和失败恢复。
- v1至v3迁移同时读取行为侧和数据对象侧的数据引用。明确输入形成“使用”关系；唯一且无冲突的输出形成“创建”关系；多输出、多个生产行为和双方冲突保持待确认。
- 单个导入JSON不得超过10MB，并且必须是有效UTF-8文本。超限、编码错误、未知版本或非法结构不得改变当前草稿。

## 4. 非目标

- 不增加数据库、账号、自动保存、浏览器持久化、AI或网络分析。
- 不调用3000，不执行真实停用、归档、销毁或匿名化动作。
- 不把系统删除映射为业务生命周期动作。
- 不把当前单流程的对象字段引用作为企业级字段身份、黄金源结论或跨流程自动合并依据。
- 不执行真实表单运行时的自动带入、只读或字段权限控制。
- 不向v6降级导出，不把v7文件描述成已经可直接导入3000。

## 5. 验收标准

- v7结构规则拒绝非法枚举、断裂引用和高风险事件的自动确认。
- 相同输入和分析器版本产生相同建议；重复分析不重复创建事件。
- 已确认、已否决和不适用决定可下载、重导并保留。
- v1至v6迁移不猜测生命周期事实，且不修改源文件。
- 早期v7只缺少后来增加的对象字段、表单字段引用、值使用方式或更新字段引用时可以兼容迁移；非法枚举、额外字段、断裂引用和重复技术标识仍被拒绝。
- 第一次迁移与第二次迁移语义相同；新增数据关系明确带有`updated_field_refs`，字段归并同步改写更新字段引用。
- 数据和表单关系只能指向业务行为节点。开始、结束、判断、并行拆分和并行汇聚等控制节点不得承担数据操作或表单处理。
- 未知结构版本、畸形JSON、超深对象、超长文字、异常Unicode和不安全DOCX返回稳定的4xx JSON错误；响应不泄露绝对路径、堆栈或底层异常详情。
- 同一对象内同名同类型旧字段自动引用同一个对象字段；同名不同类型字段分别保留并提示。
- 表单引用不存在对象字段、引用其他对象字段或字段类型与对象字段不一致时，v7结构校验拒绝文件。
- 数据操作选择更新后，页面打开字段多选弹窗；未选字段时保留明确待核对提示，引用其他数据对象字段时结构校验拒绝文件，非更新操作不保留更新字段。
- 多条闭环核对提示均显示具体关系，点击任一提示后只定位并高亮该关系的终点节点，不修改关系类型。
- 首个表单引用默认权威录入，后续引用默认使用已有值；多个权威录入位置或无建立位置的引用只提示，不自动选取权威来源。
- 分支、并行、循环均能按已有`flow_relations[]`形成路径引用，不另建自由状态机。
- 1280、1536和1920三档桌面视口无页面级横向溢出，关键操作可见，控制台无错误。
