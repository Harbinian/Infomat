# 迁移测试计划：3001 v7

## 1. 自动化样本

- v1至v6各迁移到v7，核对结构版本、稳定引用、业务内容、对象字段、表单引用、值使用方式和待确认生命周期容器。
- 同一对象内同名同类型表单字段归为同一对象字段，首个直接采集位置为权威录入，后续依赖位置引用已有值。
- 同名不同类型字段分别生成对象字段；跨对象同名字段不归并。
- 早期不含对象字段的v7候选补齐字段引用，同时保留既有生命周期和人工决定。
- 构造断裂对象字段引用、跨对象引用和字段类型不一致，核对v7校验拒绝。
- v7下载后重新导入，核对已确认、待确认、需要重新核对、不适用和已否决内容。
- 同一输入重复迁移和重复分析，核对不重复创建事件或路径。
- 对源对象做深度快照，核对迁移和失败路径均未修改源对象。
- 构造非法枚举、断裂路径引用和高风险自动确认，核对v7校验拒绝。

## 2. 流程图形态

- 分支：同一对象的不同出口路径保留不同事件和出口状态。
- 并行：路径引用既有并行关系，不合并成单一路径结论。
- 循环：允许路径引用循环关系，分析合并键保证不无限递归、不重复生成。
- 大流程：使用代表性对象和行为数量检查分析耗时、页面响应和事件列表可读性。

## 3. 失败恢复

- 导入前建立含未下载修改、当前对象选择和撤销记录的草稿。
- 导入非法文件，确认上述状态保持不变。
- 修复文件后重新导入，确认只在全部校验通过后替换草稿。
- 服务回退到v6时，不生成降级文件；恢复v7后重新导入原v7文件。

## 4. 浏览器验收

在1280×720、1536×864和1920×1080三档视口检查：七步导航、对象字段编辑、两张表单引用同一对象字段、权威录入与引用已有值自动选择、数据视图切换、对象属性面板、主数据提示、生命周期事件核对、下载提示、页面级横向溢出、长文本和控制台错误。正式结论记录实际浏览器和服务提交，不以本文档代替测试结果。
