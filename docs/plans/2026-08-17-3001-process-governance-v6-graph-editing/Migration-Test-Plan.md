# 3001流程结构规则v6迁移与验收计划

## 迁移核对

- 分别导入v1、v2、v3、v4、v5样例，核对流程、行为、关系、数据、表单、字段、术语和稳定标识的保留数量。
- 核对`current_actor_role`拆解：`全公司`转为`company_wide`；部门岗位拼接转为`actor_department`和`actor_position`；无法拆分的内容进入`unresolved_actor_roles[]`。
- 核对`work_role`非空记录移入`migration.work_roles[]`并保持`behavior_ref`绑定；空值不生成记录。
- 核对`reference_materials`和`internal_process_calls`移入`migration`后只读保留、无损往返。
- 核对`governance_status`和`join_mode`删除后不影响校验、评分和绘图。
- 核对旧跨部门记录只在导入时转换，结果进入`legacy_cross_department_records[]`，不参与当前流程计算、评分或绘图。
- 对同一输入重复规范化，核对关系数量、技术标识和内容不继续变化。
- 制造非法枚举和断开引用，确认校验失败且当前页面内容和源文件保持不变。

## 往返核对

- v6当前页面导出后重新导入，核对新字段、归档内容、迁移信息和稳定引用不丢失。
- 检查序列化、回读、再次规范化和`/api/validate`，任何内容丢失都阻断导出。

## 图编辑验收

- 图上新建五类要素后，对应数组正确写入，技术标识唯一。
- 图上建立和修改流程关系与数据关系后，`flow_relations[]`和`data_objects[].behavior_links[]`正确更新。
- 点击图中元素跳转文字编制对应项并聚焦；反向"定位到图"居中该元素。
- 图上操作产生损坏引用时当场阻断并提示，不静默写入。
- 刷新后草稿、布局和撤销记录清空；有未导出内容时先提示。

## 代表性规模

使用40个流程节点、80条流程关系、30个数据对象、120条数据操作记录、至少60条合并可见数据边、10张表单和200个字段执行页面操作、校验、导出和重新导入。视觉验证覆盖1920×1080、1536×864和1280×720内容可视区；低于1280像素只验证过窄提示、必要滚动以及文字编辑和合法导出不受阻断，不执行手机布局验收。

## 业务场景

覆盖本地创建、更新和使用；多行为处理一张表单；主表和多张明细表；字段直接取值、依赖本流程数据和外部系统来源；跨部门行为自动标记；跨泳道箭头；并行开始与汇合；判断分支与回路；数据先后按可达性判断；被引用对象删除保护；关系总览；版本说明与迁移摘要。
