Excel 列转 SQL IN

复制 Excel 中的一列，粘贴后自动生成查询条件，再复制到 SQL 编辑器。

01

支持 Windows 换行及 Excel 双引号包裹的单元格；粘贴多列时会提示修正。
02

输入 0 行输出 0 项 忽略空行 0去重 0
等待粘贴。编号、工号等带前导零的内容，请使用文本模式。

用法：在查询中写 WHERE 字段名，再粘贴右侧条件。只生成条件，不连接数据库。
文本中的单引号会自动转义；默认保留前导零，字符 NULL 按普通文本处理。

所有内容仅保留在当前页面内存中，关闭后不保存。
Excel 已丢失的前导零或数字精度，无法通过本工具恢复。
