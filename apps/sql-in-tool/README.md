# Excel 列转 SQL IN

独立单文件离线工具。双击本目录的 `index.html`，使用 Microsoft Edge 打开，无需安装依赖或启动服务。源码和可用页面为同一个文件，复制该 HTML 到其他位置后仍可独立使用。

## 使用

1. 在 Excel 中复制需要查询的**一列**，粘贴到左侧。
2. 默认按文本生成，例如 `00123` 生成 `'00123'`；查询数值字段时可选择“数字（不加引号）”。
3. 按需设置去掉首尾空白、去重、跳过首行表头和每行一个值。默认去掉首尾空白并去重，不默认跳过表头。空单元格始终忽略，数量显示在结果下方。
4. 点击“复制 SQL 条件”。在 SQL 编辑器中写入 `WHERE 字段名` 后粘贴结果，例如 `WHERE item_code IN ('A001', 'A002')`。

文本模式默认使用标准 SQL 单引号转义，适用于 SQL Server 等使用单引号加倍的环境，例如 `O'Brien` 生成 `'O''Brien'`。MySQL 会话开启反斜杠转义时，选择“MySQL（反斜杠转义开启）”；启用 `NO_BACKSLASH_ESCAPES` 时使用标准 SQL 选项。字符串 `NULL` 按普通文本处理，不转换为数据库空值；默认结果不带 SQL Server 的 Unicode `N` 前缀，需要时由使用者按目标字段类型调整。

## 输入和边界

- 支持 CRLF / LF / CR 换行及 Excel TSV 的双引号包裹、双引号加倍、单元格内换行和制表符。单元格内换行统一为 LF。输入行数按单元格记录计数，末尾换行不额外计一行。
- 检测到多列、未闭合的双引号或非法数字时，清空旧结果并禁用复制，不生成部分条件。空输入或全部被忽略时不生成 `IN ()`。
- 数字模式接受正负整数、小数和科学计数法，只校验原文，不转换为 JavaScript 数值。实际数值范围及科学计数法的数据库支持由目标字段和 SQL 方言决定。
- 文本模式保留前导零和长编号；Excel 在复制前已丢失的精度或前导零无法恢复。去重按选项处理后的文本精确比较，不合并 `1` 与 `1.0`，也不按数据库排序规则合并大小写。
- 仅生成 `IN (...)` 条件，不执行 SQL。目标数据库的类型、编码、语句长度和 `IN` 项数限制由使用者核对；工具不自动拆分或截断。
- 页面不请求网络、不连接数据库、不写入浏览器持久存储，也不自动读取剪贴板。仅在点击复制时写剪贴板；浏览器拒绝自动复制时可手动按 `Ctrl+C`。
- 输入与结果只保留在页面内存中，关闭或刷新页面后不保存。

界面基线为 Microsoft Edge、100% 缩放、1699×828 CSS 像素内容区，仅支持桌面。验证复制 Excel 单列、文本与数字模式、前导零、长数字、引号转义、空行、去重、表头、多列拒绝及复制操作；使用合成数据，不连接数据库。
