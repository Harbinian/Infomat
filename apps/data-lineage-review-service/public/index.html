CRUD 和 RACI

选定字段 → 按动作明确参与岗位 → 核对血缘 → 保存记录。

CRUD 是对字段做什么

C · 新建
首次录入、导入或生成该字段的值。
R · 查询
查看、查询或引用已有的值。
U · 更新
更正、变更或重新取值。
D · 删除或停用
清除字段值，或通过作废、停用结束使用。现场确认实际动作。

RACI 是谁参与该动作

R · 执行
实际办理该动作的岗位。
A · 最终负责
对处理结果承担最终责任的岗位。每项动作最多选一个，待定可留空。
C · 征询
办理或决定前需要征询的岗位。
I · 知会
需要获知处理结果的岗位。
