# 信息表收集服务权限矩阵

| 资源或动作 | 信息收集管理员 | 部门设计者 | 填报人 |
|---|---|---|---|
| 授予或撤销后台权限 | 全部 | 无 | 无 |
| 创建表单 | 任意归属部门 | 授权部门 | 无 |
| 修改设计稿 | 全部 | 表单归属部门 | 无 |
| 选择跨部门填报人 | 允许 | 允许 | 无 |
| 发布、关闭、延期、重新开放或取消任务 | 全部 | 任务归属部门 | 无 |
| 查看完成情况、答卷和附件 | 全部 | 任务归属部门 | 本人答卷 |
| 导出 Excel 和附件包 | 全部 | 任务归属部门 | 无 |
| 保存、提交或重新编辑答卷 | 不允许代填 | 不允许代填 | 本人开放任务 |

## 服务端判定顺序

1. 系统确认会话属于当前端口，并重新读取人员、账号状态和 `auth_version`。
2. 4000 写操作确认应用角色和表单归属部门；4001 写操作确认任务目标包含当前人员。
3. 系统确认任务和答卷处于允许当前动作的状态。
4. 系统校验输入结构和 `expectedRevision`。
5. 系统提交事务并写入不含完整答案的审计事件。

前端隐藏按钮只用于减少误操作，不能替代上述服务端授权。
