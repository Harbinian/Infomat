# 信息收集服务范围及启用状态

## 当前范围与入口

用户已确认将多个主表分区、多个独立明细表、明细逐行录入及从 Excel 粘贴连续单元格纳入正式范围。当前暂缓4000/4001的开发与正式启用。[目录约束](../AGENTS.md#修改边界)、[README](../README.md)、[PRD](PRD.md)及[技术设计](Tech-Spec.md)按此范围和状态维护。

4000表单设计提供“新增主表分区”“新增明细表”；4001按不可变表单版本提供明细网格及粘贴。每张明细表当前最多100行，附件字段只用于主表。旧表单和答卷的稳定标识及原有内容继续保留；不能直接回滚到不识别`__detailRows`的旧代码，恢复要求见[部署手册](Deployment-Runbook.md#4-回滚与恢复)。

## 启用状态

范围已确认，能力已实现；开发与正式启用暂缓，业务验收尚未完成。凭据补齐、账号创建和服务启动均不继续执行。此前完成的本地准备保留，后续恢复时重新核对目标实例及当时状态。

当前固定连接目标为`localhost:3307/infomat_mdm`，收集账号为`mdm_user`。收集服务优先使用独立`COLLECTION_MYSQL_PASSWORD`，仍兼容同账号的旧`MYSQL_PASSWORD`配置。后续恢复启用工作时，先核对凭据及结构，再启动4000/4001并检查健康和未登录访问边界；合同测试或历史数据存在不代替运行证据与业务验收。
