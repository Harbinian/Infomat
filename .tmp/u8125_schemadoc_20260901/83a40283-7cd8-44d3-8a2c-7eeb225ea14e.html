PU_CheckOptStatus Stored Procedure  (SA 销售管理)  [U861]

Summary

检测是否能修改或删除单据

Remark

--目的: 检测是否能修改或删除单据 --应用: 采购/销售系统(采购订单/采购发票/销售订单/发货单/销售发票) --作者: 李刚 --日期: 2001.04 --参数: @sFlag:单据标识(PBV表示发票; PO表示订单); @iVouchID:主表ID; -- @iStatus:0:修改;1:删除; @iCurAccMonth:当前会计月; @bAdmin:是否为账套主管 -- 返回: -- 采购: (1-正常; 0:无权限; -1:单据不存在; -2:当月已结胀(发票) 或订单已审核 ; -3: 发票已审核/付款/结算或订单已关闭 -- -4:发票日期所在会计月已经月末结账 -- 销售: 销售订单修改状态: 0:无权限; -1:单据不存在; -2:订单已经审核; -3:订单已经关闭; -- 销售订单删除状态: 0:无权限; -1:单据不存在; -2:订单已经审核; -3:订单已经被发货单关联; -4:订单已经被发票关联 -- 发货单修改状态: 0:无权限; -1:单据不存在 ; -2:发货单已经审核 ; -3:库存已经生成相关出库单 -- 发货单删除状态: 同上 -- 委托发货单修改: 0:无权限; -1:单据不存在 ; -2:已经审核 -- 委托发货单删除: 同上 -- 发票修改状态: 0:无权限; -1:单据不存在; -2:发票已经作废; -3:发票已经记账; -4:发票现结或审核或复核; -6: 库存已经生成相关出库单; -5:委托结算生成的发票不允许修改 -- 发票删除状态: 基本同上 -- 代垫费用单修改状态: 0:无权限; -1:单据不存在; 修改状态 -2:对应发票不存在 删除状态-2:单据已经审核 -- 销售支出单修改状态: 0:无权限; -1:单据不存在; -2:单据已经生成其他应收单 -- 委托结算单状态： 0:无权限; -1:单据不存在 ; -2:已经审核 --最后修改：2002-5-9 850版本将SO主子表关键字更改为ID --2002-7-12 将代垫费用、支出单据索引更改为id
