UFDATA

UA_UserDesktopState Table  (DP 企业门户)  [U8110]

Summary

用户桌面状态

Remark

/*用途：用户桌面状态标记 说明：当用户在自己的桌面上做过任何改动，例如：保存布局，增加常用功能，增加监控桌面页等等。 则将此标记记录为1.否则为0. 当管理员分配桌面给用户时，查询此表， 若没有记录，则认为用户从来没有改动过自己的桌面。从而按新分配的桌面给用户。（在分配时删除用户的桌面，用户在登录时会根据分配的重新获得桌面） 若有记录，则此次分配无效，提示 用户已经有自己的桌面。不能生效，若需要生效，则需要用户执行，恢复功能。 增加iType类型，iType=0表示桌面是否修改过，是则成为私人桌面 iType=1表示上版本中的“我的工作”是否升级过。只升级一次。 */

Columns

  iState (U8110) 当前状态为1,表示用户已经更改过桌面 smallint2 True
