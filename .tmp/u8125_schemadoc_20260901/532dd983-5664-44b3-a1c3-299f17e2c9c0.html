TCProc_ResPoolTimer Stored Procedure  (MK 营销管理)

Summary

实现资源池自动回收规则的定时任务

Remark

1. owner_id is not null && dept_id is null 回收到公共资源池，此时看owner_id下面有没有选择规则，如果有选择规则的话，则按选择的规则回收；如果没有选择规则的话则按默认规则回收 2. owner_id is not null && dept_id is not null 回收到部门资源池，此时看owner_id下面有没有选择规则如果有选择规则的话，则按选择的规则回收；如果没有选择规则的话则按默认规则回收 3. owner_id is null && dept_id is not null 回收到公共资源池---用回收到公共资源池默认规则 4. owner_id is null && dept_id is null 不需要回收
