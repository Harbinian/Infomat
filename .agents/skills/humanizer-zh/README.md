# 中文文风清理

本仓库的执行入口是 [SKILL.md](SKILL.md)，仅在用户明确点名 `humanizer-zh` 时使用。技能已随仓库提供，无需再次安装到个人目录。

按当前入口清理指定文字，保持事实、责任、术语、编号和执行条件。不要为自然感补造案例、数据、经历、来源或情绪；上游示例不是事实依据。正式、受控或可执行内容同时遵守 [technical-chinese-writer](../technical-chinese-writer/SKILL.md)。不执行固定评分门槛，不修改未授权内容。

## 来源与许可

本地版本改编自 [blader/humanizer](https://github.com/blader/humanizer)，并参考 [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop)；中文版本来源为 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)。上游参考资料包括维基百科的 [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)。这些链接用于来源追溯，当前执行规则以本目录技能入口为准。
