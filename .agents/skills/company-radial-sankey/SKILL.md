# Company Radial Sankey

Use this skill for the company-level `docs/company-sankey.html` radial business map. It is a self-contained presentation HTML, not a normal department Sankey page.

## Non-Negotiables

- Keep `docs/company-sankey.html` directly double-clickable; no remote CDN, no external runtime.
- Do not use ECharts Sankey as the main chart. Use native SVG/JS or local bundled code only.
- Preserve `var RAW_DATA = ...;` so `node scripts/parse-sankey-data.mjs --rebuild` can update embedded data.
- Do not alter business semantics, merge different node names, or invent missing department information.
- Treat `[空]部门名` as "该部门尚未提供业务资料", not junk data. Show those departments and their no-data markers strongly.
- Every visible label state must be overlap-free. If a label cannot be placed without overlap, hide the low-priority label and rely on tooltip/search/detail.
- Keep the first screen as the actual map, not a landing page.

## Expected Structure

The radial hierarchy is:

`昌兴复材 -> 三大域 -> 部门 -> 业务能力 L2 -> 业务流程 L3 -> 业务行为 A1 -> 应用系统/说明`

Default view should show company, domains, all departments, L2, systems/notices, and no-data markers. Do not show all L3/A1 labels by default.

The title must include a date:

`昌兴复材 · 全域能力流程系统 YYYY-MM-DD`

Use the current local date unless the user specifies another report date.

## Domain Sector Rules

The three domain sectors must be visually separated. Do not let `总经理直属域` wrap into or share a radial direction with `经营域`.

Use explicit angle ranges with at least 24 degrees between every pair of sectors. A proven default:

```js
var sectors = {
  '经营域': { start: -128, end: -18, color: DOMAIN_COLORS['经营域'] },
  '生产域': { start: 26, end: 128, color: DOMAIN_COLORS['生产域'] },
  '总经理直属域': { start: 158, end: 206, color: DOMAIN_COLORS['总经理直属域'] }
};
```

When adding departments, update data first with `node scripts/parse-sankey-data.mjs --rebuild`; then inspect whether the new density requires changing sector spans. Prefer widening the crowded sector and narrowing sparse sectors, while keeping gaps.

## Layout And Readability Rules

- Root is center. Domains, departments, L2, L3/A1, systems/notices radiate outward.
- Systems and notices stay on the outer ring.
- No-data markers get a warning style, dashed/halo emphasis, tooltip text, and a visible ray from the department.
- Long Chinese labels are truncated; full text goes in tooltip/detail.
- Department/domain/system/no-data labels are high priority. L2/L3/A1/notice labels are low priority and may be hidden by collision logic.
- In A1 mode, show A1 nodes and links but do not force all A1 labels onto the screen.
- The layer controls should use human business wording: `概览`, `业务流程`, `业务行为`.
- Search must look discoverable. Use a visible border and readable placeholder; do not leave it as a nearly invisible dark input.
- Provide zoom and pan. At minimum: mouse wheel zoom, `+`, `-`, `1:1`, and drag-to-pan after zoom.
- Clicking blank background must cancel node selection/focus and hide the detail panel. Treat SVG background, sector bands, rings, and links as blank for this purpose; do not reset domain/depth/search/zoom. Guard node clicks, controls, legend, stats, tooltip, and detail panel so they do not accidentally clear selection.
- Once a node is selected, selected focus takes priority over hover. Unrelated nodes must remain visible but blocked from click/focus switching; related nodes may still be clicked. Use the currently rendered link set to decide relatedness.

## Implementation Workflow

1. Check current data state:
   - Run `node scripts/parse-sankey-data.mjs`.
   - If source mapping files changed, run `node scripts/parse-sankey-data.mjs --rebuild`.
   - Confirm embedded HTML `RAW_DATA` counts match parser output.

2. Update only the necessary UI/layout code:
   - Preserve data generated by the parser.
   - Preserve existing helper names where possible: `buildGraph`, `computeNodeDomain`, `detectNoDataDepartments`, `computeParentsAndDepths`, `buildVisibleSet`, `aggregateLinks`, `layoutRadial`, `render`.

3. Repair readability by priority:
   - First fix sector geometry and angular distribution.
   - Then fix label collision.
   - Then tune opacity/color/controls.
   - Do not solve overlap by hiding departments or no-data markers.

4. Validate in a real browser or headless Chrome:
   - default overview
   - `全部/经营域/生产域/总经理直属域`
   - `概览/业务流程/业务行为`
   - search examples such as `OA`, `质量管理部`, `GLTX`
   - zoom button, wheel zoom, `1:1`, and drag pan
   - resize behavior

## Static Validation Checklist

Before finalizing, verify:

- `docs/company-sankey.html` contains no `<script src=...>`.
- No `type: 'sankey'` or `type: "sankey"` remains for the main chart.
- `var RAW_DATA = ...;` is present and parseable.
- Center node is `昌兴复材`.
- The title contains `YYYY-MM-DD`.
- Buttons include `业务流程` and `业务行为`, not `展开到 L3` or `展开到 A1`.
- Search border is visibly brighter than surrounding panel.
- Sector ranges have no overlap and every sector gap is at least 24 degrees.
- No-data department count in the rendered map matches `RAW_DATA.stats.departmentsEmpty`.

## Browser Validation Pattern

Use Chrome DevTools Protocol or another browser tool to inspect SVG output. Do not rely on screenshots alone.

At minimum, programmatically check:

- `.node-group` count is greater than zero in every state.
- `.node-label` visible bounding boxes have no overlap above a tiny tolerance.
- `#radialMap.viewBox.baseVal.width` decreases after zoom in or wheel zoom.
- `1:1` restores the original viewBox width.
- After clicking a node, clicking blank background clears `.node-group.dimmed`, `.node-group.highlight`, and hides `#detailPanel`.
- After clicking a node, hovering or clicking an unrelated blocked node must keep the original detail/focus active.
- Browser runtime/log events contain no errors or warnings.

## Final Response Discipline

Report only the meaningful results: what changed, the key counts, and what validation passed. Mention if temporary browser profile folders remain locked, but do not present that as a delivery blocker.
