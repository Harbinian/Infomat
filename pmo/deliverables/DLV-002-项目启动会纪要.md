## 六、责任池会议口径

责任池是启动期和调研期的历史问题保护机制。凡在项目推进中主动暴露、被 PMO 发现或由部门说明的历史流程问题、历史数据问题、跨部门边界问题、表单台账不一致问题和历史不符合项，原则上先进入责任池，作为治理对象处理。

除以下三类执行问题外，责任池内事项一律不追责：

| 例外类型 | 判定口径 | 处理方式 |
| -------- | -------- | -------- |
| 拖期 | 逾期未提交、逾期未反馈、逾期未确认，且未提前说明原因或申请协调 | 纳入 PMO 周会阻塞项；影响阶段门时提交项目决策层 |
| 交付物未交 | 应提交的清单、记录、模板、确认单、台账、材料未提交 | 纳入交付物台账；不得以口头说明替代交付物 |
| 提交材料质量过于低劣 | 空白、明显与任务无关、关键字段大量缺失、无法追溯来源、经一次退回后仍不能支撑下一步评审 | 退回重提；仍未改善的列为执行质量问题 |

责任池不是免做池。进入责任池的事项仍需记录、分级、确认责任边界并制定治理动作。
