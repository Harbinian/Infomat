# 调研范围与对象清单

| 项目 | 内容 |
| ---- | ---- |
| 交付物编号 | DLV-004 |
| 关联 WBS | 1.2.1.1 调研范围与对象清单确认 |
| 计划完成时间 | 2026-07-02 |
| 主责 | 信息化项目组 |
| 协作 | 各工作组 |
| 审核 | 信息化项目管理工作室 |
| 执行标准 | STD-PLAN-001 调研计划编制与评审标准 |
| 完成判定 | 范围覆盖五类专项；对象清单含部门、联系人、主题 |
| 证据要求 | 清单文件、确认记录 |

本清单先解决一个问题：下一轮现状调研到底找哪些部门、问哪些主题、由谁负责收材料和确认事实。

本清单不决定系统选型，不替代调研模板、访谈提纲、资料清单和调研日程。后续模板、提纲和日程仍按 WBS 1.2.1.2 至 1.2.1.5 继续形成。

## 一、使用边界

| 可以用于 | 不用于 |
| -------- | ------ |
| 确认五类专项调研范围 | 直接判断某个系统是否采用 |
| 确认各部门或工作组的调研对象 | 替部门指定最终业务负责人 |
| 确认联系人待补项和材料责任 | 替代正式会议通知或签字确认 |
| 为访谈提纲、资料清单和日程表提供输入 | 直接作为蓝图、招采或合同依据 |

联系人栏目前先按“待部门指定”处理。PMO 周会确认后，再补姓名和确认记录。涉及个人电话、邮箱等直接联系方式时，只进 PMO 内部联络台账，不写入公开版交付物。

## 四、主题清单

| 主题编号 | 调研主题 | 必问问题 | 输出到哪里 |
| -------- | -------- | -------- | ---------- |
| T-001 | 对象和字段 | 这个对象叫什么；谁维护；哪些字段必须有；现在有没有重复或缺失 | 数据与主数据调研清单 |
| T-002 | 流程和责任 | 谁发起；谁审核；谁执行；谁确认；结果交给谁 | 流程地图和责任边界 |
| T-003 | 表单和台账 | 使用哪些表单、台账、截图或系统记录；原始来源在哪里 | 资料清单和证据链 |
| T-004 | 系统和接口 | 目前在哪个系统或表格里处理；是否重复录入；接口是否稳定 | 系统现状和接口现状清单 |
| T-005 | 异常和问题 | 哪些场景经常绕行、返工、等待、口头确认或线下补录 | 问题清单和责任池 |
| T-006 | 权限和确认 | 谁能改；谁能看；谁负责最终确认；跨部门争议怎么升级 | 权限边界和阶段确认记录 |
| T-007 | 现场和资源 | 现场设备、网络、机房、终端、服务器和存储是否支撑目标场景 | 基础设施差距与风险清单 |
