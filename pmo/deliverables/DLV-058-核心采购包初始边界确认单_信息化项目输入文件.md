## 一、审查结论

### 1.1 当前结论

本文件可作为 DLV-058 的编制中版本进入内部评审。相较于原始输入文件，本版补齐了四项 PMO 必需内容：

1. 明确交付物编号、WBS、责任方、审核方和计划完成时间。
2. 把采购包边界从单一基础设施口径扩展为“核心应用采购包 + 基础设施支撑包”的两层结构。
3. 明确本文件只冻结初始边界，不触发招标或比选发布。
4. 补齐完成判定、证据要求、供应商澄清模板和初始确认页。
5. 本次 V0.3 补充超融合资源池推荐配置、普通办公 VDI 桌面模板、一期 80 人与二期 120 人资源预留、流畅度验收指标和扩容触发条件。

### 1.2 尚不能作为正式招采文件的原因

| 原因 | 说明 | 处理方式 |
| ---- | ---- | -------- |
| 技术规格未定稿 | PLM、MES/低代码平台、ERP、OA、基础设施各包仍缺供应商书面方案和资源落位表 | 供应商按本文件逐项澄清后再形成技术规格书 |
| 预算测算未闭环 | 当前只具备分包测算方向，未形成经采购和财务复核的预算口径 | 各包按同一模板报价和偏离说明 |
| 网络安全和机房承载未评审 | OA 外网、DMZ、仿真服务器外联、高功耗设备上架仍需专项确认 | 网络安全和设施评审先于正式发布 |
| 阶段门结论未形成 | DLV-058 是 G0 前置输入，不是阶段门放行结论 | 项目决策组确认后才能进入后续招采草案 |

### 1.3 本文件允许做什么

1. 用于内部确认核心采购包是否拆分合理。
2. 用于供应商下一轮书面澄清和预算测算。
3. 用于识别需要项目决策组提前处理的边界、资源、机房和安全风险。
4. 用于 PMO 周会跟踪 WBS 2.1.1 是否具备“初始边界冻结”条件。

### 1.4 本文件禁止做什么

1. 禁止直接作为招标文件、比选文件或采购公告发布。
2. 禁止据此直接确定供应商、技术路线、品牌型号或合同金额。
3. 禁止把不同采购包混成一个“大包”后要求供应商笼统报价。
4. 禁止把仿真/HPC、AI、VDI、OA 外网、涉密网络与普通管理系统资源池默认混用。
5. 禁止用本文件替代最终技术规格书、报价清单、合同条款、施工图、测试方案或验收方案。

### 2.2 初始冻结的含义

“初始冻结”只表示项目团队可以暂按本文件划分采购包、组织供应商澄清和预算测算。它不表示范围永久不变，也不表示进入正式招采发布。

后续如出现以下情况，应通过 PMO 变更或补充确认处理：

1. 总体蓝图改变核心系统边界。
2. 业务部门确认的流程、数据或并发规模发生重大变化。
3. 机房、电力、网络安全或合规条件无法满足初始方案。
4. 供应商书面澄清显示当前拆包存在重大技术或商务风险。
5. 项目决策组要求调整本期和二期范围。

## 五、基础设施支撑包边界

### 5.1 I01 超融合与虚拟化底座

| 边界项 | 初始口径 |

#### 5.1.1 超融合备选资源池基线

当前超融合平台按“PLM/MES/ERP/OA 后端 + 普通业务虚拟机 + 一期普通办公 VDI”进行初始测算，不承载 Ansys Fluent 生产仿真、AI 主负载和专业图形桌面。

| 项目 | 初始推荐/备选口径 |
| ---- | ---------------- |
| 节点数量 | 3 台超融合节点 |
| 单节点 CPU | 双路服务器，每节点建议不低于 64 物理核心级别，供应商需给出实际 CPU 型号和核心数 |
| 单节点内存 | 当前备选为每节点约 512GB；如二期承载 120 人 VDI，建议评估每节点扩展至 1TB 或新增 VDI 节点 |
| 虚拟化平台 | 支持 VM、HA、在线迁移、快照、备份接入、资源池划分、权限和告警 |
| 分布式存储 | 业务虚拟机和普通 VDI 系统盘优先放全闪/高性能池；个人文件和部门资料不建议全部放桌面系统盘 |
| 网络 | 管理网、业务网、存储网、迁移/HA 网、备份网分离；存储网和迁移网不面向普通用户路由 |
| 备份 | 接入统一备份平台；快照不等同于长期备份 |
| 高可用边界 | 供应商必须说明单节点故障后 PLM/MES/ERP/OA 与 VDI 的剩余承载能力 |
| 扩容方式 | 二期优先按“加内存、加 VDI 节点或拆独立桌面云资源池”三种路径比选 |

#### 5.1.2 超融合资源落位原则

| 负载 | 初始落位建议 | 控制要求 |
| ---- | ------------ | -------- |
| PLM/MES/ERP/OA 应用服务器 | 超融合业务资源池 | 按系统分区和安全域部署，不与管理网混用 |
| 核心数据库 | 原则上进入数据库专用资源区或数据库集群 | 不建议和普通 VDI 任意抢占资源；数据盘、日志盘、归档盘、备份盘分离 |
| 测试/培训环境 | 超融合资源池 | 资源上限和开机策略需受控 |
| 普通办公 VDI | 可从超融合中划分独立 VDI 资源池 | 一期可纳入，二期需触发扩容评估 |
| PLM 文件库 / 企业云盘 | 文件存储或云盘资源区 | 不建议把大量个人文件塞入 VDI 系统盘 |
| Ansys Fluent 仿真 | 独立仿真/HPC 平台 | 禁止与业务系统同池混跑 |
| AI 主负载 | 独立 AI 或仿真空闲算力试点 | 不作为超融合默认负载 |
| CATIA/Fibersim/Ansys 前后处理 | 图形虚拟化/vGPU 资源池 | 不纳入普通办公 VDI 模板 |

#### 5.1.3 普通办公 VDI 纳入超融合的容量边界

本文件将普通办公 VDI 暂按“内网办公桌面”纳入超融合可选资源池，不承担外网/民机非密专网/其他专网三网切换，不承担涉密桌面，不承担专业三维图形桌面。

| 阶段 | 用户规模 | 建议资源预留 | 结论 |
| ---- | -------- | ------------ | ---- |
| 一期 | 80 人 | 约 200～230 vCPU、850GB～950GB 内存、8TB～12TB 全闪桌面系统盘 | 可作为三节点超融合内的独立 VDI 资源池试点/一期运行，但需保留 PLM/MES/ERP/OA 余量 |
| 二期 | 120 人 | 约 300～340 vCPU、1.25TB～1.4TB 内存、12TB～18TB 全闪桌面系统盘 | 不建议在 3×512GB 节点上硬撑；需每节点扩至 1TB、新增 VDI 节点或拆独立桌面云资源池 |
| 文件容量 | 80～120 人 | 个人文件建议放企业云盘/文件服务，普通用户 100GB～200GB，核心岗位另行审批 | 不建议给每个 VDI 桌面系统盘配置 500GB |

#### 5.1.4 超融合扩容触发条件

出现以下任一情况，应触发超融合扩容或 VDI 拆池评估：

1. 二期普通办公 VDI 用户达到或接近 120 人。
2. VDI 资源池内存预留超过超融合可用内存的 70%。
3. PLM/MES/ERP/OA 与 VDI 高峰时段资源争抢明显。
4. 单节点故障后无法同时保障核心业务系统和普通办公桌面。
5. 登录风暴测试、Office/网页体验测试或存储延迟测试不达标。
6. 个人文件、部门共享文件、PLM 文件库占用超融合高性能池过快增长。
7. 供应商资源落位表显示三节点无法满足 N+1 运行边界。

#### 5.3.1 普通办公 VDI 推荐桌面模板

如本期将普通办公桌面放入超融合资源池，建议按以下三档模板设计。默认采用“标准办公流畅版”，不建议大面积使用 6GB 内存模板。

| 模板 | 适用对象 | vCPU | 内存 | 系统盘 | 用户配置盘/Profile | 个人文件空间 | GPU |
| ---- | -------- | ---: | ---: | -----: | ------------------: | ------------: | --- |
| VDI-Office-Standard | 大多数普通办公、OA、ERP、网页、Office、PDF | 2 | 8GB | 100GB | 50GB | 100GB～200GB，放企业云盘/文件服务 | 无 |
| VDI-Office-Heavy | 主管、财务重表格、数据统计、浏览器多开、大 PDF | 4 | 16GB | 120GB | 80GB～100GB | 200GB～300GB，放企业云盘/文件服务 | 无 |
| VDI-Office-Light | 前台、查询终端、轻 OA 用户，谨慎使用 | 2 | 6GB | 80GB～100GB | 30GB | 100GB | 无 |

控制口径：

1. 普通办公默认模板为 `2 vCPU / 8GB / 100GB 系统盘`。
2. “不卡”优先时，重办公用户直接按 `4 vCPU / 16GB`。
3. 不建议将普通用户全部配置为 `4 vCPU / 16GB`，否则会快速消耗超融合资源。
4. 不建议每个 VDI 桌面配置 500GB 本地系统盘；个人文件应进入企业云盘或文件服务。
5. 需要 CAD、CATIA、Fibersim、Ansys 后处理、三维模型查看的用户不属于普通办公 VDI，应单独进入图形虚拟化/vGPU 资源池测算。

#### 5.3.4 普通办公 VDI 流畅度验收要求

本期 VDI 以“不卡”为主要体验目标。供应商应提交体验测试方案，并在试点和验收阶段提供数据。

| 体验项 | 建议目标 |

#### 5.3.5 VDI 与授权边界

1. VDI 管理软件、桌面云授权、瘦终端、外设兼容和实施服务需单独列价。

3. 如涉及 vGPU 切片，NVIDIA vGPU 授权必须单独列价，不得默认包含。
4. VDI 只按内网普通办公桌面考虑，不承担外网、民机非密园区网和其他专网的网络切换。
5. 涉密桌面不纳入本文件普通 VDI 范围。
