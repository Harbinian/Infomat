## 七、变更与冲突处理

| 场景 | 处理规则 | 证据 |
| ---- | -------- | ---- |
| 时间冲突 | 优先保留覆盖多部门或关键责任人的场次，其他场次顺延 | 会议调整记录 |
| 关键人员缺席 | 会议可先收资料，但不得形成该人员职责确认结论 | 补访谈安排 |
| 资料未准备 | 允许召开说明会，但资料缺口必须进入 DLV-902 | 缺口台账 |
| 专项范围重叠 | PMO 统一判断是否合并场次或拆分议题 | 调整说明 |
| 会议取消 | 保留原计划、取消原因和新的拟排期 | 会议取消记录 |
