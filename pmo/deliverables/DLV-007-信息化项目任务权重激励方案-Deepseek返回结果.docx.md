一、第一阶段试运行考核方案

1.1试运行目的

本次试运行聚焦第一阶段流程治理与数据治理工作，核心验证三项机制：

权重合理性——任务权重是否能反映真实工作负荷；

有效工作评价——是否区分“做了很多”与“做成、做准、一次过”；

重点标的可管理性——高风险、里程碑、阶段门任务能否作为可复盘、可兑现的重点对象。

试运行结果用于校准权重、阈值和推广规则。期间发现任务边界、主责部门、证据标准不清的，先列入PMO待确认清单，不直接修改任务基线。

二、任务权重与总负荷计算

2.1计入范围

计入总负荷：非摘要、非0工作日、可执行且有明确交付要求的任务。

不计普通工作量：摘要任务、虚拟父节点、仅用于分组展示的任务。

里程碑和阶段门：不按普通工作量堆积分，单独作为节点兑现和节点考核标的。

经执行副组长审批同意调整的任务：按调整后周期计入，不作为未完成处理。

2.2单任务权重分（基础分1分）

| 加权项 | 加分 | 说明 |

| --- | --- | --- |

| 高风险任务 | +2 | 风险等级为高 |

| 关键路径控制 | +2 | 影响后续关键任务、阶段门或整体节奏 |

| H5重点展示 | +1 | 已纳入PMO重点展示或管理层关注清单 |

| 阶段门/放行阻断/合同付款控制 | +2 | 与节点放行、阻断、合同或付款控制直接相关 |

| 有明确交付物或审核人 | +1 | 任务基线存在交付物、审核人或审批组 |

| 工期6-10工作日 | +0.5 | 适度补偿持续工作负荷 |

| 工期超过10工作日 | +1 | 适度补偿长周期协调和材料闭环负荷 |



单任务权重分封顶8分。权重只用于评价任务负荷和有效工作，不代表资金金额。

2.3总负荷

试运行期应完成总负荷=周期内应完成任务的权重积分合计。

PMO不按任务条数或参与人数简单平均，高风险/关键路径/阶段门任务总负荷更高。

2.4任务有效积分

任务有效积分用于月度复盘和阶段汇总，计算公式为：

任务有效积分=任务权重分×完成系数×质量系数×证据系数

| 系数 | 取值口径 |

| --- | --- |

| 完成系数 | 按期完成或经执行副组长审批调整后完成为1.0；未获批逾期但已完成为0.6；未完成为0 |

| 质量系数 | 一次通过为1.0；退回一次后闭环为0.8；退回两次后闭环为0.5；最终未通过为0 |

| 证据系数 | 证据齐套为1.0；补齐后可追溯为0.8；无有效证据为0 |



三、按总负荷计算的有效工作评价

3.1核心指标

| 指标 | 计算公式 | 用途 |

| --- | --- | --- |

| 按期完成率 | 按期或经执行副组长审批调整后完成的权重积分÷应完成总负荷 | 判断节奏是否受控 |

| 一次通过率 | 一次评审通过的权重积分÷已提交评审的权重积分 | 判断提交质量和前置准备质量 |

| 证据齐套率 | 证据齐套任务的权重积分÷已完成任务权重积分 | 判断交付是否可追溯 |

| 返工扣减率 | 返工任务扣减积分÷已提交评审权重积分 | 判断返工对有效产出的消耗 |

| 有效工作得分率 | 按期完成率×40%+一次通过率×30%+ 证据齐套率×20%-返工扣减率×10% | 月度和阶段试运行综合评价 |



若分母为0，该指标不参与当期计算，并在复盘中说明原因。

3.2最终激励分数

试运行期内，各工作组的激励分档以最终激励分数为唯一量化依据，该分数由“综合评价得分”与“有效工作得分率”加权合成。

综合评价得分反映工作组当期实际挣得的有效积分占应完成总负荷的比例：

综合评价得分=任务有效积分实得总和÷应完成总负荷×100%

最终激励分数即为该工作组当期激励分档的唯一量化依据。

最终激励分数=综合评价得分×40%+有效工作得分率×60%

试运行评价分档（A/B/C/D）与最终激励分数共同用于激励分档表的判定，其中试运行分档作为定性约束条件（必要条件），最终激励分数作为定量门槛（充分条件），两者同时满足时方可进入相应激励分档。

3.3一次通过口径

一次通过必须同时满足以下条件：

按任务要求提交交付物、清单、纪要、评审材料或确认单。

首次正式评审结论为“通过”，或“仅需文字性修订（非内容性调整）且不影响结论”。

证据能关联至任务、责任部门、审核人、日期和版本。

未出现“提交内容无法判断”“证据链缺失”“关键字段为空”“部门未确认”等实质性退回原因。

3.4返工扣减口径

| 情形 | 返工扣减积分 |

| --- | --- |

| 首次退回，按要求补正后通过 | 任务权重分×20% |

| 第二次退回，按要求补正后通过 | 任务权重分×50% |

| 仍未通过、证据不成立或无法支撑下一步工作 | 任务权重分×100% |



因PMO模板、审核口径或上游任务变化导致的返工，经PMO确认为客观原因后，不计入返工扣减。

3.5试运行评价分档

| 分档 | 条件 | 应用 |

| --- | --- | --- |

| A档 | 有效工作得分率不低于90%，且关键节点无未闭环阻塞 | 优先确认正向激励资格，作为月度重点任务完成的支撑材料 |

| B档 | 有效工作得分率不低于75%，且阶段门未被阻断 | 视为试运行达标，进入常规复盘 |

| C档 | 有效工作得分率低于75%，或高风险/阶段门任务存在未闭环阻塞 | 暂缓相关专项激励资格，形成整改清单 |

| D档 | 关键节点未达成，且无执行副组长审批调整或有效证据 | 取消当期相关任务正向激励资格 |



3.6典型情形与处理结果

| 情形 | 示例表现 | 评价结果 | 激励或考核结果 |

| --- | --- | --- | --- |

| 完美交付 | 高风险任务按期提交，首次评审通过，证据齐套，未产生返工 | 完成系数1.0，质量系数1.0，证据系数1.0，任务有效积分等于任务权重分 | 计入按期完成率、一次通过率和证据齐套率；优先纳入正向激励资格 |

| 按期交付但小幅补正 | 任务按期提交，首次评审发现格式、文字或附件命名问题，补正后不影响结论 | 完成系数1.0；如不影响评审结论，可按一次通过处理；如形成正式退回，质量系数按0.8 | 可计入当期完成，不影响专项激励资格 |

| 经审批调整后完成 | 因上游材料或跨部门确认延迟，主责工作组提前提交调整说明，经执行副组长审批后按新节点完成 | 按调整后节点评价，完成系数1.0；不计未获批逾期 | 不作为负向激励事项；仍需按新节点验证一次通过和证据齐套情况 |

| 未获批拖期但未阻塞节点 | 任务超过计划日期提交，未提前取得执行副组长审批，但未影响阶段门或后续关键任务 | 未获批逾期，完成系数最高按0.6；按实际评审质量和证据情况继续折算 | 不进入该任务正向激励优先项；纳入月度复盘说明，可作为绩效扣分事实依据 |

| 高风险任务返工 | 高风险任务按期提交，但首次评审发现关键字段缺失、证据不足或结论不能支撑下一步工作 | 按返工次数扣减任务有效积分；一次退回后闭环按20%扣减，两次退回后闭环按50%扣减 | 暂缓该任务正向激励资格；进入整改清单，闭环后再评价工作组分档 |

| 证据缺失 | 声称任务完成，但没有评审记录、确认人、版本文件、纪要或其他可追溯证据 | 证据系数为0；任务有效积分为0 | 不计入有效完成；补证后可重新评价，但不作为一次通过 |

| 里程碑未达成 | 里程碑节点到期，前置交付物未齐套或评审结论未形成 | 不按普通任务补积分；节点兑现不成立 | 暂缓相关阶段正向激励资格；PMO形成节点偏差说明 |

| 拖期并阻塞阶段门 | 关键路径或阶段门前置任务未获批拖期，导致GATE-1.2等阶段门无法放行 | 相关任务有效积分为0；阶段门判定为阻塞；工作组当期分档原则上不高于C档，严重时按D档处理 | 暂缓相关工作组阶段专项激励资格；提交PMO周会和项目决策层复核，作为月度绩效扣分和整改依据 |

| 虚假完成或隐瞒阻塞 | 提交材料与实际进展不一致，或明知关键阻塞存在但未在周会和调整申请中说明 | 任务有效积分为0；不接受事后按客观原因追认 | 取消该任务当期正向激励资格；提交PMO周会和项目决策层复核，并纳入负向激励记录 |



四、正向激励应用

4.1月度绩效挂钩

试运行期每月由PMO汇总工作组最终激励分数及分档结果，作为阶段性激励资格认定的事实依据。

4.2项目专项激励资格

项目专项激励先确认资格，不直接计算金额。满足以下条件的工作组或主责部门，可进入专项激励资格确认：

当期应完成总负荷已完成，或未完成部分已有执行副组长审批调整。

高风险任务按期闭环，未形成未闭环重大阻塞。

里程碑或阶段门前置交付物齐套。

一次通过率、证据齐套率达到试运行分档要求。

无重大质量、进度、客户抱怨或合规问题。

激励资金额度、分配方式和审批程序，以本项目立项时批准的资金方案为准，由PMO汇总分档结果后，报执行副组长复核确认。

4.3激励资格分档标准

以最终激励分数为定量门槛，以试运行评价分档（A/B/C/D）为定性约束条件，两者同时满足时方可进入对应激励分档。

| 激励分档 | 最终激励分数及试运行分档要求 | 附加条件（需同时满足） | 激励资格 | 激励系数 |

| --- | --- | --- | --- | --- |

| A档 | 最终激励分数不低于85%，且试运行评价为A档 | 高风险任务100%按期闭环；阶段门全部放行；无返工超过一次的任务 | 确认 | 1.2 |

| B档 | 最终激励分数不低于75%，且试运行评价为A档或B档 | 高风险任务无未闭环；阶段门未被阻断；无虚假提交记录 | 确认 | 1.0 |

| C档 | 最终激励分数不低于65%，且试运行评价为B档 | 高风险任务无未闭环；阶段门未被阻断 | 确认 | 0.7 |

| D档 | 最终激励分数不低于55%，且试运行评价为B档或C档 | 阶段门未被阻断；已形成整改清单且承诺限期闭环 | 确认 | 0.4 |

| E档 | 最终激励分数低于55%，且试运行评价为C档或D档 |  | 暂缓资格，整改后经执行副组长审批可重新评定 | 0 |



以下任一情形发生，当期取消全部正向激励资格（对应激励系数为0）：

当期应完成总负荷不足60%按期完成（按权重积分计算）；

出现虚假提交或隐瞒重大阻塞事实的行为；

关键里程碑或阶段门未达成，且未取得执行副组长审批调整；

高风险任务出现重大质量事故或合规问题（由项目决策层认定）。

激励金额计算公式：

工作组实得激励金额=项目当期激励资金总额×（该工作组激励系数÷参与当期激励的各工作组激励系数之和）

注：项目当期激励资金总额由执行副组长会同PMO根据项目总预算和阶段进度提出方案，报项目决策层批准后执行。

4.4年度部门绩效挂钩

试运行期的月度汇总表、阶段门兑现确认表和整改闭环记录，可作为年度部门绩效中重点任务及行动项考核的事实依据。

年度应用坚持三项原则：

看总负荷完成质量，不只看任务数量。

看一次通过和证据闭环，不只看是否提交。

看高风险和阶段门结果，不只看普通事项完成率。

五、负向激励与资格暂缓

5.1触发情形

| 情形 | 处理口径 |

| --- | --- |

| 未获批逾期 | 对应任务完成系数按0.6或0计算，纳入按期完成率 |

| 无交付物或交付物无法支撑下一步工作 | 对应任务质量系数按0计算 |

| 无有效证据 | 对应任务证据系数按0计算 |

| 高风险任务未闭环 | 暂缓相关工作组当期专项激励资格 |

| 里程碑或阶段门未达成 | 暂缓节点兑现和后续阶段正向激励资格 |

| 虚假提交、重复提交无效材料或隐瞒阻塞事实 | 取消该任务当期正向激励资格，提交PMO周会和项目决策层复核 |



5.2客观原因调整

任务确需调整时，主责工作组应在任务节点前3个工作日提交调整说明，说明调整原因、影响范围、需协调事项和新的完成时间，须经执行副组长审批确认；未经审批的无效。客观因素消除后仍未完成的，按调整后的节点重新评价。

5.3责任池边界

本方案只评价当前项目任务的承接质量、证据闭环和整改推进，不对历史遗留问题本身做追溯处理。
