# 信息化工作群通知

各位：

现将《信息化项目协同工作规则》和《信息化项目部门主备对接人名单》提交信息化工作群，请项目决策组确认。

本轮主备岗按照实际承担项目工作的情况重新确定，不沿用既有名单作为默认安排。主对接人由项目负责人提出，备岗人员由部门负责人提出，最终名单由项目决策组确认。

当前名单中的主对接人和备岗人员栏暂时留空，线下确定后按以下时间补录并确认。

请各部门负责人注意以下时间：

1. 对主对接人人选有异议的，请于2026年7月28日12:00前在本群一次性说明理由并提出替代人选。
2. 各部门请于2026年7月28日17:00前提出备岗人选。
3. 项目决策组于2026年7月28日17:00前确认最终名单，PMO随后公示。
4. 新规则和主备岗名单于2026年7月29日生效，不设置过渡期。
5. 2026年7月30日13:30至14:00的周例会按新规则执行。

主对接人的项目工作时间建议为每日不少于1小时，或者每周累计不少于5小时，会议和培训时间计入其中。该时长是部门资源安排建议，不是个人考核项，也不要求填报工时表。部门未保障项目工作时间，并以“没有时间”为由影响进度的，按执行问题处理，不进入责任池保护。

规则生效后，项目通知、行动项、调整申请和决定以信息化工作群记录为准。请各部门负责人安排好人员和工作时间，确保项目相关信息、行动项和结果能够及时传达、接收、跟踪和反馈。
