# SVG信息图生成任务

## 角色

你是一名企业架构可视化设计师，同时具备组织社会学、数字化转型治理和信息架构能力。

你的任务不是重新解释模型，而是将给定的组织数字化参与度十六维模型，转换为一张高质量、中文可读、可编辑的 SVG 信息图。

---

# 一、任务目标

根据提供的 Markdown 真源内容：

《组织数字化参与度十六维分型模型
（16种类型 + 成长路径 + 退化路径 + 成因与治理策略）》

生成一张：

- 中文完整显示；
- 无乱码；
- 可编辑；
- 适合企业内部汇报；
- 适合微信分享；
- 适合打印A3/A4；
- 风格类似企业咨询报告信息图；

的 SVG 文件。

---

# 二、重要约束

## 1. 禁止使用AI图片生成

不要生成PNG图片。

不要使用图像生成模型绘制文字。

必须使用：

- SVG文本元素；
- 矢量布局；
- HTML/CSS转SVG；
- D3.js / Mermaid / Graphviz 等结构化方式。

原因：

中文文字必须100%准确。

## 2. SVG必须保持文字可编辑

要求：

- 所有中文必须作为 text 元素存在；
- 不允许文字转路径；
- 不允许嵌入图片；
- 不允许使用OCR生成文字。

---

# 三、整体版式要求

生成一张纵向长图。

建议尺寸：

```text
width: 1600px
height: 2400px
```

适合：

- 微信长图；
- PPT插图；
- 企业内部分享。

## 区域3：成长路径

使用绿色区域。

标题：

成长路径（理想演化方向）

展示：

```text

↓
机械执行型
↓
任务完成型
↓
业务伙伴型
↓
架构协同型

```

补充：

关键成功因素：

- 正向反馈
- 价值体现
- 组织激励

## 区域4：退化路径

使用红色区域。

标题：

退化路径（组织常见倒退）

展示三个方向：

### 能力退化

```text
A4 → A3 → A2 → A1
```

原因：

- 人员流失
- 知识未沉淀
- 工具替代思考
- 模型复杂度过高

### 意愿退化

```text
B4 → B3 → B2 → B1
```

原因：

- 利益受损
- 责任暴露
- 权力强化
- 收益不可见

### 双重退化

```text
A4+B4
↓
A3+B2
↓
A2+B1
↓
A1+B1
```

原因：

- 项目失去可信度
- 高层信号变化
- 长期没有收益反馈

## 区域5：退化成因

使用五个卡片：

### 人员与组织因素

人员流失导致知识重新隐性化。

### 利益与权力因素

透明化改变既有利益结构。

### 项目与管理因素

目标变化、资源不足、推进失衡。

### 方法与工具因素

工具复杂超过组织承载能力。

### 环境与战略因素

战略调整导致优先级下降。

## 区域6：治理策略

按照四类输出：

### 防御型（B1）

- 降低风险感知

- 高层治理介入

### 被动型（B2）

策略：

- 简化工具

- 分阶段交付
- 快速反馈

### 合作型（B3）

策略：

- 能力培养

### 共建型（B4）

策略：

- 参与企业级治理

不要创造新的理论。

不要添加不存在的类型。

不要简化16个类型。

不要把它变成普通管理培训海报。

它的核心用途：

> 观察企业数字化转型过程中，不同部门面对结构化、透明化和责任明确化时的行为变化，并指导PMO采取差异化治理策略。
