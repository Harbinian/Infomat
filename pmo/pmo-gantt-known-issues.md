> 记录日期：2026-06-05  
> 适用范围：`pmo/gantt-react`、`pmo/信息化项目_计划管控真源.md`、`pmo/信息化项目_WBS结构真源.md`

## Console 错误分类

| 错误类别 | 来源 | 处理 |
|---|---|---|
| `Slow network is detected` + `Fallback font` | Chrome 扩展 Adobe Clean 字体加载 | 与项目代码无关，无需处理 |
| `Download the React DevTools` | React 开发提示 | 生产构建无此日志 |
| `A listener indicated an asynchronous response` | Chrome 扩展消息通道 | 与项目代码无关，仓库内无对应消息监听代码 |
| `甘特图数据诊断报告` 中的 WBS 字符串排序异常 | `dateUtils.js` 的 `analyzeTasks()` 开发诊断 | 已限制在 Vite 开发模式，生产构建静默 |
| `里程碑占用父级编号: 3 个` | `isMilestoneTask()` 启发式判定误判 | 不改 MD 真源；作为已知展示层误判保留记录 |
