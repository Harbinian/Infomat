# 系统集成说明 H5 转 PPT 规划

## 受众与目标

受众为 2026-05-09 系统集成方案预审会参会人员，包括管理层、项目管理部、工程技术部、质量、采购、车间、财务及各系统实施方。目标是把 H5 长卷材料转换为可投屏、可编辑、风格一致的 PPT。

## 叙事结构

1. 先说明会议定位和为什么不能直接作为最终决策会。
2. 展开系统拓扑、四大集成域、MDM、黄金源、数据中台、适航追溯和关键接口。
3. 收束到未决问题、会前行动、组织分工、议程和 Q1-Q8 预审状态。

## 视觉系统

沿用 H5 的浅灰背景、白色卡片、海军蓝标题、亮蓝主强调、青色辅助强调，并保留绿色、橙色、紫色、红色等业务状态色。标题字体使用 Microsoft YaHei/PingFang SC，正文采用 Microsoft YaHei。

## 页面清单

封面、预审定位、核心系统清单、总体集成拓扑、四大集成域、MDM 建设路径、物料编码与字段治理、黄金源预审矩阵、数据中台架构、适航追溯专节、关键接口卡、接口字段示例、未决问题诊断、A0-A8 会前行动、组织分工、会议议程、Q1-Q8 预审问题、文档版本说明。

## 编辑性

所有标题、正文、表格、流程节点、系统卡片、拓扑节点和行动项均以 PPT 可编辑文本或形状生成，不使用截图方式承载主要内容。
