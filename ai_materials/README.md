# ai_materials 说明

> 状态：AI 处理输入材料目录  
> 生效日期：2026-06-11  
> 范围：用于 AI 提取、整理或转换的原始 Office 文档、扫描结果和中间索引。

本目录保存 AI 处理流程的输入材料和扫描索引。它可以作为资料来源追溯，但不替代 `docs/norms/` 中的标准映射 Markdown。

## 当前内容

| 路径 | 作用 |
|---|---|
| `1407/` | 工装工具相关体系文件原始材料 |
| `_folder_scan*.json` | 文件夹扫描索引 |
| `_compilation_table.json` | 编制或整理索引 |
| `体系文件编制*.xlsx` | 体系文件编制相关表格 |

## 使用边界

1. 从本目录抽取流程、证据或表单后，应沉淀到 `docs/norms/` 或相应报告。
2. 本目录材料可用于追溯来源，但不能直接作为 PMO 驾驶舱或 MDM 平台输入。
3. 新增原始资料时，保留来源、日期和适用范围。
4. 未脱敏或临时转换文件不要放入本目录。
