# ai_materials 说明

> 状态：AI 处理输入材料目录  
> 生效日期：2026-06-11  
> 范围：用于 AI 提取、整理或转换的原始 Office 文档、扫描结果和中间索引。

本目录保存 AI 处理流程的输入材料和扫描索引。它可以用于追溯来源；当前任务使用哪些材料由用户指定，目录归属和旧映射Markdown均不自动赋予其治理权威。

## 当前内容

| 路径 | 作用 |
|---|---|
| `1407/` | 工装工具相关体系文件原始材料 |
| `_folder_scan*.json` | 文件夹扫描索引 |
| `_compilation_table.json` | 编制或整理索引 |
| `体系文件编制*.xlsx` | 体系文件编制相关表格 |

## 使用边界

1. 从指定材料抽取流程、证据或表单时，保留来源和待确认项；草稿按对应技能或应用入口交付，经业务确认后由用户人工交给3000。历史副本或报告不能替代确认。
2. 本目录材料可用于追溯来源，但不能直接作为 PMO 驾驶舱或 MDM 平台输入。
3. 新增原始资料时，保留来源、日期和适用范围。
4. 未脱敏或临时转换文件不要放入本目录。
