API 路由设计

新增 /api/roles 和 /api/permissions 两个路由模块，扩展 /api/org/users 路由

角色管理 CRUD

方法路径说明权限
GET/api/roles角色列表（含继承链和权限数）admin
GET/api/roles/:id角色详情 + 完整权限树 + 已分配用户admin
POST/api/roles创建自定义角色admin
PUT/api/roles/:id编辑角色（名称/描述/父角色）admin
DELETE/api/roles/:id删除角色（系统角色拒绝）admin

权限分配

方法路径说明权限
GET/api/permissions全部权限定义列表（按资源分组）admin
GET/api/roles/:id/permissions某角色的权限矩阵admin
PUT/api/roles/:id/permissions批量更新角色权限（整表替换）admin

用户角色分配（扩展现有 /api/org/users）

方法路径说明权限
GET/api/users/:id/roles查看用户角色列表admin
PUT/api/users/:id/roles设置用户角色（替换全部）admin

批量导入

方法路径说明权限
POST/api/import/user-roles上传用户-角色分配 Excel/CSVadmin
POST/api/import/role-permissions上传角色-权限定义 Excel/CSVadmin
GET/api/import/templates/:type下载导入模板（user-roles / role-permissions）admin

设计要点

  • 权限更新用整表替换：PUT /roles/:id/permissions 传入完整权限 ID 数组，后端在事务中先删后插，简单可靠
  • 导入返回详细报告：{"total":100, "success":95, "errors":[{"row":3,"reason":"..."}]}
  • 角色删除保护：系统角色和有用户分配的角色不能删除，返回具体原因
  • 复用现有 multer + exceljs：批量导入复用现有文件上传和 Excel 解析基础设施
