深色顶栏的"黑度"选择

明确了：顶部深色 + 内容浅底 + 品牌红点缀。现在确定顶栏到底多黑？

三档黑度对比

A

纯黑 #000000 — 与 logo 一致的极致黑

完全匹配 logo 黑色，品牌一致性强。对比度最高。长期阅读表格后抬头看 topbar 时视觉冲击较大。

B

近黑 #0a0a0a — 99% 黑，微妙柔和

肉眼几乎看不出与纯黑的区别，但在大面积深色区域下眼睛更舒适。保留黑色气质的同时降低一点攻击性。

C

深灰 #1a1a2e — 蓝调深灰，更温和

带一点蓝调的深灰，不会和纯黑 logo 形成"两种黑"的对比。适合大面积使用的深色，有点像 GitHub 的暗色 header。

Tabs 导航条的处理

topbar 深色后，下方的 tab 导航条怎么处理？

D

Tabs 保留白色背景

Topbar 深色 → 下方 tab 白色底。清晰的分层，tab 与内容区融为一体。和当前结构一样，只改了 topbar 颜色。

E

Tabs 也变深色（整体深色头部区）

Topbar + Tabs 统一深色，形成一个完整的深色"命令区"。内容区从 tabs 下方开始变白。更有沉浸感但改动更大。
