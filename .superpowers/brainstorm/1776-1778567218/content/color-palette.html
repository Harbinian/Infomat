Logo 配色分析 & 方案方向

Logo 主色：#fc0000 红色 47.7% + #000000 黑色 32.9% — 大胆高对比的红黑风格

当前配色 → Logo 驱动配色

当前：灰度单色系
黑色系 accent + 灰白背景 — 专业但缺乏品牌识别度
目标：红黑品牌色
大红 + 纯黑 — 强烈的品牌冲击力，源自 logo 基因

选择配色方向

以下三种方案各有侧重，点击选择你的偏好

A

红强调 — 浅底 + 红色点缀

白色背景，红色 (#fc0000) 用于按钮、tab、链接、图表。保留大量留白，红色只作为"动作色"。类似 Stripe / Linear 的克制路线。

B

深色模式 — 黑底 + 红高亮

深色背景 (#0a0a0a → #1a1a2e)，红色作为强调色点缀。高对比度、科技感强，适合长时间使用的工具类产品。

C

混合模式 — 浅底为主 + 深色顶栏 + 红色标识

内容区保持浅色（便于阅读表格和表单），topbar 和导航区域使用深色/黑色，红色只用于品牌标识和关键交互元素。兼顾可读性与品牌识别。
