琥珀色错误 — #d97706 (沿用 warning 色系)

把 error 和 warning 统一为琥珀/橙色调，与品牌红彻底拉开距离。

B

保留红色错误 — 加深 error 红色使其区别于品牌亮红

Error 用更暗的红色 (#991b1b / #b91c1c)，品牌红保持 #fc0000 鲜亮。
都是红但亮度差够大，用户能区分。

错误标签 品牌红
C

珊瑚色错误 — 品牌红偏暖方向，错误红偏粉

Error 改为偏粉/品红方向 (#e11d48 rose)，与纯红 #fc0000 形成暖/冷区分。
保留"红色系"直觉但色调不同。
