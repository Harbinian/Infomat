方案 A：保守 — 深头 + 浅身，红只在关键点位

Red 标记的关键变化

  • accent #111827(黑) → #fc0000(红) — 核心转变
  • error #dc2626 → #b91c1c — 更深以区分品牌红
  • focus-ring 跟随红色

需要关注的 ECharts

  • 柱状图 itemStyle.color 当前 #111827 → 改为 #fc0000
  • 饼图 color 数组 5 级灰 → 红 + 深灰渐变

方案 B：更激进 — 红色在更多点位

同样的深色头部 + 浅内容框架，但红色不仅用于按钮，也用于 tab 激活态文字、链接、选中行高亮等。视觉上更"红"，品牌感更强，但可能带来视觉疲劳。

B 方案差异：红用在 tab 文字 + 链接

你选哪个？

A

保守红色 — 仅按钮 + Tab 指示器 + focus ring 用红

Tab 文字保持白色/灰色，链接保持默认色。红色克制地出现在"可点击执行"的位置。

B

品牌强化 — Tab 激活态 + 链接 + hover 行也用红

红色在更多 UI 位置出现，品牌一致性更强，但日常使用可能视觉疲劳。
