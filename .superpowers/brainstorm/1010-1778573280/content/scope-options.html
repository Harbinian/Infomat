布局重设计 — 三种范围选项

从最小的 CSS 调参到跟随交互 spec 的完整重构

A

仅调 CSS 参数

不改 DOM / JS，只改几个数字

max-width → 1600px chart 300→450px split 320→400px
B

跟随交互 spec 重构

按已审批的 frontend-interaction spec 实施三层架构 (L1列表→L2详情→L3操作)，新页面自然消除当前布局问题

需要新 DOM 需要 hash 路由 工作量较大
C

CSS 先改 + 结构后改

先调 CSS 立即缓解空间浪费（30 分钟），交互 spec 的结构性重构后续再做

快速见效 分步推进 低风险

对比

A · CSS 微调 B · 跟随 Spec C · 分步 (推荐)
改动量 ~10 行 CSS 全量 DOM+CSS+JS CSS 先 ~20 行，后续再重构
耗时 30 分钟 2-3 天 30min + 后续 2 天
解决 1200px 问题 ✅ ✅ (设计即考虑) ✅ 先解决
