Dashboard 图表高度

当前 300px 固定，1080px 视口下内容区约有一半是空白

A

450px (适度放大)

占视口 ~42%，平衡数据可视与下方内容

.chart { height: 450px; }
B

视口比例 50vh (动态)

始终占半个屏幕高度，不管分辨率。图表够大但有滚动

.chart { height: calc(50vh - 120px); }
C

图表自适应 + 合并行

增大图表的同时，将 2 列并排改为上下堆叠，每个图表独占一行更宽

.chart { height: 420px; }
.g2 { grid-template-columns: 1fr; }
/* 宽屏下每个图表全宽 */
