容器宽度策略

当前 max-width: 1200px — 1920px 屏幕浪费 37.5% 空间

A

放大至 1600px

改动最小，兼容性好。1920px 屏占比 83%

max-width: 1600px;
padding: 40px 32px 80px;
B

响应式断点

按屏幕大小自动适配，更灵活但稍复杂

≥1920px → max-width: 1600px
≥1440px → max-width: 1200px
<1440px → 100% (padding 撑开)
C

完全流式 (无 max-width)

内容撑满全屏，仅靠 padding 留边距。最大密度，但超宽屏可能阅读困难

/* 移除 max-width */
padding: 40px 48px 80px;
