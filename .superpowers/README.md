# .superpowers 说明

> 状态：Superpowers 历史工作输出目录  
> 生效日期：2026-06-11  
> 范围：历史 brainstorm 输出、截图、HTML 片段和运行状态文件。

本目录当前保存 Superpowers 工作流产生的历史输出。它用于追溯当时的设计探索，不作为当前流程输入基线、PMO 展示真源或 MDM 实现真源。

## 当前内容

| 路径 | 作用 |
|---|---|
| `brainstorm/` | 历史头脑风暴输出，包含截图、HTML 片段和状态文件 |

## 使用边界

1. 历史 brainstorm 结论若要进入当前执行线，应转写到 `docs/plans/`、`docs/reports/` 或 `docs/adr/`。
2. 新的截图、运行状态和临时输出不应继续长期提交到本目录。
3. 清理或迁移已跟踪历史输出前，应先写迁移提案并确认引用关系。
4. 这里的 `state/server.pid` 等文件只反映历史运行状态，不作为当前服务状态。
