# 欢迎使用 Slidev

这是一个基于 Markdown 的演示文稿工具。

---

## 功能特点

- 🖥️ **双重视角** - 同时编辑代码和幻灯片
- 📝 **Markdown 语法** - 使用熟悉的 Markdown 编写
- 🎨 **主题系统** - 丰富的自定义主题
- ⚡ **即时预览** - 文件保存后自动刷新

---

## 代码高亮

```javascript
const greeting = 'Hello, Slidev!'
console.log(greeting)
```

---

## 使用方法

1. 运行 `npm run slidev` 启动开发服务器
2. 编辑 `slides/index.md` 文件
3. 按 `o` 打开幻灯片概览
4. 按 `f` 进入全屏模式
